# 短剧美术与资产设计

## 创作目标与默认阅读

以“观众爱看、愿意停留”为第一性原理。先读[共同创作方式](../short-drama/references/viewer-first.md)和[影视工业核心](../short-drama/references/film-craft-core.md)，以及本阶段核心知识：

- [主动美术设计](../short-drama/references/visual-structure-and-art-direction.md)
- [人物与妆造](references/character-and-look.md)
- [空间与陈设](references/location-and-view.md)
- [道具与状态](references/prop-and-state.md)

- [成像风格与感官质感](../short-drama/references/image-look-and-finishing.md)

以上默认读取；同一轮已读且未变化的内容直接复用。按场面选择手法，接口和专门故障资料用到再查。

围绕“观众爱看、愿意停留”，把简单剧本发展成有性格、有层次、可表演的视觉世界。承担本集美术指导职责，统一写入 `剧集/<EP>/视觉设定.md`。

## 工作流

1. 读故事内核、人物关系、情绪走向和已定视觉方向；明确观众先看到什么、怎样认识人物、哪些细节值得记住。
2. 主动发展人物造型与场景设计。未规定的外观、空间、陈设、天气光态和生活趣味由 Agent 选择，写明是美术设计以及服务的体验。
3. 同时考虑下表，再按场面选主次。复用既定角色和地点，新增设计融入其当前造型、视图与状态。
4. 把关键设计写入现有条目；用 `- 设计重点：` 留下需要在资产图与成片读到的重点，声音用 `- 声音重点：`。一般陈设作为地点整体设计，关键互动道具单独登记。
5. 规划身份参考、造型板、场景母版和角色入景代表帧的用途。已有图能承担多个用途时复用；在真实目标画幅里检查人物、衣服、背景与光线能否共同成立。
6. 选少量跨镜识别锚点与连续性锁，记录真正变化的状态。将设计重点交给图片、分镜和后期；完整制作任务继续推进后续环节。

## 设计菜单

| 维度 | 作出具体选择 |
|---|---|
| 人物轮廓 | 面部与体态、剪影、常态姿态、与其他角色的区别 |
| 服装造型 | 廓形、内外层搭配、织物、鞋履、配饰、穿法与使用痕迹 |
| 妆发与表面 | 发型整理、妆面、皮肤或毛发、当日状态、接触与天气影响 |
| 空间与建筑 | 功能分区、出入口、纵深、前中后景、观看和行动路径 |
| 陈设与生活 | 家具组合、收纳、维修、磨损、时代用品、摆放习惯 |
| 道具与趣味 | 个性物件、反差搭配、可互动功能、材质趣味与视觉记忆点 |
| 光色与摄影 | 光源来处、主次色、软硬与明暗、材质响应、人物和背景分离 |
| 环境与声音 | 持续活动、物理反馈、画外世界、空间底声、衣料和物体声音 |

识别锚点保持简练，完整设计可以丰富。朴素、极简、夸张或华丽由人物与观看体验决定。生活质感、审美和趣味本身都是细节的价值。

## 文档与交接

沿用 `## 人物|造型|地点|道具 · 名称`、`识别锚点`、`本集造型`、`状态变化`、`画面代称`、`连续性锁` 等现有语法。条目区分剧本明确事实、美术设计与本集状态；设计来源可写“EP001-SC001 · 美术设计”，成为下游依据。

身份描述负责同一个人；Look 负责一套完整造型；地点负责空间和陈设；状态负责本集变化。分镜再把它们放入具体机位、动作和视听节奏。跨语言名称按实际提示词拼写声明；可见文字沿用项目选择。

## 完成

角色有自己的视觉语言，环境有设计与使用逻辑，关键细节有可见承载和可用的表演空间。已有图时实际看图；文本阶段交付可执行设计和明确的出图意图。用跨文档检查核对引用与状态，把创作质量落在作品上。
