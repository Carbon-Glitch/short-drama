# 短剧剪辑与成片

把 `剧集/<EP>/制作成果/` 里的逐镜素材装配成一条成片，取舍写进 `剧集/<EP>/剪辑单.md`。
每段使用二级标题 `## CUT-...`，各自绑定一个来源 ID 和一个真实媒体文件：视频段是 `MOTION-...`，
静态漫剧的关键帧段是 `SHOT-...` 或 `IMG-...`。

根据实际素材选择可用片段，按剧本与分镜核对叙事。素材与意图不一致时，记录取舍和缺口。

每次剪辑先读[前期情绪到实际剪法](editorial-intent.md)：承接已有节奏、揭示与反应，主动选 BGM、声画切点和字幕样式，将决定落实在当前剪辑单与真实时间轴上。

声画分离、音乐包络、转场和低清预览按[分轨执行](layered-execution.md)直接完成；仍由本技能作剪辑决定，原剪辑单生成执行计划，调用已有本地 helper。

默认读取[精剪与后期精修](finishing-craft.md)和 `$short-drama` 的
[影视工业核心](../../short-drama/references/film-craft-core.md)。先做故事、表演和节奏剪，再做声音、连续性和交付精修。

主动以观众情绪体验和高级影视感组织本阶段选择；读取[主动导演](../../short-drama/references/film-craft-core.md)，将机位、构图、运镜、声画与剪辑技巧落实到具体画面和时间关系。

## Quick Start

```text
用 $short-drama-edit 把 EP001 已生产的镜头剪成成片
```

## 入口

进入条件是**素材已经存在且可读**：`剧集/<EP>/制作成果/` 里有本次要用的视频文件；
静态漫剧是已接受的关键帧和配音文件。
先确认本次素材文件可打开，不能仅凭提示词、生产确认或 adapter 成功回执开始剪辑。

素材不全时可以先剪已有连续段落；用户要求完整成片时，将这一版标为片段并列出缺口。
在「未采用镜头」说明缺文件、质量不可用或叙事取舍。

`剧集/<EP>/分镜.md` 与 `视频提示词.md` 是镜序和职责的来源。剪辑可以**取舍**它们，不能**改写**
它们：删一镜、缩一镜、换顺序都属于本阶段；改台词、改镜头职责、改起终状态要回上游发修订请求。

原生渲染直接拼接编码后的分段，输入素材的画幅与帧率须一致；分轨路线按已选画布保构图留边并统一帧率。原生 `check` 在可探测媒体时核对；
不同规格先通过外部工具按交付要求统一，保留构图并记录裁切或留边，再更新剪辑单的路径与时间。

渲染与测量需要 `ffmpeg` / `ffprobe` 在 PATH 上。没有时 `edit_tool.py` 直接失败并说明，
不用别的手段近似，也不把「没测」写成「通过」。

## 工作流

沿用现有现实观众基线和分镜知情时机，将需要保留的预测依据、反应与兑现落实到实际源片区间；不能以“现在观众都要快”为由裁掉理解和情绪落点。
有真实平台反馈时区分观察与原因推断，证据不足保留假设。本阶段不重做市场研究；需要改核心看点时回交开发/写作。方法见[现实观众预期校准](../../short-drama-develop/references/audience-expectation-calibration.md)。

1. **看完整素材，标可用带并构思剪法。** 主动选择表演、反应、镜序、声画先后、动作/图形匹配、蒙太奇、转场和速度变化；关键段落比较不同情绪组织，选定后写进剪辑单。 每个文件从头到尾看一遍，写下它实际能用的时间
   区间，以及区间之外发生了什么（起势静止、结尾漂移、发白、动作回弹、多余的重复表演）。
   这一步的产出是事实，不是决定。做法见 [生成素材的可用带](generated-footage.md)。
2. **有台词的镜先定位发声区间。** 保留完整字音和所需停顿。视频自带声音随画面同步裁切；
   独立配音文件可用 `配音` 行跨切点播放，分离或替换原视频音轨则先用外部工具处理。
3. **在可用区间内选叙事入出点。** 按动作、反应或停顿的需要选择入点，出点取信息完成之后、缺陷
   开始之前。逐段写清入点理由和出点理由。做法见 [入出点与镜序](cut-craft.md)。
   选定区间后对照该SHOT职责与可选的“剪辑意图”：触发、选择、接触、确认、反应和余韵是否真的留下；
   有引用但源窗裁掉关键事件仍算缺失。精剪时读[分镜落实与精剪](editorial-conform.md)。
4. **排镜序并检查相邻关系。** 检查动作、空间、揭示与声音是否连贯；重复信息没有新增作用时再删。
5. **比较相邻段的画面。** render 会在同一场景内自动接镜；按同场景、同光态比较可比区域，
   自动接镜不够或不该动的段写 `画面`。做法见 [接镜与色彩一致性](generated-footage.md#接镜与色彩一致性)。
6. **处理声音接缝与响度。** 拼接后回听；需要混音时通过外部工具执行并记录。
   做法见 [声音、字幕与音乐](sound-and-subtitles.md)。
7. **写字幕、画面文字与音效。** 字幕的每一个字都取自 `剧本.md` 的台词原文，不取自转写结果；
   标点照抄剧本，字不能改。转写只用来定位时间。画面留白给后期的 `[画面文字]` 写成 `画面文字` 行，
   需要落在画面文字出现时的提示音写成 `音效` 行。
   承接分镜的制作分工，按实际采用时钟落实字幕、图形与效果；先查素材是否已经含该层，避免重复叠加。
   跟踪、遮挡或复杂效果超出内置字段时，落实到真实外部工程并记录，不把“制作分工”说明当成已执行。
8. **写出 `剪辑单.md`，再渲染。** 取舍、时间与后期处理先落进文档，成片按这份记录生成。
9. **按可测项验收成片，再交付。** 见 [交付与验收](delivery-verify.md)。

## 剪辑单要求

- 正文开头写交付规格：`成片目标时长`、`画幅与帧率`、`交付响度`、`字幕`。目标时长是意图，
  实际时长与目标的差写在报告里。用户明确要求固定时长时，应满足要求或报告缺少的素材。
- 每段一个 `## CUT-<EP>-<序号> · <中文名称>`，块内逐行写：

  - `- 来源：<MOTION-...> · <项目相对路径>`——`MOTION-...` 必须是 `视频提示词.md` 里真实存在
    的条目，路径必须是当前可读的文件。静帧段写 `- 来源：<SHOT-...> · <图片路径>`（`分镜.md` 的镜头）
    或 `<IMG-...> · <图片路径>`（`图片提示词.md` 的条目），图片为 png / jpg / jpeg / webp；
    入点写 `0.00`，出点等于时长，至少 `0.50` 秒。静帧按交付规格的画幅与帧率铺满出画，
    有静帧时交付规格必须写 `画幅与帧率`。
  - `- 入点：<秒>` / `- 出点：<秒>` / `- 时长：<秒>`——三者必须自洽，`出点 - 入点 == 时长`。
    全部用秒，保留两位小数，不写时间码，不写帧号。
  - `- 取舍：入点=<理由>；出点=<理由>`——说明画面上的具体变化及其叙事作用，不只写「节奏需要」。
  - `- 声音：<本段声音怎么处理>`——记录保留原声或外部处理。此行不驱动内置 render 的混音。
  - `- 画面：<接镜校正>`、`- 画面：无` 或 `- 画面：不校`——校正是「亮度 <数>」「饱和 <数>」「色温 <数>」
    三项的任意组合，用 `；` 分隔，写了就替代这一段的自动接镜；`无` 表示不另写校正；`不校` 表示连自动接镜
    也不做。详见 [接镜与色彩一致性](generated-footage.md#接镜与色彩一致性)。
  - `- 字幕：<逐字台词原文>` 或 `- 字幕：无`。本段有多句台词时改用编号写法，
    每句自带时间：`- 字幕 1：0.20-1.50 请进`、`- 字幕 2：2.30-4.30 门没有锁`。
    编号从 1 连续，时间相对本 CUT 入点，且不得重叠；止可以超过本段时长（跨切点见
    [静帧段](still-cuts.md#配音)）。句末可加 `（重点：<词>｜<词>）`，
    这些词须出现在本句里，烧录时标黄。字色按 `剧本.md` 里这句的来源决定：对白白色，
    `[VO] 系统：` 青色，其他 `[VO]` 浅青，剪辑单里不另写。
  - `- 画面文字 N：<起>-<止> <样式> <项>｜<项>…`——视频模型写不对字，系统面板、倒计时、屏幕上的
    粉丝数在画面里留白，由 render 叠上去。每一项都要能在 `剧本.md` 的 `[画面文字]` 行里找到。
    单条可不编号；编号与时间规则同字幕。三种面板共用画面顶部，角标在右上角，同一位置不得重叠。

    | 样式 | 各项的位置 |
    |---|---|
    | `卡片` | 每项一行：第一个词是名称，最后一个词是数值，中间的词是单位（`本月 订单 128｜退货 3`） |
    | `系统面板` | 第一项是状态行，逐字打出；其余是奖励行 |
    | `任务面板` | 标题、目标（逐字打出）；其后写成 `<数> / <数>` 的一项是进度，其余是奖励标签 |
    | `角标` | 各项连成一行标签 |

    奖励可在项末写稀有度 `（传说）` `（史诗）` `（稀有）`，不写按稀有；稀有度不是文字，不参与核对。
    `任务面板` 和 `角标` 末尾可加 `（倒计时：<秒>）`，显示成 `4天 23:59:58` 并逐秒走动；
    `（倒计时：接续）` 接着成片里上一个倒计时走。相邻两段写同一条角标且首尾相接时，
    成片里是同一个角标，切镜时不重新入场。面板自带的 `【系统提示】` `【新任务】` `进度` 属于样式，不写进剪辑单。
  - `- 音效 N：<起>-<止> <项目相对路径>（起点：<秒>；增益：<dB>）`——从声音文件的起点（默认开头）
    取 `止 - 起` 秒，混进本段该时刻的原声；括号里两项都可省、顺序不限，增益范围 -40 到 +6。单条可不编号。
  - `- 运镜：<固定|推近 n%|推近 r%/秒|…>`——只写在静帧段上，方向另有拉远、左移、右移、上移、下移；
    n 为 1–30 的幅度，r 为 0.1–10 的速度（可带小数），不写按固定。两种写法怎么动、怎么接见
    [静帧段](still-cuts.md#运镜)。
  - `- 配音 N：<起> <项目相对路径>（起点：<秒>；增益：<dB>）`——从本段 `起` 秒开始，把声音文件从起点
    放到结尾；括号规则同音效。`起` 可以为负，声音可以跨过切点；跨切点、核对与后期配音的规则见
    [静帧段](still-cuts.md#配音)。
  - `- 环境声：[<起>] <项目相对路径>（起点：<秒>；增益：<dB>）` 或 `- 环境声：[<起>] 无`——从本段 `起` 秒
    （默认 0，可为负）起循环铺一层环境声，直到下一条 `环境声`；`无` 让它停下。见
    [静帧段](still-cuts.md#环境声)。
- 素材里没有被采用的镜头，在正文开头写一行 `- 未采用镜头：<MOTION-...>（理由：……）`，
  多项用 `；` 连接。理由区分两类：**文件缺失**（还没生产 / 生产失败）和**质量不可用**
  （生成结果不能用），也可说明叙事取舍。补素材前先判断需要重出还是修订上游。
  有静帧段时也可写 `SHOT-...`；哪些镜头要有下落见 [静帧段](still-cuts.md#每一镜的下落)。
- 同一个 `MOTION-...` 可以拆成多个 `CUT-...`（同一段素材的两处分别使用），也可以整段不用。
  不能凭空出现没有素材来源的 `CUT-...`。
- 同一视频被用两次时，两个 `CUT-...` 的源时间区间不得重叠。确需重复出现（闪回、强调）时，
  写明重复的意图及第二次的作用；同一静帧可以用于多个 `CUT-...`。

## 边界

- **不生成新素材。** 需要补拍、重出、换参考图，回 `$short-drama-produce`；需要改提示词，
  回 `$short-drama-video-prompts` 或 `$short-drama-image-prompts`。
- **不改上游语义。** 剪辑单可以让某句台词不出现在成片里（整镜未采用），不能改这句台词是什么。
  发现剧本层面的问题就点名报告，交回 `$short-drama-write`。
- **沿用剧本的声音设计。** 保留已有对白、VO 和 OS，不自行增加解说；需要新增叙述时回写作阶段。
- **不把技术成功写成质量结论。** 渲染完成、时长对上、文件存在，都不是「这条片子能看」。
  成片质量的判断交给 `$short-drama-review`，或交给创作者本人。
- **按已授权目标完成。** 继续修复影响交付的问题；新增创作方向或补素材需求交给创作者决定。

## 命令

命令由 [edit_tool.py](../scripts/edit_tool.py) 提供：

```text
python3 <本技能目录>/scripts/edit_tool.py check <剧集/EP001> --project-root <project>
python3 <本技能目录>/scripts/edit_tool.py conform <剧集/EP001> --project-root <project>
python3 <本技能目录>/scripts/edit_tool.py render <剧集/EP001> --project-root <project> [--no-subtitles] [--subtitles ffmpeg|remotion] [--remotion-concurrency N]
python3 <本技能目录>/scripts/edit_tool.py verify <剧集/EP001> --project-root <project>
```

`check` 只核对不渲染：素材是否比剪辑单新（重出之后字幕、画面文字与音效时间必须重测）、区间自洽、
来源 ID 解析与每一镜的下落、文件存在、区间不越过素材时长、同源区间不重叠、字幕去标点与空白后能在 `剧本.md` 里找到、
画面文字能在 `[画面文字]` 行里找到、「接续」之前确有倒计时、音效文件存在且落在本段内、
字幕与配音在整条片里不越过结尾、互不重叠。
其中「区间不越过素材时长」需要 `ffprobe`，配音的两项需要 `ffmpeg`；缺哪个就报哪几项「未测」并说明原因，
不静默跳过。
有《分镜.md》时，同时核对全部SHOT的去向，包括还没写成MOTION的漏镜；有意不采用仍按原有理由记录。
`conform` 只读输出 `CUT→MOTION→SHOT→场景`、源窗、计划成片时码与职责，`check/verify`也携带该对照；
所有内容落实仍标为未验证，实际声画检查见[分镜落实与精剪](editorial-conform.md)。
`render` 按剪辑单切段、静帧按运镜出画、同场景自动接镜、拼接、混入音效、配音与环境声、烧字幕与画面文字、统一响度，
输出 `剧集/<EP>/制作成果/成片/`。
`verify` 只测量已经渲染出来的成片并回报数字，另列出画面文字、音效与配音在成片里的起止秒、切点亮度变化和疑似坏帧，
供抽帧和回听；不改文件、不给质量结论。

字幕默认由带 libass 的 ffmpeg 烧录。`--subtitles remotion` 换成一条排版可调的
路线，代价是装一次 Node 依赖，而且叠层要**逐帧过无头浏览器**渲整部成片——慢且吃内存，
并发默认压在 2（`--remotion-concurrency` 可调，调高前先量本机）。画面文字只有 Remotion 一条路线：
剪辑单里有画面文字时，无论字幕走哪条路线 render 都需要它，没装就报错并给出安装命令；
走 ffmpeg 的字幕压在画面文字之上。取舍见 [声音、字幕与音乐](sound-and-subtitles.md)，
装法见 [Remotion 叠层](../assets/remotion/README.md)。

`render` 保留中间文件；`声音` 行只记录方案，不驱动处理，也不会按交付规格自动转换视频的画幅或帧率。
需要额外混音、逐镜字幕避让、转场或视频规格转换时，用外部工具完成并记录，再验收实际交付文件。
规格整理、音轨处理、配乐ducking、明确调色与抽帧已有[可选FFmpeg后期工具](ffmpeg-finishing.md)，
从本skill直接调用，不加载另一套剪辑流程或默认改变项目规格。

## 修订

保留未受影响的 `CUT-...` ID。改一段的入出点不触碰其它段；删一段时说明它承担的信息由哪一段
接住，或明确说明这条信息在成片里不再出现。重新渲染前先更新剪辑单，不要让成片领先于文档。

## 完成

每个 `CUT-...` 都绑定真实素材与自洽区间，台词在成片里完整可听，字幕逐字等于剧本原文，
剪辑点没有可听的音床硬切，成片响度落在交付目标上，未采用镜头都写明理由并区分了缺文件与缺质量，
完成技术交付；同时按已选导演方案回看情绪起伏、视觉记忆点、剪接力度与余韵，落实可做的修订。目标时长差、实际采用方案和具体残留写入报告。

## 旧渲染器的色彩匹配与颗粒

### 接镜与色彩一致性

逐段生成的素材曝光各不相同，同一场景里切过去会像闪了一下。`render` 默认在同一场景内自动接镜：
剪辑单里相邻、并经《视频提示词.md》的「分镜」与《分镜.md》的「来源」追到同一场景 ID 的几段为一组，
测量每段的逐通道均值与离散度，各向组内中位数拉近 70%，每个通道只用一个增益和偏移。
它用于减小同场景切点的统计差异；换场、插叙和追不到场景的段不动，实际观感仍须查看。
实际用到的数值列在 render 输出的「自动接镜」里。

自动接镜看的是全画面统计，会受景别、服装面积和背景影响，以下情况在对应 CUT 处理：

- 段内有意的光态变化（关灯、闪回、冷暖对比）写 `- 画面：不校`：这一段不校正，也不计入组内中位数。
- 自动接镜后仍有可见偏差，先按同一光态选脸、衣物或中性表面作基准比较，再写校正。
  写了校正的段只用这里的值，不再自动接镜，也不计入中位数：

```text
- 画面：亮度 +0.06；色温 -6
```

- `亮度`：加法偏移，工具支持 −0.25…+0.25。
- `饱和`：倍数，工具支持 0…2。
- `色温`：工具的冷暖校正量，支持 −30…+30，正数提红压蓝；不是开尔文值。

这些范围是内置工具的处理范围，不是画面质量标准。需要更大或更精细的校正时使用调色工具。
先试小幅校正，再看渲染结果和相同区域的测量。人物身份漂移、错误光源或缺失动作应交回上游。
整集都不要自动接镜时，在交付规格写 `- 接镜匹配：无`。

生成阶段仍应保持已接受的光线和色调；已有素材只差可校正的曝光或白平衡时，优先评估后期修正。

### 颗粒

项目需要时，在交付规格写 `- 颗粒：6`；不写或写「无」就不加。
内置工具支持 0–20 的动态噪点强度，在拼接后对整片统一应用。
这是一种可选质感处理，不保证产生胶片效果，也不能修复身份、动作和光线错误。
需要按场景区别处理时，使用外部调色工具并记录决定。

## 旧渲染器的声音与字幕


## 声音接缝

在相邻镜头拼接后回听底噪、混响、环境声和音乐是否突然变化。
可按需要采用音轨交叉淡入、连续环境底、对白与画面分离或补充音乐。
保留有叙事作用的静默、音效和相对响度。

**内置工具范围**：`edit_tool.py render` 保留素材原声，按 `音效` 行混入指定片段、按 `配音` 行播放
独立声音文件、按 `环境声` 行循环铺底，再对整片做响度标准化；这些声音叠加不会自动压低原声。
CUT 的 `声音` 行是剪辑说明，工具不解析它，不执行静音、交叉淡入、配乐进入或 ducking。
需要这些处理时用 ffmpeg 或剪辑软件另行完成，记录命令或工程及实际输出；完成后再验收。
不能把写下声音方案或 render 成功当成已经混音。

需要执行这些处理时，可按[FFmpeg后期工具](ffmpeg-finishing.md)调用 `audio`；它处理主轨与已选配乐，
不会理解原混音里的谁在说话。仅淡出配乐用 `--music-fade-out`，`--fade-out` 会连对白一起淡出。
接触拟音按文件内真实瞬态对齐动作，不按音频文件零点盲挂；重编码后在最终文件复查，不复制统一延迟补偿值。

## 响度

两遍测量不保证归一化后恰好达到目标。线性增益会超过峰值或动态范围目标时，
`loudnorm` 会退回动态处理；短片和稀疏音效仍需测量编码后的实际 LUFS 与真峰。
内置归一化输出使用 48 kHz，避免动态处理的内部升采样直接决定 AAC 采样率。
不达标时按声音设计通过外部工具处理瞬态、限幅或混音，再核对成片；不要把目标值当实测值。

## 台词与时间

先在源素材上定位发声区间，再在成片上逐句回听，核对留下的台词完整、可辨。
转写可以辅助查漏和定位，最终文字按剧本核对，识别有出入时回听确认。

重出素材会改变发声位置，应重测相关字幕时间并更新剪辑单。
`check` 会提示素材比剪辑单新；这个时间戳检查不能证明字幕已经重新对齐。

## 字幕

新任务优先把 `assets/后期配置.json` 复制到剧集目录并按[字幕设计](editorial-intent.md#字幕作为画面设计)选样式。`subtitle_timing:"exact"` 保留每条 cue 的文字与起止时间，长句用同一时窗内的排版处理；FFmpeg/ASS 路线读取 `subtitles` 样式与逐 cue 覆盖。没有配置文件的既有工程继续走下面的旧版显示规则。

竖屏短剧默认硬字幕，服从用户的字幕选择。
字幕文字逐字取自《剧本.md》，剪辑单照抄剧本标点。转写仅辅助定位，不覆盖原文。
render 烧录时按 GY/T 288 与短剧惯例改写显示形式：去掉句末标点，保留 `？` `！`，
句中的 `，。、；：` 换成全角空格；`字幕.srt` 用的也是这一形式。`check` 忽略标点与空白检查字幕
是否出现在剧本中，逐字及标点是否照抄仍须对照原文核对。

- 字幕一行显示。超过 12 个字的句子，render 在句中停顿处拆成先后显示的几条，
  按字数分配这句的时间；没有停顿的长短语按字数均分。重点词不会被拆到两条里。
- 一镜有多句时使用 `字幕 1`、`字幕 2` 等编号，每句给出时间。
- 字幕时间相对本 CUT 的入点，不相对源素材起点；从本段内开始，可以跨切点延续，但不得越过
  成片结尾或与其他字幕重叠。
- 累计成片位置使用渲染后各段的实际时长，避免帧边界取整产生漂移。
- 抽帧检查字号、折行、安全区和画内文字遮挡。

两条路线用同一套尺寸：字高为画面高度的 4.3%，深色描边 0.42%，基线在距底边约 24% 处，
避开平台自己的底部界面；字色按来源区分，重点词标黄。内置 ffmpeg 路线用实际画幅作为 ASS PlayRes，
字号按该画幅像素计算；它采用全片统一样式，CUT 的字幕行不支持位置指令。需要逐镜避让或更复杂排版时，
用外部字幕编辑器或修改 Remotion 字幕层，并对输出抽帧检查。

### 渲染路线

| 路线 | 适用范围 | 开销 |
|---|---|---|
| `ffmpeg`（默认） | 本机的思源黑体粗体，描边与颜色同上 | 需要带 libass 的 ffmpeg |
| `remotion` | 思源黑体 Heavy（随叠层安装），描边压在字下、入场弹出、重点词 120 ms 放大 | Node 依赖，逐帧浏览器渲染；并发默认 2 |

Remotion 安装与样式调整见 [Remotion 叠层](../assets/remotion/README.md)。
两条路线都要在实际成片上检查字幕。

## 响度与时间线音乐

在剪辑单写交付响度；混音完成后对整片标准化并测量输出。
同时回听对白与环境的相对关系，整片响度达标不代表各句都清楚。

时间线音乐按已接受意图选择进入、退出、循环与对白压低区间。
素材不足时回生产阶段补齐；具体混音通过外部工具执行，并在剪辑单留下可复现记录。
