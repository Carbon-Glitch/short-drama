# 精剪与后期精修

剪辑与后期任务读取本页，主动组织情绪、节奏、声音、调色与转场；
新工程的实际区间、处理与样式写入 film.html/VTT/镜头页；剪辑单自动派生。未迁移旧工程仍用原剪辑单。

## 先划可用带，再选入出点

完整看听候选素材一次，记录实际可用区间及缺陷：等待、曝光漂移、持物变化、重复表演、口型错位、
环境声断裂或画面坏帧。可用带是素材事实，入出点是叙事选择，不能用计划时长代替。

素材职责完整但偏长，先裁掉无效等待；职责缺失才补镜或回上游修订。画坏声好时，可以保留有效声音并
寻找真实画面覆盖；不能用静帧、随机插图或冻结帧掩盖丢失的反应和动作。

## 六遍精剪

1. **故事剪**：因果、信息释放、选择、后果、集尾交接是否完整；
2. **表演剪**：主动者、听者反应、重音、停顿、打断和话后余韵是否成立；
3. **节奏剪**：进入、退出、动作切、反应延迟、重复和声音桥是否改变观众注意；
4. **声音剪**：对白清晰度、声源位置、空间连续、有效静默、拟音和音乐让路；
5. **连续性剪**：人物、道具、轴线、视线、光态、色彩、画内文字和字幕；
6. **交付精修**：画幅、帧率、响度、峰值、坏帧、字幕、安全区和目标播放面。

每遍可聚焦一类问题，修改后重看整体视觉与表演，避免局部正确破坏整体。若发现缺少剧情事实、表演或镜头边界，交回对应 owner，不在剪辑单里偷偷补写。

## 切点方法

| 观众正在获得什么 | 可选方法 | 必须保住 |
|---|---|---|
| 听者先处理关键词 | L-cut，声音继续而画面切到听者 | 触发词、反应起点、完整发声 |
| 下个空间的声音先出现 | J-cut 或声音桥 | 时空归属、知情边界 |
| 动作跨镜继续 | 动作切 | 接触、方向、速度、后果 |
| 物件或视线承担线索 | 插入镜或反应镜 | 观众读懂因果，不添随机信息 |
| 关系改变但台词表面没变 | 按视线、距离、占位或反应切换 | 潜台词和表演落点 |

主动尝试J/L cut、动作/图形匹配、跳切、交叉剪辑、蒙太奇和运动转场，为关键段落构成鲜明的声画节奏。以实际观看比较哪种剪法最有情绪力量。
笑点、反转和关键回应后的反应属于兑现，不要为了压时长一起删掉。

## 改声音也会改画面职责

更换或移动对白后，检查受它驱动的口型、屏幕发声、机械反馈和人物反应。可编辑层按最终声音重定时；已烘焙动作则选新源窗、换覆盖或定向重生成。保持音色与保持完整表演分别判断。回看确认刺激、回应、兑现共同成立，不只看轨道对齐。

## 声音与音乐

先确定声源、距离、听者和叙事功能，再决定是否补音、撤音乐或保留静默。对白、环境、拟音、设计音和
音乐共同组织听觉层次。主动设计声源距离、频段/动态对比、音乐进入、骤停、击点与尾音，让声音塑造期待和释放。

独立对白或环境声可以跨切点形成声音桥；混音完成后再测量响度并回听对白与环境的相对关系。响度达标
不代表对白清楚，写下声音方案也不代表已经混音。

## 色彩与画面精修

先比较同场同光态中的脸、衣物和中性表面，再做曝光、白平衡和肤色校正。不要用全画面平均值强行拉齐
不同景别或有意光态变化。主动以创意调色塑造情绪、触感、空间、美感与风格记忆，使色彩在整场中发展。

按[成像风格](../../short-drama/references/image-look-and-finishing.md)统筹光学观感、局部注意、纹理、时间稳定性和声音空间；用[工程执行](look-execution.md)落实所选处理。

## 最终回看

导出后以正常速度、目标画幅和目标音量观看/回听：观众何时知道答案，谁在承受后果，听者是否真正接住，
切点是否推进，音乐是否帮助而非遮盖，最后一个反应和余韵是否完整。问题按时间码修订当前工程并重新渲染；
技术检测只支持技术结论，不能代替审美验收。
