# 在现有工程落实 Look

先读默认的成像风格知识，按实际素材决定场景共同 Look 与单镜变化。后期处理归当前 OpenFilm 工程，生成端已经完成的效果根据素材保留或调整。

## 可执行承载

- 普通色彩和画面属性写入 clip.style；用当前 native fields 补丁修改，保留已有构图与人工设置。
- OpenFilm 0.4.1 的视频 clip 可用 `--of-lut: url(looks/scene.cube)`，也支持其 SPEC 中声明的 CTF/CLF 色彩转换。使用真实文件与正确的输入/输出约定。图片和页面的 LUT 操作范围与视频不同，按安装版本 SPEC 核对。
- 亮度、对比、饱和度、模糊等可用当前原生 CSS/效果能力；物理扩散、bloom、halation 与均匀模糊是不同外观，按实际预览判断实现是否达到目标。
- 颗粒、复杂局部效果或光学模拟需落成实际可 seek 的图层/镜头页或已验证的逐素材处理。现有迁移器对未映射 grade/effects 会逐项报告，不能据旧版自动处理描述推断新工程已经完成。
- 同一处理选择一个执行位置；源素材、工程 Look 和最终输出分别可追溯。

## 执行顺序

识别输入色彩状态 → 调整必要曝光/白平衡 → 场景 Look → 有意的单镜局部变化 → 纹理/效果 → 输出色彩与编码。保持肤色、细节与相邻镜的共同世界，同时允许明确的动态光态变化。

在工程中记录实际参数和所用文件，先比较代表帧及运动片段，再正式输出。输入、LUT 和引用页进入现有版本快照；输出后以正常速度检查高光、暗部、纹理、运动与声音。
