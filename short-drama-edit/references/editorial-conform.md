# 分镜落实与精剪

有已生成素材、需要选镜精剪或检查“是否真正照分镜拍出来”时读取。事实与采用写入当前film.html及绑定，
不新建另一套剧情/镜头真相。

## 先选表演，再选漂亮画面

按同一个 `SHOT` 的真实剧情拍点比较已有候选：人物是在试探、拒绝、掩饰还是决定？听者有没有接住刺激？
手物接触、目光、声音和相邻镜的状态是否可信？画面精美但没有完成职责的素材不能靠调色胜出。

先在可用带内找完整表演单元，再选择叙事入出点；必要时可以跨候选取不同区间，但接缝不能让策略、
持物、声线或空间无原因跳变。重出素材后重新定位相关发声/动作/反应，不沿用旧秒数。

## ID、采用源窗、成片体验是三层证据

1. **引用对账**：`CUT → MOTION → SHOT → 场景`。每个分镜镜头有去向；有意不拍/不用写明理由。
2. **采用源窗**：从实际素材的 `[入点,出点)` 看听，是否保住该镜职责、完整对白、动作接触、选择及后果？
3. **相邻成片**：从上一镜的预期看到下一镜的反应，答案、笑点、权力转向与余韵是否在正确时刻落下？

第一层可以由脚本核对；后两层必须看听。字幕逐字正确不能证明真实声音完整，引用正确的素材也不能证明
剪进了它的关键部分。未看到的维度写未验证。

例如：素材0.8秒锁扣、1.2秒她误解、2.6秒他回头；采用1.6–3.2秒虽然 `SHOT` 正确，却丢掉锁扣与误解。
先扩大源窗、换已有覆盖或保留可验证的声音桥；缺少唯一因果证据时补拍或回上游，不用whoosh/叠化遮过去。

## 时钟和分镜对照

```text
python <skill>/scripts/edit_tool.py conform <剧集/EP001> --project-root <project>
```

这是只读的计划对照：输出每个CUT的源入出点、按渲染帧率取整的成片入出点、来源SHOT、场景、分镜职责与
可选的“剪辑意图”，列出缺少落点/未采用/断开的引用。`check` 和 `verify` 也携带此对照。
镜序重排或非连续复用会给出提示供核对取舍，不将非线性剪辑自动判错。
未提供分镜时照常输出可解析来源，并明确无法做完整分镜核对。

生成请求时长、素材实际时长、采用源窗和成片时钟不同。外部重排、变速、插入、叠化或转场重叠后必须更新
当前剪辑单/实际工程并重新定位；不能把旧对照当作外部新出口的真实时码。该报告不自动判定表演完成、口型
正确或艺术效果通过，也不禁止有理由的非线性剪辑。

## 精确处理重要剪口

对可疑剪口，查看前后一个完整动作/交流，再加密到局部影格条和波形：

- 眼睛要转向谁？前镜的注意中心在后镜哪里被接住？
- 接触、受力、速度、身体朝向与持物有没有重置？
- 句中切换、尾辅音、呼吸和房间底声有没有被切断或重复？
- 反应过早是否泄露答案，过晚是否让人物显得没有听见？

不要全片机械逐帧看，也不要统一裁去所有头尾等待。人物仍在判断、压住回答或承受结果时，停顿可能就是戏。
比较替代剪法时先保持其他变量不变，再在正常速度声画联合播放下采用。

预期差段落另看：观众有没有机会形成预测，新信息何时使它失效，旧细节怎样获得第二意义，结果落在谁身上。
揭示后用于理解和反应的时间不等于拖尾；重复讲谜底也不等于兑现。先删重复解释、调整并发信息和无效等待，
不要先用全片加速/密切镜补节奏。实际掉点、回看或“太拖/没懂”的评论只定位疑点；结合版本、受众和入口
判断理解、价值或执行问题，不用一条曲线直接证明某镜头必须删。

## 后期围绕已锁的剪辑工作

关键事件和时钟稳定后，再做对白编辑、环境/拟音/音乐、色彩匹配、创意look、图形字幕与最终母版。
可以提前用代理音轨或风格帧试效果，但时间线改变后重新对齐真实声音与文字。
终混前检查原声已有的音乐/效果，避免重复；混合原声不假称独立对白stem。
调色先处理可比区域的曝光/白平衡与颜色空间，再塑造look，不以套LUT或堆转场表示高级。

技术执行按需读取[FFmpeg后期工具](ffmpeg-finishing.md)；叙事判断仍使用[剪辑决策库](editing-decision-library.md)
和[声音导演](sound-narrative-and-music.md)。
