# 短剧剪辑与成片

## 目标与输入

先看素材里谁先变了。台词还没说完，听者的笑已经收住，这一刀就可能属于听者；两人在同一画面里更有劲，就让镜头继续。开篇第一刀敢于砍掉多余起势、从最抓人的动作或声画瞬态切入，按实际表演和呼吸节奏选剪点。
读当前工程与[剪辑意图](references/editorial-intent.md)；精修查[精剪手艺](references/finishing-craft.md)，声音任务查[声音与音乐](references/sound-narrative-and-music.md)。

## 一份后期主稿

新项目使用 `film.html`、引用的 VTT 与镜头页。Studio 与当前 Agent 修改同一份工程；`剪辑单.md` 自动生成供阅读。剧本、视觉设定、分镜及两份提示词继续拥有前期创作事实。

1. 完整制作先按设计阶段 `inspect` 接续分镜与实际资产图缺口；读五份前期文件中与本次剪辑有关的职责，观察实际素材、真实对白和动作窗口。听不了时用已有语音时间、波形与能量辅助，明确仍需回听的判断。
2. 承接分镜「生成安排／接镜」与真实出口记录，区分自然切镜、动作匹配、同镜续段与有意转场。从表演选源窗、镜序和听者反应，写稳定 CUT ID、SHOT/MOTION 来源与取舍。重要对白、接触、揭示和兑现绑定真实源区间。
3. 在工程中安排独立声音、J/L cut、BGM 与逐句字幕，明确演员原声、现场声、旁白、音乐与静默各自承担什么；同时统筹**镜间影调匹配（LUT/色彩过渡与黑位平衡）、成片质感微调，以及贴合全片审美的字幕排版与镜头页图形风格**，让后期收束把成片的影视完成度再往上托一层。音乐按情绪选真实曲段，关键反应前给停顿、呼吸和接触声留位置。
4. 打开短剧创作台精修。每轮先读当前版本，写清本轮变化与冻结部分；保留人工样式、锁定轨道和已经成立的声音/字幕关系，独立设计的错位照常保留。
5. 自由试剪并连续预览，检查开场抓力、对白、反应、声音归属、镜间色彩统一、音乐和字幕。关键兑现按[剪辑决策库](references/editing-decision-library.md)比较真正不同的声画版本：同镜持续/切出、先证据/先反应、原声连续/主动静默、保留过程/省略过程等，沿观看承诺与情绪力量选择，不把平均切镜、机械踩点或“更顺”当默认答案。保留前期选中的表达机制；若剪辑发现更强方案，直接在当前工程中试剪并记录取舍，不用安全常规磨平设计。
   预览自动附带接点回看页；先正常速度看接点前后，再按需逐帧定位重复/冻帧、动作重启、光色跳变或声音台阶。优先调整源窗、覆盖、调色匹配与声画对齐，表演或身份缺失再回生产。交付前用 `handoff` 对照前期事项，`bind-handoff` 指向实际承载层；有意省略写明创作理由。工具跟踪缺项和上游变化，OpenFilm 只渲染一次正式版。

## 采用与声画返修

换完一句配音，回到那一拍：嘴什么时候合上，屏幕何时熄下去，听者的表情有没有抢在关键词前面？变速或改剪点同样回看。关键兑现用实际源时间窗和观察简记，复用 events/制作记录；`handoff` 只证明有承载层，不证明事件被看见。找不到有效源窗就补覆盖或返修该段。先完成可观察修复，缺听感证据时交待验收预览。

## 执行

从本技能目录相对调用：

```sh
python scripts/edit_tool.py init <剧集目录>
python scripts/edit_tool.py open <剧集目录>
python scripts/edit_tool.py plan <剧集目录>
python scripts/edit_tool.py preview <剧集目录>
python scripts/edit_tool.py render <剧集目录>
python scripts/edit_tool.py verify <剧集目录>
```

首个真实剪辑用 seed JSON 初始化，后续使用带版本的补丁。大胆决定剪法、转场、声音与后期质感统合，把交接对账交给工具；字段、素材更新、音频处理与迁移见[工程接口](references/openfilm-workflow.md)。初始化/打开时自动部署固定版本的隔离 OpenFilm 运行时；基础与可选依赖见[运行时依赖](references/runtime-dependencies.md)。

素材生产仍由 $short-drama-produce 和项目已配置的 Seedance 2.5 / MiniMax H3 / imagegen 等路线负责。当前 Agent 做写作、分析与审美判断；素材测量、节拍、波形与音频处理复用本地 helper。OpenFilm 独占新工程的预览和最终混音/渲染。

旧项目没有 film.html 时保持原执行路线。用户选择迁移后，导入独立副本；旧格式按需读[旧工程工作流](references/legacy-edit-workflow.md)。复杂图形转成可编辑镜头页，特殊效果注明实际保留范围。
