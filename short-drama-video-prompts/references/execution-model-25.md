# Seedance 2.5 执行模型：写每个 CLIP 前必读

> 依据：Ksr 课程公开配套包的 seedance_25_execution_model / v8_structure_template / iteration_manual，
> 与即梦/TapTV 头部创作者公开画布提示词（70 条样本）交叉验证，并结合 2026 年下半年 2.5 实战规律校准。
> 本文件是 2.5 与 2.0 执行差异的规律总结，不是问题清单。目标档案为 `target_video_model: seedance-2.5` 时，
> 正文按本模型写；本文件不适用于 2.0、H3、Wan。

## 0. 核心认知：把执行判断与视觉护栏写清楚

本组课程与样本显示，2.5 常比 2.0 更直接地执行字面指令，且对开篇确立的视觉基调、光学性格与排他护栏高度敏感。
实际表现随平台、任务、素材和版本变化，以下写法用于减少歧义，提升成片高级感与可控性。

| 维度 | 本组样本与 2.5 实战提供的写作启发 |
|---|---|
| 视觉护栏 | 只写“好看/真实”仍易滑向均质平光与塑料感；开篇用具体光学/画材介质与针对性排斥项（如拒绝对称大平光、塑料CG反光）立住格调 |
| 抽象词 | 只写情绪名时，表演可能空泛或过度；重要反应宜补可见动作或克制停顿 |
| 环境 | 画面容易死时，检查是否缺少与主体或光影变动有关的环境运动 |
| 光照 | 人物与环境脱节或画面显廉价时，检查光源是否局部合理衰减、暗部是否保留纹理、色温是否染脏全片 |
| 字数 | 长文本可容纳更多信息，但平台 text 上限不同；按目标平台控制长度，字符优先给全局基调、动作、运镜、光影变化和时机 |
| 结果 | 细节越具体，越要检查是否装得下、是否互相冲突 |

写得多不是目标。优先写本镜需要看见、听见和接续的事实；导演解释与情绪目的留在正文外，
执行文本只保留能指导画面、光影质感与声音的内容。

## 1. 情绪→可见表演（按镜头需要，兼顾克制留白）

情绪名可以帮助导演统一意图，但重要反应若只写情绪名，模型可能给出不合适或过度的表演。
根据景别、人物和镜头目的，把需要观众读懂的部分落成少量可见动作——**同时谨防在每一拍硬塞过多肌肉动作造成“演得太用力”；该静默凝视或留半拍呼吸时，稳住重心与视线比抖眉毛更有力量。**

| 抽象意图 | 可选的可见实现 |
|---|---|
| 微微一笑 | 嘴角轻抬后回落，随后接入下一动作 |
| 愤怒 | 眉骨下压、下颌咬紧、颈部肌肉绷起、双手攥拳 |
| 悲伤 | 眼睑下垂、嘴角轻微下拉、喉结吞咽、双肩内卷 |
| 犹豫 | 视线左右各看一眼、嘴唇微张无声、右脚半步探出又停住 |
| 轻蔑 | 下巴轻抬、单侧嘴角下拉、呼气时鼻翼张开 |
| 紧张 | 喉结滚动、手指蜷起又松开、重心移到左脚 |
| 恐惧 | 双眼睁大、鼻翼张开、躯干后倾、手势停在半空 |
| 惊讶 | 眉毛上挑、嘴微张、身体轻微后仰 |
| 疲惫 | 双肩塌下、眼睑半垂、张嘴呼气、脊柱轻微前弯 |
| 警惕 | 头转向声源、双肩端平、呼吸浅而快 |

这些只是候选，不需要数值化毫米或角度，也不要求每个角色在每个时间段都展示全部通道。
关键动作之间保留接收、反应和停顿的空间；需要连续行动时再明确下一动作。

> 公开样本中的表演百分比可保留为导演标注；执行文本按镜头需要选择眉心、鼻翼、下巴、
> 呼吸或身体动作来承载，不把百分比当成模型能直接执行的强度参数。

## 2. 全身动力学链（按动作需要选写）

动作僵硬或只动一个部位时，检查这条动作链还缺什么：

1. **主动件**：完成核心动作的部位；
2. **稳定件**：维持平衡的部位，如重心腿和核心；
3. **补偿件**：自然联动的部位，如肩膀跟转、手臂跟摆；
4. **不自主反应**：呼吸、眨眼、重心微移、衣物随动。

例如转头可以写颈部转动、重心稳定、肩部轻随和一次眨眼；走路可以写迈步、蹬地、手臂摆动和衣角落差。
静止人物是否需要重心、呼吸或微晃，由镜头职责决定；近景表演和长时间停留可写，短暂插入或信息不需要时不凑齐。
这些用于补足可见动作，不要求每个角色在每个时间段都有完整的四层描述。

## 3. 环境动态系统（服务主体，把光影也当成动态事件）

画面死、人物与环境分离时，可从下列元素中选择与动作、空间或情绪有关的动态：

| 类别 | 可选元素 |
|---|---|
| 空气 | 风、灰尘、雾、蒸汽、烟；写影响对象和运动方向 |
| 水 | 涟漪、水滴、积水、倒影；写与脚步或物体的接触 |
| 光影事件 | 火焰、摇曳光斑、移动阴影、门窗开合切入的光带、车灯扫过、云隙破光、光柱中的微粒 |
| 物体 | 布料、旗帜、松动物件、碎屑、植物 |
| 生物 | 飞虫、动物、背景路人、摊主 |
| 温度 | 呼气雾、热气、凝结水珠 |

环境动态与角色动作或情绪拐点交织时最具电影张力（例如推门瞬间的尘埃光带切亮人物半边脸、脚步溅起水花倒映霓虹散开）。
不写固定项数；没有叙事或气氛作用的环境运动可以省略。丁达尔光柱只用于确有光源、粒子且画面需要它的镜头。

## 4. 光照-表面交互与色彩分离（告别均质平光与脏滤镜）

人物与环境颜色脱节或质感显塑料时，补充实际光源怎样有层次地落到主体：

- **光源动机与局部衰减**：主光源来自画内或画外哪里，照到哪个部位、光线如何随距离衰减（避免所有角落均匀一样亮）；
- **色阶与色温分离**：避免给整段视频泼上一层统一发黄或发青的廉价滤镜；让暖光源只停留在受光面附近，使木器、织物、肤色、金属各自守住干净分明的明度层级；
- **暗部与高光宽容度**：暗调戏写明暗部保留可辨纹理与层次（不死黑糊团），亮调戏写明高光柔和自然过渡（不惨白溢出）；
- **反射、阴影与轮廓分离**：地面、墙壁或水面的反射光如何随动作游移，阴影由什么结构投向哪里，多光源色温怎样碰撞，以及背光时是否用窄轮廓光将主体从背景中剥离。

同时考虑材质物理响应：湿石反光强，干石偏哑光，金属有窄亮边高光，布料呈现自然织纹漫反射，皮肤保留微细肌理与自然光泽。按当前景别选择能看清的内容，不为每个角色机械填写全部项目。

## 5. 画面层次与构图张力（按叙事需要组织）

前景遮挡、中景主体、背景层次、负空间留白与空气层是塑造高级感的关键工具，用于打破扁平居中站桩，检查主体是否吸睛、空间是否有呼吸、关键动作是否可读。
需要写实质感时，可给相关物体补材质、受光和运动状态；角色踩地、手扶墙、身体靠物时，可写接触面的物理反应。
既敢在需要时用大面积暗部或干净留白压出极简高级感，也不必每层都填满或强加无关天气。

## 6. @Image 声明与写法边界

- 在提示词开头统一声明一次素材：顺序、身份或用途、允许控制和不得控制的范围（**明确区分“身份参考图”“空间参考图”与“风格/影调定调母版图”**）。后文使用稳定角色名，局部动作确需强调素材职责时用自然语言说明，不重复 `@Image` / `@图片` 标签。
- 只列本镜实际使用的素材，避免无关素材干扰人物和空间。
- 区分“面朝左”和“在画面左侧”，并区分人物自身左右与画面左右。
- 抽象比喻能转成可见事实时直接写事实；服装和眼色是否重复描述，按参考图、特写和连续性需要决定。
- 光源写明真实来源；暗部保留细节与轮廓光按主体可读性和风格需求决定。

## 7. 生成前质检（preflight）

写完每个 2.5 提示词后，只检查本镜相关项：

- [ ] 开头是否只声明一次素材，身份/空间/风格母版各职责是否清晰，参考图之间是否争夺构图或运动控制？
- [ ] 全局基调是否立住了成像介质/光学性格、色彩秩序与针对性的防塑料/防均质平光护栏？
- [ ] 景别、机位、视角态度与构图留白是否具有影视张力（没有滑回呆板居中站桩），且能看清本镜信息？
- [ ] 前后景、画面方向、视线目标与人物走位是否可执行，关键动作是否被前景误挡？
- [ ] 固定或移动是否有目的、触发和终点，焦点是否随注意转移，单镜连续与多镜 `硬切` 是否说清楚？
- [ ] 多镜序列是否有节奏层次感（快慢、远近反差），切点两侧的人物侧、机位侧、接触点、出入方向、双手/道具和声音是否相接？
- [ ] 关键情绪是否有当前景别读得到的克制或爆发表演（兼顾停顿余韵），不需要的抽象解释是否已删？
- [ ] 动作僵硬时，是否补足必要的稳定、联动和不自主反应？
- [ ] 环境动态与光线变化是否服务主体和情绪拐点，而不是凑数量？
- [ ] 人物与环境的光照层次、材质反射、色阶分离和接触面是否成立，暗部纹理与高光过渡是否自然？
- [ ] 是否删掉了重复外观与空洞赞美词（如“极致画质/超级好看”），同时保留了真正改变透视、宽容度、画材介质的光学描述与定向防跑偏护栏？
- [ ] BGM、字幕、画内文字、台词和连续性等必要边界是否准确？

## 8. 常见问题修复表（按实际视频的时间点局部返修）

| 问题 | 优先检查 | 局部修复方向 |
|---|---|---|
| 塑料CG感/像廉价网剧 | 开篇基调护栏、光照与材质肌理 | 顶部补明确成像载体与“无塑料光泽/无均匀平光”护栏，补充肤质/织物微瑕疵与局部光源衰减 |
| 镜头平庸像站桩PPT | 景别反差、构图留白、节奏与运镜 | 拆出远近景别对比、补前景遮挡或视角俯仰，明确硬切点与有呼吸感的时间分布 |
| 掉帧/卡顿 | 运镜幅度、运动模糊和动作复杂度 | 降低手持幅度或动作并发，明确自然运动模糊 |
| 角色复制 | 素材清单和人物数量 | 只保留实际使用的素材，在开头写清实际人物数量 |
| 表情过度/不对 | 情绪名或微表情堆砌过多 | 改为当前景别可读的少数精准肌肉动作，或改用克制凝视与半拍停顿 |
| 动作僵硬像人偶 | 是否只写了一个身体部位 | 补必要的稳定件、补偿件和不自主反应 |
| 画面假/没有活人感 | 环境是否完全静止 | 补与主体有关的环境动态或光线游移 |
| 皮肤与环境颜色不匹配 | 光源是否只写在环境里或全局滤镜过重 | 补局部光源对人物的照射/反射，去掉全片泛染色调 |
| 画面空/元素太少 | 主体和空间层次是否不清 | 按构图需要补前景遮挡、背景纵深或空气层（若刻意留白则强化光影轮廓） |
| 角色与环境无物理交互 | 接触面是否没有反应 | 补脚踩、手扶、倚靠等接触面的形变与接触阴影 |
| 动作被跳过 | 单镜动作是否超载 | 保核心动作，减并发或拆镜 |
| 注意力落错对象 | 景别、景深和焦点是否服务同一信息 | 保留机位，重写焦点起点、触发与终点，或减少竞争动作 |
| 对话空间接不上 | 过肩归属、视线目标与轴线侧 | 分别修人物视线与机位工作侧，不用“保持连续”笼统覆盖 |
| 动作切变成跳状态 | 切点两侧的接触、方向与道具归属 | 让后一镜从同一切点状态继续，或回分镜重定切点 |
| 连续镜头像多次剪切 | 是否只写运镜名而没写实时路径 | 补起止机位、人物走位与遮挡，或明确声明实际 `硬切` |
| 色调不一致 | 光源和色温是否跨镜漂移 | 用共享视觉定调参考图与全局基调统一光源关系 |
| 景别与描述不匹配 | 是否写了镜头拍不到的内容 | 只写当前机位能看见的表演和物体 |
| 比例漂移 | 是否缺相对尺度 | 用已知物件、人物或空间作尺度参照 |

**迭代纪律**：先记录镜号、时间点和实际观察，再判断修文本、素材职责、上游边界还是利用 2.5 区域 `edit` 局部精修；每轮保留已成立部分，只改诊断所需变量，必须联动的变化一起记录。修改多文件时先核对各文件的规则是否仍然一致。
