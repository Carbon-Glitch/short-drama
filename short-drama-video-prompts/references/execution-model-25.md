# Seedance 2.5 执行模型：写每个 CLIP 前必读

> 依据：Ksr 课程公开配套包的 seedance_25_execution_model / v8_structure_template / iteration_manual，
> 与即梦/TapTV 头部创作者公开画布提示词（70 条样本）交叉验证。本文件是 2.5 与 2.0 执行差异的
> 规律总结，不是问题清单。目标档案为 `target_video_model: seedance-2.5` 时，正文按本模型写；
> 本文件不适用于 2.0、H3、Wan。

## 0. 核心认知：把执行判断写清楚

本组课程与样本显示，2.5 常比 2.0 更直接地执行字面指令。实际表现随平台、任务、素材和版本变化，
以下写法用于减少歧义，不是对模型能力的统一断言。

| 维度 | 本组样本提供的写作启发 |
|---|---|
| 抽象词 | 只写情绪名时，表演可能空泛或过度；重要反应宜补可见动作 |
| 环境 | 画面容易死时，检查是否缺少与主体有关的环境运动 |
| 光照 | 人物与环境脱节时，检查光源怎样落到人物和材质上 |
| 字数 | 长文本可容纳更多信息，但平台 text 上限不同；按目标平台控制长度，字符优先给动作、运镜和时机 |
| 结果 | 细节越具体，越要检查是否装得下、是否互相冲突 |

写得多不是目标。优先写本镜需要看见、听见和接续的事实；导演解释与情绪目的留在正文外，
执行文本只保留能指导画面和声音的内容。

## 1. 情绪→可见表演（按镜头需要）

情绪名可以帮助导演统一意图，但重要反应若只写情绪名，模型可能给出不合适或过度的表演。
根据景别、人物和镜头目的，把需要观众读懂的部分落成少量可见动作；不必把每个情绪词都替换掉。

| 抽象意图 | 可选的可见实现 |
|---|---|
| 微微一笑 | 嘴角轻抬后回落，随后接入下一动作 |
| 愤怒 | 眉骨下压、下颌咬紧、颈部肌肉绷起、双手攥拳 |
| 悲伤 | 眼睑下垂、嘴角轻微下拉、喉结吞咽、双肩内卷 |
| 犹豫 | 视线左右各看一眼、嘴唇微张无声、右脚半步探出又停住 |
| 轻蔑 | 下巴轻抬、单侧嘴角下拉、呼气时鼻翼张开 |
| 紧张 | 喉结滚动、手指蜷起又松开、重心移到左脚 |
| 恐惧 | 双眼睁大、鼻翼张开、躯干后倾、手势停在半空 |
| 惊讶 | 眉毛上挑、嘴微张、身体轻微后仰 |
| 疲惫 | 双肩塌下、眼睑半垂、张嘴呼气、脊柱轻微前弯 |
| 警惕 | 头转向声源、双肩端平、呼吸浅而快 |

这些只是候选，不需要数值化毫米或角度，也不要求每个角色在每个时间段都展示全部通道。
关键动作之间保留接收、反应和停顿的空间；需要连续行动时再明确下一动作。

> 公开样本中的表演百分比可保留为导演标注；执行文本按镜头需要选择眉心、鼻翼、下巴、
> 呼吸或身体动作来承载，不把百分比当成模型能直接执行的强度参数。

## 2. 全身动力学链（按动作需要选写）

动作僵硬或只动一个部位时，检查这条动作链还缺什么：

1. **主动件**：完成核心动作的部位；
2. **稳定件**：维持平衡的部位，如重心腿和核心；
3. **补偿件**：自然联动的部位，如肩膀跟转、手臂跟摆；
4. **不自主反应**：呼吸、眨眼、重心微移、衣物随动。

例如转头可以写颈部转动、重心稳定、肩部轻随和一次眨眼；走路可以写迈步、蹬地、手臂摆动和衣角落差。
静止人物是否需要重心、呼吸或微晃，由镜头职责决定；近景表演和长时间停留可写，短暂插入或信息不需要时不凑齐。
这些用于补足可见动作，不要求每个角色在每个时间段都有完整的四层描述。

## 3. 环境动态系统（服务主体，不设数量）

画面死、人物与环境分离时，可从下列元素中选择与动作、空间或气氛有关的动态：

| 类别 | 可选元素 |
|---|---|
| 空气 | 风、灰尘、雾、蒸汽、烟；写影响对象和运动方向 |
| 水 | 涟漪、水滴、积水、倒影；写与脚步或物体的接触 |
| 光 | 火焰、光斑、影子、反射光、光柱中的粒子 |
| 物体 | 布料、旗帜、松动物件、碎屑、植物 |
| 生物 | 飞虫、动物、背景路人、摊主 |
| 温度 | 呼气雾、热气、凝结水珠 |

环境动态与角色动作交织时更有效，例如脚步带起灰尘，灰尘在火光中散开。
不写固定项数；没有叙事或物理作用的环境运动可以省略。丁达尔光柱只用于确有光源、粒子且画面需要它的镜头。

## 4. 光照-表面交互（按可见结果写）

人物与环境颜色脱节时，补充实际光源怎样影响主体：

- 主光源来自哪里，照到哪个部位；
- 地面、墙壁或水面是否有反射光；
- 阴影由什么结构投下，落在哪里；
- 多光源是否形成不同色温区；
- 背光时是否需要轮廓光帮助主体与背景分离。

同时考虑材质：湿石反光强，干石偏哑光，金属有镜面高光，布料多为漫反射。
按当前景别选择能看清的内容，不为每个角色机械填写全部项目。

## 5. 画面层次（按构图需要组织）

前景、中景、背景和空气层是组织画面的可选工具，用于检查主体是否突出、空间是否成立、关键动作是否可读。
需要写实质感时，可给相关物体补材质、受光和运动状态；角色踩地、手扶墙、身体靠物时，可写接触面的物理反应。
不必每层都填满，也不必为“空气有内容”添加无关颗粒或天气。

## 6. @Image 声明与写法边界

- 在提示词开头统一声明一次素材：顺序、身份或用途、允许控制和不得控制的范围。后文使用稳定角色名，
  局部动作确需强调素材职责时用自然语言说明，不重复 @Image 标签。
- 只列本镜实际使用的素材，避免无关素材干扰人物和空间。
- 区分“面朝左”和“在画面左侧”，并区分人物自身左右与画面左右。
- 抽象比喻能转成可见事实时直接写事实；服装和眼色是否重复描述，按参考图、特写和连续性需要决定。
- 光源写明真实来源；暗部是否保留细节、是否加轮廓光，按主体可读性决定。

## 7. 生成前质检（preflight）

写完每个 2.5 提示词后，只检查本镜相关项：

- [ ] 开头是否只声明一次素材，职责、继承范围和顺序是否明确，参考图之间是否争夺构图或运动控制？
- [ ] 景别能否看清本镜信息，机位、水平角度、高度、视点和轴线工作侧是否被混为一谈？
- [ ] 前后景、画面方向、视线目标与人物走位是否可执行，关键动作是否被前景遮挡？
- [ ] 固定或移动是否有目的、触发和终点，焦点是否随注意转移，单镜连续与多镜切分是否说清楚？
- [ ] 切点两侧的人物侧、机位侧、接触点、出入方向、双手/道具和声音是否相接？
- [ ] 关键情绪是否有当前景别读得到的表演，不需要的抽象解释是否已删？
- [ ] 动作僵硬时，是否补足必要的稳定、联动和不自主反应？
- [ ] 环境动态是否服务主体，而不是为了数量添加？
- [ ] 人物与环境的光照、材质和接触面是否成立，实际光源能否支持要读到的信息？
- [ ] 是否删掉了重复外观、空泛质感词、无用途的器材/胶片/色温参数与通用负向清单？
- [ ] BGM、字幕、画内文字、台词和连续性等必要边界是否准确？

## 8. 常见问题修复表（按实际视频的时间点局部返修）

| 问题 | 优先检查 | 局部修复方向 |
|---|---|---|
| 掉帧/卡顿 | 运镜幅度、运动模糊和动作复杂度 | 降低手持幅度或动作并发，明确自然运动模糊 |
| 角色复制 | 素材清单和人物数量 | 只保留实际使用的素材，在开头写清实际人物数量 |
| 表情过度/不对 | 情绪名是否承担了全部表演 | 改为当前景别可读的肌肉和身体动作 |
| 动作僵硬像人偶 | 是否只写了一个身体部位 | 补必要的稳定件、补偿件和不自主反应 |
| 画面假/没有活人感 | 环境是否完全静止 | 补与主体有关的环境动态 |
| 皮肤与环境颜色不匹配 | 光源是否只写在环境里 | 补光源到人物部位的照射、反射和阴影 |
| 画面空/元素太少 | 主体和空间层次是否不清 | 按构图需要补前景、背景或空气层 |
| 角色与环境无物理交互 | 接触面是否没有反应 | 补脚踩、手扶、倚靠等接触面的变化 |
| 动作被跳过 | 单镜动作是否超载 | 保核心动作，减并发或拆镜 |
| 注意力落错对象 | 景别、景深和焦点是否服务同一信息 | 保留机位，重写焦点起点、触发与终点，或减少竞争动作 |
| 对话空间接不上 | 过肩归属、视线目标与轴线侧 | 分别修人物视线与机位工作侧，不用“保持连续”笼统覆盖 |
| 动作切变成跳状态 | 切点两侧的接触、方向与道具归属 | 让后一镜从同一切点状态继续，或回分镜重定切点 |
| 连续镜头像多次剪切 | 是否只写运镜名而没写实时路径 | 补起止机位、人物走位与遮挡，或明确声明实际切镜 |
| 色调不一致 | 光源和色温是否跨镜漂移 | 用共享光影风格卡统一实际光源关系 |
| 景别与描述不匹配 | 是否写了镜头拍不到的内容 | 只写当前机位能看见的表演和物体 |
| 比例漂移 | 是否缺相对尺度 | 用已知物件、人物或空间作尺度参照 |

**迭代纪律**：先记录镜号、时间点和实际观察，再判断修文本、素材职责、上游边界还是后期；每轮保留已成立
部分，只改诊断所需变量，必须联动的变化一起记录。修改多文件时先核对各文件的规则是否仍然一致。
