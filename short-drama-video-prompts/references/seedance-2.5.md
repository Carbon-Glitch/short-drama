# Seedance 2.5 提示词方言

只在目标档案明确写 `target_video_model: seedance-2.5` 时使用。推荐档案：

```json
{
  "target_video_model": "seedance-2.5",
  "video_prompt_dialect": "seedance-2.5",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 4, "max": 30},
  "supported_generation_modes": ["text", "reference", "edit", "extend"],
  "audio_generation": "same_pass"
}
```

2.5 沿用中文自然指令和 @图片N、@视频N、@音频N 绑定，但不能直接套 2.0：它支持 30 秒长叙事、
整数秒时间戳控制与显式硬切，以及明确的参考、编辑、延长三类全模态任务。

## 生成与参考

单镜先在顶部定准视觉基调与防跑偏护栏，再写镜头职责对应的构图、调度与动作，最后补光影变化、声音和必要约束，不机械凑齐无用栏目。
单镜内部的动作时机先写清先后与触发；散文秒数不保证精确落点。
多镜或长叙事按 镜头 1 [0:00–0:03]： 写时间段，并在切换处明确标注 硬切（或切镜方式），不重叠、不留无意空档，最后终点等于总时长。时间戳仍有生成偏差，不能作为音节同步或精确剪辑点的保证。
在提示词开头统一声明一次 @图片1、@视频1 等具体职责，区分身份参考、空间参考、风格/影调母版、动作/运镜预演参考（含 3D 灰模/火柴人参考）。后文使用稳定名称指代；局部动作确需强调素材职责时用自然语言说明，不重复 @图片N 标签。普通参考任务说明保留和借用什么，不让一个素材顺手控制身份、动作、构图等所有维度。
多镜容器使用一份参考清单，各镜的 @图片N 重新映射到这份清单，不能照抄独立生成时的编号。
多镜容器不自动保证跨镜一致性。按当前参考输入检查结果，不把对照观察变成禁用规则；
见[OBS-SD25-CONTAINER](model-observations.md#obs-sd25-container)。
多镜容器包含切口；一镜到底是连续画面。按叙事目的与节奏吸引选择，并保留生成后剪辑的余地。

### 反应镜：保留可见反应链（craft_default）

可先试触发 → 人物处理 → 当前景别读得到的可见反应（或极克制的半拍停顿）→ 落点，不套用 H3 的反应配方。
仍按角色立场与镜头目的选动作，生成后核对可读性与自然度；小样本见[OBS-SD25-REACTION](model-observations.md#obs-sd25-reaction)。

### 两端都锚：用途：起始帧 与 用途：结束帧

接口提供 first_frame 与 last_frame 两个位置，各自只收一张。
终点状态或极致末帧构图重要时可增加尾帧约束，仍需检查生成后的中间动作与节奏。
按分镜已接受的终点制作尾帧并绑定 用途：结束帧；未提供尾帧时在正文中说明终点。
开场构图与影调要一次锁住时先试 first_frame，不要只在参考模式里写「@图片1 是开场画面」；
小样本见[OBS-SD25-FIRST-FRAME](model-observations.md#obs-sd25-first-frame)。
[官方接口契约 · BytePlus，2026-11-25] 首尾帧条件与全能参考图片/视频/音频互斥；纯首帧或首尾帧使用 ratio: adaptive。两个帧位各占一个图片序号，按素材出现顺序编号。全能参考正文指定某图作开场不等于 first_frame 条件。其他入口按实际映射核对。
依据：[创建视频任务API](https://docs.byteplus.com/en/docs/modelark/create-video-generation-task-api)。

### 音色参考

目标接口支持 reference_audio 时，可用已接受的角色参考音频辅助约束声音；在本镜写 参考音频，
正文按顺序写音色参考。参考可来自预置音色或已授权录音，选型由视觉设定记录，生成后回听确认。
绑定只用于提高命中，逐镜回听不能省；观察见[OBS-SD25-VOICE](model-observations.md#obs-sd25-voice)。
输入参考图 仍只接受图片，音频单独写在 参考音频 字段。

## 编辑与延长不是普通参考

[官方接口契约] 提示词意图必须与 job 的 omni_reference_task_type 一致；参数依据[2.5官方说明](https://docs.byteplus.com/en/docs/ModelArk/seedance-2-5)：
reference：基于素材生成新视频，写“参考 @视频1 的运镜/动作”或具体素材职责。
edit：直接点名 @视频1，写“保留 A、B，只修改 C”；API 参数为 ratio: adaptive、duration: -1。极其适合在保住好表演和好运镜的前提下，定向升级局部灯光氛围、道具颜色、背景冷暖或微调情绪，避免整段推倒重抽。
extend：写“在 @视频1 的基础上续写 N 秒”，从实际终点描述后续动作过程和新终点；API 使用 ratio: adaptive。
连续创作可另绑实际尾帧为 @图片1，只控制新段开场。需要无缝接下去时可优先试延长，实际接缝仍须观察；
记录见[OBS-SD25-EXTEND](model-observations.md#obs-sd25-extend)。
提示词与 job 的任务类型不一致时可能报不匹配；任务类型是创作选择，不由 adapter 猜。
在 MOTION-... 的 生成方式 后写 - 任务类型：reference | edit | extend：
| 字段 | 回答什么 | 谁决定 |
|---|---|---|
| 生成方式 | 是否送图 | 由「输入参考图」机械推出 |
| 任务类型 | 参考、编辑还是延长 | 创作决定，本套件不推断 |
edit 与 extend 使用视频素材，不一定有图片；现有图片字段不足以表达纯视频输入，准备 job 时核对实际绑定。
目标模型不是 2.5 时不写这一行。

## 对白、声音与文字

可辨对白整体写进 {角色用中文说：“逐字台词”}；对白与音效内嵌在触发它的动作旁，每句逐字台词只出现一次；文末只留一句持续声底，不另抄对白时间线。
音效写进 <声音>，音乐写进 （音乐）；明确开启的字幕才用 【字幕】。
同轨声音按事件闭合；上游明确排除的发声边界在时间线末尾写一次，没有上游边界时不追加固定负面后缀。
默认禁字幕时明确写“全程无字幕、无对白文字叠加”，画内获准文字仍独立说明。
屏幕图形与精确文字按[通用成像配方](../../short-drama-image-prompts/references/common-recipe.md#7-参考文字与定向修改)分工；后期文字不写入生成正文，只正向描写承载面与交互。
两次正式档观察见[OBS-SD25-NOTIFICATION](model-observations.md#obs-sd25-notification)，不外推为普遍失败。

## 连续容器

同镜延续先核对所选入口是否支持 extend，支持时用真实已采用视频承接；需要图片锚点时按该入口允许的参考角色加入，不把 reference_image 与 first_frame 条件混用。前段尚未存在则标为待续接草案，不伪造素材。普通切镜、换机位或时空跳变按[分组与接镜策略](../../short-drama/references/model-aware-coverage-and-joins.md)选择独立生成，不强制第二段全部走 extend。

## 时长

[官方接口契约] Seedance 2.5 手动指定的整数时长是 4–30 秒。项目采用一镜一生成时每镜均落在此区间；采用 30 秒多镜容器时，
按已选执行路线落实成员镜头与时间。段长建议与分组只沿[统一策略](../../short-drama/references/model-aware-coverage-and-joins.md)，本方言不另设默认段长。
对白、VO、OS 同样按 [performance-action-timing.md](performance-action-timing.md) 先预算再排时。
30 秒扩大了可用容量，不代表固定短镜中的长对白会自动恢复自然语速。
普通生成/参考任务支持 duration: -1，由模型在4–30秒内选择。本套件已规划较长clip或固定时长交付时，优先显式传对应正整数；自动时长用于确实交给模型选择的任务，并核对实际返回时长。
edit 的 duration: -1 表示基本保持待编辑视频的时长。换成更长对白时仍须检查原片发声窗口，
不能靠 -1 自动延长；放不下就回上游调整任务或台词，不静默切换为延长。
extend 的时长针对新增片段，预算其中新增对白与过渡，不把原片长度当成新增发声容量。
实际回测需听台词完整性、语速、尾音，并测量媒体真实时长。API 返回的 duration 是按帧数折算后向下
取整的近似秒数；编辑结果也可能与源片略有时长差异，不能只看响应整数就判定逐秒满足要求。

## 影视感提示词：先定视觉基因，再以镜头语言执导

2.5 正文是一份可执行的导演与摄影简报，不是无目标的散文堆砌。先在开头确立全段的视觉基因与审美护栏，再明确每一镜让观众看什么、站在谁的位置看、节奏如何快慢错落，最后落成动作、动态光影、声场和必要约束。镜头职责与创作解释留在 MOTION-... 卡片；可复制正文只保留能被摄影机和麦克风拍录/执行的视听事实。

### 正文路由：先分单镜与多镜容器

一个连续镜头先定视觉基调护栏，再用相对先后组织动作，只有需要按秒对齐时才写秒段：
```text
素材职责（如有）→ 时长/画幅与视觉基因护栏（成像载体/调性/排斥塑料或平光）→
开场构图与调度 → 动作、光影事件与反应 → 摄影机与焦点 → 完整声音 → 必要约束
```

多镜或长叙事容器把共享基因、材质与声音规则放进全局头尾，把景别反差、硬切节奏与变化放进各镜：
```text
素材职责 → 全段规格与全局视觉基调（类型、成像载体、剧组色盘、光比性格与防跑偏护栏）→
逐镜声画过程（对白与音效内嵌触发动作，切镜按分镜）→ 一句持续声底 → 必要约束
```

一镜到底写明连续拍摄及摄影机如何实时到达新位置；多镜容器在每个边界明确写 硬切 及前后构图反差，不混用两种结构。
时间段按已接受镜长划分，连续、不重叠、不留无意空档；善于运用节奏分层（如 1.5–2 秒锐利动作/细节切镜 与 4–6 秒蓄势凝视/推进的对比），切忌把所有镜头拍成均匀的 6～8 秒慢节奏中景。
单镜内的秒数只作节奏计划，不能保证精确剪辑点或音节同步。
每个镜头仍有独立的构图姿态、主变化与终点；不要把多镜容器写成一串只有时间和地点的幻灯片。

### 镜头语言六层：从“拍清楚”升级为“有电影拍法”

写正文前先把分镜的摄影意图翻成下面六层。只写本镜需要控制的层，已由起始帧可靠承载的静态外貌不重复。
| 层 | 要回答的问题 | 可执行写法 |
|---|---|---|
| 景别与构图张力 | 要看清什么？用什么几何占比、前景边框或留白制造气场？ | 偏低机位中近景，前景虚化酒杯边缘占左侧三分之一形成压迫边框，人物偏右留出冷暗负空间 |
| 机位与视点 | 摄影机在哪、朝哪、在轴线哪侧，是客观窥视还是某人主观？ | 丈夫肩后过肩视点，机位压在桌面同高度并守在轴线左侧 |
| 光学与焦段性格 | 要广角空间畸变张力，还是长焦压缩剥离？焦面如何交接？ | 85mm 浅景深将后景宾客虚化成流动暖金光斑；先合焦前景信纸，抬眼瞬间拉焦至她瞳孔 |
| 调度与空间权力 | 谁通过走位、遮挡、进出光区来改变强弱关系？ | 她不动声色将信推过桌面中线；对面阴影中的手臂向前探入光区按住纸角 |
| 摄影机行为 | 为什么动或不动，何时触发，沿什么轨迹，停在何种定格构图？ | 信纸入光区瞬间短促推近并微下摇，停在她未松开的指节与签名极近景 |
| 镜头边界 | 是连续推进还是显式 硬切，切点两侧的动势、视线与声音怎样咬合？ | 右手按定信纸时硬切单人正打近景，下一镜保持同一触碰姿态与背景声底 |
可合并成紧凑的摄影指令，不必写成六个干瘪标签：
```text
丈夫肩后低伏过肩中近景，85mm 浅景深把后景宾客揉成暖金散景，轴线左侧保持不动；
她把信推入光区瞬间镜头短促推近并微下摇，焦点从她眼底稳稳移至按住纸边的指节近景。
```

景别、水平角度、机位高度、焦段是不同选择：仰拍不等于正面，长焦不等于特写。合理利用焦段透视、景深虚实和前景留白能让同一句台词高级十倍。

### 按需调用的专业镜头与节奏机制

| 叙事任务 | 镜头机制 | 正文要写清的执行事实 |
|---|---|---|
| 打破平庸对话站桩 | 过肩遮挡 / 纵深偏置反打 | 前景虚化遮挡归属、人物占画不对称留白、焦点切换与视线落点 |
| 情绪骤然拐弯 | 拉焦揭示 / 极端景别跳切 | 从全景或近景直接 硬切 到手/眼/微物极特写，或焦点由前物锐利移向人物眼底 |
| 用环境表达孤立或压迫 | 负空间构图 / 固定凝视 | 大面积留白或门框/廊柱框中框，明确不动摇的稳定机位与细微空气呼吸 |
| 制造悬念或喜剧错位 | 前景遮挡显露 / 声画错位 | 遮挡物遮住核心信息，声音先行诱导误判，人物移动或移开遮挡才揭破 |
| 增强临场感与抓人冲击 | 贴近跟拍 / 主观 POV / 甩镜衔接 | 明确身体感视线高度或高速跟拍轨迹，不胡乱堆砌无动机晃动 |
| 动作连续与打击力 | 动作切 / 动势匹配 / 节奏变速 | 接触阶段、出入方向、受击后坐力物理反馈，以及快切后接半拍慢放蓄力 |
这些机制按题材与体验选用——轻快幽默短片同样可以通过精准对称构图、利落跳切与声画反讽拍出极强电影感，不局限于暗黑题材。

### 竖屏短剧与短视频的取景补充

9:16 先确认本镜卖点是微表情张力、双手/道具交互、服装造型气场还是纵深空间关系，再分配天地留白与前后景层次。
善用竖屏天然的纵深通道与上下分割（例如前景虚化桌面/门框、中景人物、后景高悬光源或深邃走廊），避免所有人永远挤在大头居中框里。
过肩构图保留远端脸与关键道具即可，前景肩背切勿挤死表演区；正反打分别核对真实朝向，防止视线错位。
参考横屏角色板或分镜板时，只继承已声明的身份/设计，不把原图排版、格线或横屏留白带入竖屏正文。

### 戏型补充：把视觉魅力与因果一起落地

对白戏：别让镜头只是“轮流拍说话的嘴”。把台词拆进空间博弈、视线闪避、动作停顿和听者反应里；明确唯一说话者，防止多人同时动嘴。
喜剧/轻快/脑洞短视频：善用反差构图（一本正经的对称或庄严大景配荒诞小动作）、利落卡点跳切、定格停顿与轻盈的环境声/音效错位，让好笑和爽感来自精准节奏而非浮夸龇牙咧嘴。
动作戏：先建立空间左右站位与距离，再写发力、接触、受力后坐力与位移；用物理惯性和节奏变速制造冲击，不用“镜头乱晃”假装激烈。
悬疑/情绪戏：把“藏”和“露”交给遮挡、虚焦、单向光带、画外声和半拍停顿；反应不必每回都切大特写哭喊，克制的眼神微震或沉默背影往往更抓人。
纪实/手机/POV：拍摄来源决定画质与运动，偶发找焦和轻微手持呼吸服从来源逻辑，不混搭矛盾的电影摇臂或棚拍光。

### 成像基因、光影层次与审美护栏（提升下限的关键）

必须明确区分两类词：
应当删除的空洞废话：没有具体指向的“高级感、电影感、超级震撼、完美无瑕、8K极致清晰”。
必须立住的高级质感锚点（按项目气质在全局头或单镜开篇定死）：
成像载体与光学性格：如真人写实可用 35mm 电影胶片感、细微有机颗粒、变形镜头柔和边缘虚化与柔和高光过渡（或柔和通透的自然胶片色彩科学）；二维/国漫等风格化作品则明确写出手绘墨线、平涂色块与纸面肌理，并明确排除 3D 体积光与塑料渐变；
局部动机布光与色阶分离：光影按**「实际光源方向 → 局部照度衰减与材质受光差异 → 暗部纹理/高光宽容度保护」**写——强调暖/冷色光停留在受光物近旁，绝不往全片泼一层脏污滤镜；暗部保留细节不死黑成团，高光自然滚落不惨白溢出；
针对性防平庸护栏：在全局基调里用简洁一句封住当前题材最易犯的廉价毛病（例如写实片写*“不要 3D 渲染感、不要塑料 CGI 光泽、拒绝均匀大平光”；二维片写“严禁转三维写实、保持平涂线稿秩序”*）。
多镜容器全局基调块保持精炼有力，全段共享项只写一次：
```text
全段：30 秒，9:16，高质感都市悬念短剧；35mm 电影胶片成像，自然有机颗粒，拒绝塑料 CGI 光泽与均匀大平光。
同一暗青冷调宴会厅与旧信道具；室内主调偏冷青灰，唯独吊灯下方形成局促暖金光区，暗部保留深色木纹与丝绒质感，85mm 浅景深带椭圆散景。
声音：同期环境底声、清晰物理音效与精准中文对白，无非画内配乐。
```

### 参考素材：职责、继承与冲突优先级

在开头统一声明一次 @图片N / @视频N / @音频N 的稳定名称、允许控制与不得控制范围：
身份/服装图只锁相貌与衣着，不让它的白底平光、站姿或背景污染视频光影；
空场图只锁空间结构、家具位置与光源朝向，禁止把参考图里的静态构图死板焊死每个镜头；
**风格定调代表图（如有）**负责锁定全片的色彩纯度、明暗对比和光学质感，不强制继承其中的人物动作；
动作/3D 灰模/火柴人参考视频只借运动轨迹、剪辑节奏或复杂走位，明确排除其原始外观；
首尾帧负责起止精准构图，不替代中间动作、焦点变化和声音时序。
镜中倒影、屏幕、遮挡后转身和快速运动等高风险段落，直接说明同一人物在这些时刻的可见连续性，不重复素材标签。

### 声音与时间的专业衔接

音效绑定可见成因和精确时点；画外声标方向/距离，环境底声在连续镜头间接续，善用 J-cut（声音提前半秒入画制造悬念） 或 声音骤抽 放大转折力。
对白逐字文本与音效紧贴触发动作内嵌；每句只出现一次。文末只留一句持续声底，音乐进退和静默放在对应事件处，不另建重复的声音时间线。
音乐是否有、从哪进哪出按项目决定；单镜产物默认同期声与现场声，不把时间线配乐强塞进每个镜头。
声音透视随景别和空间变化：推近时呼吸与纸张摩擦更脆，拉远或隔门时带出空间混响。

### 长度与删减顺序

先核对目标入口当前 text 上限，不把某个第三方入口的 2000 字符限制当成所有 2.5 入口的统一规则，
也不设固定词数目标。正文长度由镜头负载与实际上限决定。
超限时按以下顺序压缩：
删除重复外观、空洞赞美词与超出当前景别的多余微动作；
合并景别、机位、视点、焦点和运镜为一条紧凑摄影指令；
多镜容器把共享的成像基因、色盘光比、防塑料护栏、声音基调移到全段块，只写一次；
保住：全局视觉基因护栏、节奏反差与 硬切、动作起止与物理反馈、焦点转移、视线/轴线、对白、声音事件、连续性锁与必要文字/配乐边界。
不能靠删掉视觉基因或关键终点来凑字数；装不下时回到分镜减负载或拆镜。

### 单镜示例：暗部留白、推光与拉焦（10 秒）

```text
@图片1 = 林晚的身份与黑色丝绒长裙（不继承原图平光与站姿）；@图片2 = 宴会厅木质长桌与吊灯空间；@图片3 = 风格影调母版（仅继承冷青暗调与暖金点光源反差）。
10 秒，9:16，35mm 电影实拍质感，柔和胶片颗粒与自然肤质纹理，拒绝塑料 CGI 光泽与均匀全亮照明。
开场为极克制的低机位过肩中近景，机位守在轴线左侧，前景虚化肩背遮住画面左缘，林晚坐在冷青暗调长桌右半侧，身旁留出大片沉静暗部，85mm 浅景深将后景宾客揉成流动暖金散景。
她不动声色将酒杯稳稳放回暗色桌面，右手从手包抽出泛旧米白信封，顺着桌面唯一一束吊灯暖光推过中线。信封滑入暖光区照亮封口火漆瞬间，镜头短促平滑推进并微下摇，焦点从她沉静的眼睛锐利拉至她仍按住信封边缘的指节极近景，冷蓝窗边轮廓光勾出她指尖发白，桌面木纹在暗处仍清晰可读。
声音：克制的宴会低语与空调底声；<放杯时沉稳一声轻碰>，<信封擦过木桌的清晰沙沙声>后，环境低语骤然退远，只留安静空气与呼吸。无对白，无非画内配乐；全程无字幕、caption 和对白文字叠加。
```

### 多镜容器示例：节奏分层 + 显式硬切 + 声音先导（30 秒）

```text
素材：@图片1 = 林晚身份与黑丝绒礼服；@图片2 = 宴会厅环境空间与桌椅布局（不控制人物动作）；@图片3 = 全片冷青/暖金影调母版。
全段：30 秒，9:16，35mm 电影胶片成像，自然胶片微粒与清晰暗部纹理，拒绝均匀照亮与光滑塑料感；同一晚宴厅与旧信道具，冷青环境暗调与局部吊灯暖光严格分离，无非画内配乐。
镜头 1 [0:00–0:04]：高机位远景俯瞰长桌，冷青色桌面占据大面积负空间，林晚与丈夫隔桌对坐两端形成几何对峙，后景吊灯暖光孤立照亮桌面中央；摄影机静止稳住压迫距离，她缓缓放下酒杯，右手探向手包。
镜头 2 [0:04–0:06.5]：硬切！桌面同高度极近景贴面横拍，泛旧信封从暗部滑入暖金光区停在中央，纸纹与指节压痕清晰锋利。切点保持信封居中与丈夫在画左轴线侧。
镜头 3 [0:06.5–0:14]：硬切！丈夫肩后过肩中近景，前景肩背做暗色边框，林晚缓缓抬眼直视画外丈夫，停顿半拍吸气后肩膀微沉、保持克制不动，镜头以极微弱的速度持续推近至她的眼睛。
镜头 4 [0:14–0:20]：硬切！干净单人近景对准林晚（保持同一轴线视线），她迎着吊灯暖侧光开口完成该句对白，口型自然同步，说完后右手轻轻收回离开信封，目光不闪不避。
镜头 5 [0:20–0:30]：硬切！反打极近景俯拍桌面上孤零零的信封与暗部里丈夫悬停半空的手指——犹豫一秒后，他的指尖慢步探入暖光区稳稳按住信封一角，画面最后定格在这只占据控制权的手与冷青暗部留白上。
声音时间线：0:00–0:06 远处宴会低语与冷气低鸣；<0:03.5 玻璃杯底轻叩桌面>；<0:05 信封摩擦木面清脆声>后环境低语开始退潮；0:06.5–0:14 仅余细微呼吸与安静室音，最后一秒突然抽空环境声留出 0.5 秒极静压迫；0:14–0:19 {林晚用中文克制却清晰地说：“这封信上的字，你还认得吗？”}；0:19–0:30 空调低鸣与手指压上信纸的轻微沙响，无其他人声。
全程无字幕、caption 和对白文字叠加；信纸内容不作可读文字展示。
```

## 生成反馈与局部返修

文本 preflight 通过不等于镜头成立。拿到实际视频后，按镜号和时间点记录可观察问题，区分：
文本实现问题：动作被跳过、机位/焦点不对、节奏太闷、台词缺失、终点未达；只修对应模块。
质感/局部瑕疵问题（优先试 2.5 区域 edit）：运镜和表演已经很棒，仅局部光色过平、背景过亮或小道具不对，直接走 edit 局部锁定重写，不必浪费好表演重抽。
参考输入问题：身份、地理、布局或参考方向互相争夺控制；修对应素材职责或参考图，不在正文重复加锁。
上游边界问题：动作/台词装不下、切点两侧状态矛盾、连续镜头要求不可能的路径；回分镜或写作修订。
后期问题：精确剪辑点、最终调色匹配、字幕与受控屏显按项目交给时间线，不伪称为模型原生结果。
每轮保留已成立部分，只改诊断所需的素材、镜头或声音变量；必须联动的变化一起记录。对比时使用同一镜头、相近设置和可核对时间点，不凭单条成功样片把写法提升为普遍规律。
