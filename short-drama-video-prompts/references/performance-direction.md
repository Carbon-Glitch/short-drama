# 表演导演：从情绪标签到可执行行动

本页是视频提示词与表演调度的默认核心知识，主动发展具体行为、听者反应和人物差异。
它补充 [表演与动作时序](performance-action-timing.md)，不另建表演表，不改剧本事实、人物立场和镜头边界。

## 先确定可演结构

每个真正承担变化的角色，只提取当前镜头需要的内容：

1. **触发**：哪句台词、动作、声音或发现迫使角色处理现在；
2. **现场目标**：角色想从谁那里得到、守住或改变什么；
3. **可执行行动**：他通过什么策略争取，而不是“表现什么情绪”；
4. **接收与阻力**：对方或现场怎样接住、回避、误解或反制；
5. **策略变化**：哪个新信息使旧策略失效，角色改用什么行动；
6. **落点**：哪个选择、反应或关系状态进入下一镜。

情绪可以保留为导演摘要，但不能替代行动。秘密、前史和人物关系沿既定故事；姿态、习惯动作、物品行为和反应方式可主动设计并回填来源。

## 可执行动词库

动词只用于打开方案，不逐镜堆满。先写“谁对谁做什么”，再选择当前景别能读到的行为。

| 戏剧需要 | 候选行动 | 可见执行方式 | 何时不用 |
|---|---|---|---|
| 试探 | test / probe | 故意留半句、给一个可撤回的小事实、观察对方是否接 | 对方已知情且没有新判断 |
| 邀请 | invite | 让出位置、递出选择权、把共同利益说具体 | 实为命令却包装成邀请 |
| 施压 | press | 缩短选项、守住出口、要求对方处理眼前事实 | 只靠提高音量或逼近 |
| 挑战 | challenge | 指出对方陈述与证据的具体矛盾，要求其回应 | 没有可核对筹码 |
| 争取同盟 | recruit | 把对方损失改成共同损失，给出可行动路径 | 只讲宏大道理 |
| 议价 | bargain | 提出交换、限定让渡范围、保留不可牺牲项 | 无条件退让却称谈判 |
| 回避 | deflect | 改谈程序、转移对象、用小事争取思考时间 | 没有策略目的的油滑 |
| 掩饰 | conceal | 继续完成原任务、控制信息出口、让表面行动遮住所知 | 全场统一“面无表情” |
| 拖延 | delay | 重读、核对、处理物件、把决定拆成下一步 | 只是填充镜长 |
| 保护 | shield | 挡住视线或路径、接管风险、替对方保留退路 | 把被保护者写成奖品 |
| 撤回 | withdraw | 收回物件、停止帮助、退出共同空间或承诺 | 没有退出成本 |
| 重新定义 | reframe | 改变称呼、公开关系、把私人冲突转为可裁决事项 | 用金句替代状态变化 |

同一台词可以执行不同动词。比较方案时改变的是观看机制与关系结果，不是“平静版/愤怒版/更愤怒版”。

## 听者表演与策略交接

听者不是等待下一句台词。先确定他此刻知道什么、担心失去什么，再选择：

- 继续原任务但速度或完成度改变；
- 接住信息却暂时不表态；
- 误解并据错误判断行动；
- 掩饰已经听懂，随后做出泄露真实理解的选择；
- 公开回应、退出或把信息交给第三方。

反应必须落在当前景别和声音能承载的通道。远景不靠眼睑微抖，近景也不必用全身后退代替内心处理。
群体反应按不同立场错开，不复制同一种“震惊”。

## 表演 adjustment：一次只改一个变量

比较或返修时保留台词、触发、人物关系、镜头边界和其他已接受选择，只改变一项：

- 行动动词：press → invite；
- 信息接收：未听懂 → 已听懂但掩饰；
- 物理任务：盯住对方 → 继续完成原工作；
- 注意对象：说话者 → 第三方或证据；
- 声音策略：完整说出 → 停顿后改称呼；
- 空间关系：保持位置 → 让出出口。

每次 adjustment 都要说明它改变了什么观众理解，以及牺牲了什么。模型实测只绑定当前模型、参考配置和镜头类型，
不把一次有效表演上升为通用规则。

## 投影到分镜与提示词

按现有字段写入，不增加新权威：

```text
触发 → 现场目标/行动动词 → 可见执行 → 对方接收 → 策略或状态落点
```

分镜负责谁拥有表演、注意如何交接、反应在哪里发生；视频提示词把它翻成目标模型可执行的
动作、视线、重心、呼吸、停顿、接触和声音。先完成通用表演结构，再读取命中的模型方言。

## 验收

- 去掉情绪形容词后，演员/生成模型是否仍知道做什么？
- 听者是否根据当前知识行动，而不是替作者提前知道？
- 策略变化是否有可见触发，还是突然换了一种情绪？
- 表演是否来自人物目标，而非统一握拳、颤抖、冷笑和瞪眼？
- 正常速度看片时，观众能否指出谁做了什么使关系改变？

## 方法来源与边界

表演行动、 adjustment、目标和听者方法参考 Judith Weston《Directing Actors》、
Michael Rabiger《Directing: Film Techniques and Aesthetics》与《Actions: The Actors’ Thesaurus》。
这里只提炼创作问题，不复制全书练习，不把舞台剧处理、真人演员经验或单一模型样本当成所有形态的固定规范。
