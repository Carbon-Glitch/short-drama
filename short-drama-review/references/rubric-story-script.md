# 故事与剧本审读

## 导演视角：按输入范围判断

先连续读当前稿，指出最值得保留的表达，以及观众会失去期待、看不懂或感受不到的具体位置。只检查本作实际使用的机制；审查方法见[问题与证据](review-method.md)。

## Story promise and engine

人物想得到什么，阻力为何持续，观众期待怎样的回报？升级是否改变关系、权力、知情、代价或时限，而非重复误会、羞辱和救场？类型标签不能代替观看承诺。

## Episode shape

开场有可感的进入理由，中途有兑现，结尾产生本集结果与相应余韵。安静收束、讽刺、悬念均可成立，不强制新增事件。重大转向由已建立的行动、事实或选择促成；若靠援助，检查主角此前做了什么使援助此时到来。

涉及艰难选择时，两条路在选择前仍有价值且可执行，代价由选择造成；普通决策不必造两难。剧情强调精确倒计时、有限次数或证据推断时，核对实际动作和后果，不让报数、登记或发问冒充完成。

先知、系统或特殊能力按[前提装置](../../short-drama-develop/references/premise-devices.md)检查：世界规则与角色/观众当前知道的规则分开。延迟披露不是漏洞；没有依据的新能力、例外或自动救场才需要修订。

## Entry, character, and serial memory

人物的私心是否通过言语、行动、距离或选择可感？变化是否有压力、行动和后果？背景资料只在影响当前理解时交代，世界事实、人物误信与观众知情不能混用。

争议证据只支持它实际证明的范围；密封、连接、位置或未接触等推断前提必须由此前动作成立。检验已经改变下一步行动后，不继续堆重复操作。

连载核对人物策略、关系、未兑现铺垫及物理交接；换集不能无因重置代价。

## Adaptation fidelity

只在改编任务启用。对照原文定位和已接受改编范围，检查核心人物立场、关系与主线。新增、合并、移位及换载体按已有改编映射记录；不能为凑反转数制造新对手。指出原文与新稿具体冲突，不以“忠实”阻止已授权改编。

## Scene test

每场承担哪项不可替代的体验变化？冲突场看目标、阻力、策略转向与退出状态；过场、仪式、蒙太奇或余波场看知情、关系、压力或感受如何变化。人物离开或沉默是否真的消除了阻力，不能只凭主角说完就宣布获胜。

## Action and production meaning

动作有路径、接触和后果，重要配角有自己的判断；精确台词、声音、画面文字与交接沿[剧本格式](../../short-drama-write/references/screenplay-format.md)检查。新资源需有来处，已有资源也不应替人物免除故事的核心难题。

字面实时倒计时核对动作容量与时间单调性；蒙太奇、时间省略和主观时间按其表达判断。重复载体若未增加节奏、视点、误导或后果，指出可删的一处。主题已经由行动成立时，不再靠总结金句解释。

## Dialogue

每句在争取、回避、试探或改变什么？人物用词、节奏和策略是否有区别？长段对白插入的行动应改变下一句的策略，不用无效眼神和停顿垫长度。精确承诺需要说清时，不强改成默剧。方法见[对白手艺](../../short-drama-write/references/dialogue-craft.md)。

## Rhythm profile (`REV-12`)

只核对 short-drama.json 中 accepted 的 rhythm_profile；未接受就不套数字。

| 字段 | 核对 |
|---|---|
| first_hook_seconds | 首个实际抓手出现时间 |
| beat_interval_seconds_max | 有效情绪/信息触点间隔 |
| opposed_reversals_per_episode_min | 已接受定义下由有议程的对手参与的反转 |
| end_on_peak | 是否按约定停在峰值 |
| reprise_previous_last_beat | 非首集是否按约定承接上一集末拍 |
| vo_share_max | VO占全部对白字符比例，采用写作工具同一计数口径 |
| first_major_payoff_by_episode | 系列首次主要兑现所在集 |

报告接受值、实际值、位置与测量依据；文本估计不冒充媒体时码。偏差按观看影响提出建议，不是自动阻断。镜长与景别比例见[分镜审读](rubric-visual-motion.md#rhythm-profile-shots)。

## Local passes (`REV-13`)

需要定位时分别读开头、中段和结尾：开头是否已有进入理由，中段是否仍在推进期待，结尾是否兑现约定。持续蓄势与反差换挡按本片选择判断，不另要求反转数量。

## Replaceable realization (`SCR-10`)

只检查用户要求替换的段落。替代版本保留戏剧功能、人物代价、后续兑现和交接；新增铺垫要写回来源，删除场景要指出由谁承担原职责。方法见[可替换实现](../../short-drama-write/references/substitutable-realization.md)。

## Common findings

优先修：期待没有兑现、人物只被动等救、反转无因、证据越界、对手突然失能、代价无因复位、同义反复和结尾自我解释。每项给出位置、观众损失与原位改法，不把自己的口味当通用模板。
