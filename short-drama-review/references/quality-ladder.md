# 影视精品质量梯度

审查先判断当前证据能支持哪一级结论，不把“规则通过”直接写成“成片优秀”。

| 级别 | 证据要求 | 可以说什么 |
|---|---|---|
| 可生成 | 剧本、资产、分镜、提示词和执行输入相容 | 具备生成条件 |
| 可剪 | 实际素材能完成镜头职责，入出点和声音边界可用 | 可以进入粗剪/精剪 |
| 可交付 | 成片技术规格、字幕、响度、切点和文件检查通过 | 满足交付要求 |
| 精品候选 | 正常速度、目标画幅和目标音量下观看/回听；关键场次的观众立场、表演、摄影、声音、剪辑和余韵成立 | 有精品完成度，但仍需确认未测项 |
| 精品定稿 | 关键问题按时间码返修后重新观看/回听；未验证项已明确记录 | 当前版本可作为精品交付 |

## 审查顺序

1. 先查故事承载：因果、信息释放、选择、后果、关系变化；
2. 再查表演与空间：触发、策略、听者反应、站位、轴线、持物和动作落点；
3. 再查声画关系：声源、声音桥、静默、音乐让路、字幕与口型；
4. 最后查后期：镜序、切点、色彩接镜、响度、坏帧、画幅和播放面。

每条 finding 指向实际时间码、镜头或字段，并说明由哪个 owner 修复。只看文字时把动态表演、声音空间、
剪辑节奏和情绪效果标成未验证；能访问成片时必须实际观看和回听。
