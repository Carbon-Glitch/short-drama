# 导演自查：逐镜比对，定位到句

设计看观看机制，分镜看可拍过程，提示词看字面指令和实际参考，回片与剪辑看正常速度下的真实声画。先连读或看听完整段落，再检查对应镜头。表演问题在设计与分镜阶段解决。

## 写完逐镜自查

表演问题针对承担本拍交流与反应的角色。

- 锚点：这一镜真正拍的是什么（瞬间/情绪一句话，「他还没开口」式，非物体状态）。
- [ ] 机位自洽 — 正文细节与所定角度一致
- **演出层深度**：每个在场角色答得出objective（动词指向对手）吗？沉默/倾听角色有眼任务吗（倾听者的脸不空转）？被打断的活/停顿里填了事吗（评估/决定/拒答）？
- [ ] anti-AI test — 这段表演读起来像模板，还是像看过演员排练的导演笔记？模板感重写
- 光位与阴影方向，能否从本场固定光源和当前机位推出？
- 观众第一次读清证据、人物接收、动作反应、声音入口和镜头切点，顺序能否成立？

同场顺接时检查：

- [ ] 时间段不重叠不留空；上一段结束状态=下一段起始状态

核对串行操作、可并行通道、完整发声、阅读和反应窗口。内层拍段与外层镜长一起核对：一镜标3秒，串行拍段却是1＋0.8＋0.7＋0.8＋0.7＝4秒，即使外层时间码衔接正确，容量仍未成立。机位从场景地标反推：相机在哪里，能看见哪些表面，遮挡、焦面与占画是否支撑信息可读。镜尾的情绪和身体状态进入下一拍，有意跳变沿本场已选表达。

道具按“原位置与持有者 → 接触／释放 → 状态或数量变化 → 当前归属”核对；参考图分别承担身份、空间、影调或状态，冲突修到实际绑定。

## 回片逐镜比对

- 站位（坐错沙发/箱子摆错方向=逐项纠）
- 表演：视线对谁、听者是否接到、反应是否在触发之后、情绪是否无因重置。
- 摄影与声音：机位、焦点、光态、声源和注意转移是否兑现本镜目的。
- 关键操作与揭示：需要观众看见的过程是否真实发生；可读文字与证据在正确时刻出现。

问题指到 SHOT、输入句子或实际文件版本与时间码，写清观众损失和负责阶段。对照 DESIGN → SHOT → 提交快照 → 采用源窗，修最早失效层。文本判断、画面观察和听审范围沿[质量证据](quality-ladder.md)记录。

## 句级修复与复看

1. **句级修改**：只改坏句，其余锁死。先定位坏句（"镜2的仰视问题出在'管道横贯头顶'这一句"），再动刀
2. **一次只改1-2个变量**：改多了无法归因

保住已成立的表演、光影与信息顺序。若问题根在分镜或参考，联动修订对应来源；对照试验固定其余输入。关键因果、体验断裂与设计降级修好后，连看受影响镜头及前后接点。

反复失败时重新审视镜头设计：该拆条、该换机位，还是该调整参考职责。

修订结果留在现有镜头或素材意见里：位置、证据、改法和复看结果。自查完成以本轮问题得到解决或未决项准确可见为准。
