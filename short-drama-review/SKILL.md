# 短剧审查

## 目标与输入

第一遍连着看：从哪一拍开始想知道下一步？哪一拍让你改了判断，或终于等到了想看的事？看完还记得哪个细节？作品以讨论或分享为目标时，再问：看完想跟谁说什么？第二遍把最该保住和最值得修的地方指给作者：分镜指到 SHOT，成片指到时间码和那里的画面或声音。制作内直接返修，单独审查交判断与建议。
先读[共同创作方式](../short-drama/references/viewer-first.md)、[作品质量证据](references/quality-ladder.md)、[审查方法](references/review-method.md)与[首次观看与反馈判断](references/fresh-viewer-review.md)；按问题查[影视工业知识](../short-drama/references/craft-knowledge.md)。

## 检查顺序

1. **开场。** 哪一格让你愿意停？你在等谁做什么？
2. **画面。** 不读解释，看造型、光色和空间，指出本片独有、值得留下的那个细节。
3. **转折。** 当答案出现，观众能同时看清证据和受影响的人吗？看不清，指出具体一拍。
4. **声画。** 顺着真实字音、接触和呼吸看一次：是谁在说，谁在听，切早一格会丢掉什么？

5. **实际交付**：来源、引用、版本、素材覆盖与输出规格由现有检查器核对；实际看听评价成片。

常见镜型、简洁构图和克制表演本身不是缺陷。审查“正确但普通”时必须指出：哪个选择换成任何作品都成立、损失了哪项既定观看收益，以及上游选中的表达机制在哪一步被磨平。沿设计重点 → 分镜目的与调度 → 提示词 → 实际素材 → 剪法追踪保守降级；不能只用“AI 味/不够高级”作结论，也不能把新增运镜、特写或效果当作修复。修订应恢复或重新选择更有观看价值的机制，再核技术正确性。

## 分镜后的导演体验审读

在资产与提示词展开前，沿《剧本.md》《视觉设定.md》《分镜.md》和已有观众基线连续读一遍，像第一次看的人那样回答：

- 顺着首看记下的那几拍，哪次兑现改变了局面，哪一段已经猜完还在等？
- 注意是否落在该看的地方，关键反应是否读得清，画面与声音本身是否有吸引力？
- 它像不像为目标观众创作的作品，哪里陈旧、温吞、拥挤或只有设定没有体验？

先说最强、最值得保留的一处，再只提最影响观看的两三处，写清位置、观众影响、owner 和原位修法。把结果交设计或分镜修订后再接资产与提示词；不新增审查文件。此处判断文本能否成立，已有近期证据用于校准，不冒充真实观众试看。

## 做法

读取当前任务的直接来源与默认核心知识，先对实际画面、声音与创作职责作判断，机械检查辅助定位来源、时序和版本问题。已有输出就观察实际输出；只有设计稿时给出可落实的创作修订与待验证项。

双视角分工前移：整集剧本进入设计前，首次观看者不知道创作意图，只读剧本并报告接收到的事件、人物吸引、何处拖与情绪落点；整集收尾再由连续性审查者沿五文档与实际素材追踪位置、双手、持物、文字状态、声音窗口和参考职责。两者都直接返回具体发现，不创建额外表格或审查文件。局部单场不重复启动。

每个问题写位置、证据、观众影响、负责阶段和明确修订结果。首看自检给出的是创作判断；发布后若有留存曲线、评论原话或分享数据，再据此核对当时的判断。优先修观众看不懂、不想看、感受不到或明显出戏的地方。

重要设计通过现有条目、参考图、镜头与 bindings 追踪；缺失时回填对应来源并继续。复用、定向修改、补覆盖或重做某段按实际问题选择。

## 输出

口头结论直接回答；需要落盘时用 `审查/<主题>-审查.md`，写清范围、实际观察方式与结论：

- `APPROVE`：本轮检查通过。
- `APPROVE_WITH_NOTES`：已完成，另有可选提升。
- `REVISE`：存在明确待修问题，并给出具体方案。
- `PROVISIONAL`：关键证据尚缺，先交付可完成部分与补证方向。

问题严重度按观众与交付影响区分 blocker、major、minor、note。创作选择通过作品与既定目标讨论，不以条款数量或装饰数量评分。
