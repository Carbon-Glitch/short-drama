# 短剧审查

## 目标与输入

第一遍以完全陌生的观众视角连着看：开场前 3 秒什么画面或声音把你钉住了？从哪一拍开始迫切想知道下一步？哪一拍让你改了判断、会心一笑、屏息或被击中？看完后脑海里真正留下印记的画面和细节是什么？第二遍把最该保住的核心亮色和最拉垮/最平庸的地方精准指给作者：分镜指到 SHOT，资产指到 IMG/REF，成片指到时间码和那里的具体画面或声音。制作内直接返修，单独审查交判断与建议。

先读[共同创作方式](../short-drama/references/viewer-first.md)、[作品质量证据](references/quality-ladder.md)、[审查方法](references/review-method.md)与[首次观看与反馈判断](references/fresh-viewer-review.md)；按问题查[影视工业知识](../short-drama/references/craft-knowledge.md)。

## 检查顺序（先审吸引力与格调，再查技术）

1. **开场抓力（前 3 秒）。** 脱离文字说明，第一眼画面、动势或先入声音能不能立刻让人停下来？你在等谁做什么，或被哪种独特世界氛围吸进去了？
2. **整体审美与大胆造型（拒绝“只有一两个小道具的平庸写实”）。** 不读解释，抽帧看人物造型、色彩秩序、构图几何、光比层次与空间性格：整片是否具备**属于自己的鲜明美学招牌与电影/艺术质感**？是否已经彻底摆脱了“AI 磨皮网红脸、均质大平光样板间、杂乱网感配色或千篇一律的正面中景站桩”？
3. **转折与情绪兑现。** 当答案或情绪高光出现，观众能同时看清关键证据/动作与承受者的反应吗？有没有因为铺垫太温吞、机位太保守或节奏太平均导致高光没响起来？看不清或不够劲，指出具体一拍。
4. **声画协同与呼吸节奏。** 顺着真实字音、接触音效、音乐进退与静默留白看一次：是谁在说，谁在听，有没有利用声画错位（J/L-cut）和静默蓄势？景别跳切与快慢节奏有没有弹性，切早或切晚一格会丢掉什么？
5. **实际交付与物理连贯。** 来源、引用、版本、素材覆盖、双手持物连续性与输出规格由现有检查器核对；实际看听评价成片。

常见镜型、简洁构图和克制表演本身不是缺陷，**但“平庸且可被任何同类套路替换”就是重大缺陷。**
审查“正确但普通”的作品时，必须明确指穿以下三件事：
- 哪个机位、造型、配色或台词换成任何平庸网剧都照样成立；
- 它在哪里把上游选中的大胆表达机制或独特情绪体验磨平了（沿**视觉主张 → 设计重点 → 分镜目的与构图光影 → 提示词质感载体 → 实际素材 → 剪辑节奏**追踪保守降级点）；
- 给出具体升级方案（不能只写“太AI味/不够高级”，也不能靠机械加运镜、硬切特写或后期加滤镜凑数），必须从**强构图态度、局部光色对比、大胆造型符号、声画反差或节奏呼吸**里找回不可替代的观看价值。

## 分镜后的导演体验审读

在资产与提示词展开前，沿《剧本.md》《视觉设定.md》《分镜.md》和已有观众基线连续读一遍，像第一次看的人那样回答：

- **吸引力与体验节奏**：开场第 1～2 镜有没有真切钩住注意力？顺着首看期待，哪次兑现真正掀翻或推进了局面，哪一段已经让人猜透却还在拖？
- **视觉胆识与质感继承**：《视觉设定.md》定下的大胆造型、色彩纪律、光影对比与空间态度，有没有真正落进分镜的 `景别/机位`、`运镜` 和 `起点→终点` 里，还是在分镜阶段悄然滑回了连续平视中景排排站？
- **注意与声画魅力**：注意是否稳稳落在最刺人的焦点上，关键反应是否读得清、留得住余韵，画面与声音配合本身是不是就足够好看好听？
- **独特性排查**：它像不像为特定观众量身打造的鲜明作品，哪里显得陈旧套路、温吞安全、微动作拥挤或“只有设定文字没有可拍的视听爽感”？

先肯定最强、最值得死保的一两处亮色，再精准指出最影响观看吸引力与影视格调的两三处（写清位置、观众影响、owner 和原位改法）。把结果交设计或分镜修订后再接资产与提示词；不新增审查文件。此处判断文本能否成立，已有近期证据用于校准，不冒充真实观众试看。

## 做法

读取当前任务的直接来源与默认核心知识，先对实际画面质感、声音魅力与创作职责作判断，机械检查辅助定位来源、时序和版本问题。已有输出就观察实际输出；只有设计稿时给出可落实的创作修订与待验证项。

双视角分工前移：整集剧本进入设计前，首次观看者不知道创作意图，只读剧本并报告接收到的事件、人物吸引、何处拖与情绪落点；整集收尾再由连续性审查者沿五文档与实际素材追踪位置、双手、持物、文字状态、声音窗口和参考职责。两者都直接返回具体发现，不创建额外表格或审查文件。局部单场不重复启动。

每个问题写位置、证据、观众影响、负责阶段和明确修订结果。首看自检给出的是创作判断；发布后若有留存曲线、评论原话或分享数据，再据此核对当时的判断。优先修观众不想停、看不懂、无质感或明显出戏的地方。

重要设计通过现有条目、参考图、镜头与 bindings 追踪；缺失时回填对应来源并继续。复用、定向修改、补覆盖或重做某段按实际问题选择。

## 输出

口头结论直接回答；需要落盘时用 `审查/<主题>-审查.md`，写清范围、实际观察方式与结论：

- `APPROVE`：本轮检查通过，美学质感、吸引力与技术连续性均成立。
- `APPROVE_WITH_NOTES`：已完成，另有可选美学或节奏提升。
- `REVISE`：存在明确待修问题（含平庸降级/AI塑料感等美学缺陷），并给出具体方案。
- `PROVISIONAL`：关键证据尚缺，先交付可完成部分与补证方向。

问题严重度按观众与交付影响区分 `blocker`、`major`、`minor`、`note`。创作选择通过作品吸引力与美学完成度讨论，不以条款数量或装饰数量评分。
