# 分镜与注意力设计

将《剧本.md》与《视觉设定.md》转成空间连续、节奏锋利且视频模型能稳稳拍出的 `剧集/<EP>/分镜.md`。默认交付文本分镜；仅在需要极高精度锁定时补充冻结或收尾关键帧。

## 1. 入口与最小读取

先按 [设计阶段](../short-drama-design/SKILL.md) 检查缺口；设计完成后直接写文本分镜，再把各镜可见需求交给最小主体资产与图片提示词（已有 `IMG`/`REF` 直接复用，不等图片齐全才开写）。

**默认只读**：本集《剧本.md》、本集《视觉设定.md》、目标模型原生时长与精简版 [共同创作底线](../short-drama/references/viewer-first.md)。动画任务加读 [动画表演](references/animation-performance.md)；其余镜头手艺文档按需查文末索引，不预先全量加载。
说明跟随项目语言；需写关键帧正文时跟随 `format/prompt_language`（未配置用英文）。

## 2. 镜头语法与反单调自检

保住上游核心体验与审美主张，改进权限沿[共同创作底线](../short-drama/references/viewer-first.md)。继承本场实际选定的光色、空间与表现机制，不自动追加色盘比例、单光源或障碍物配额。

检查相邻镜的景别、机位、前景与注意重心是否在推进体验；景别落差、45°变化和“三选二”可作为发现无意重复的工具，不是通过门槛。连续同景别、对称正反打或固定长镜有观看价值时，在 `目的` 写清理由即可，不为了凑变化越轴或切碎表演。

台词不自动决定画面：听者、道具、同框距离或画外声音更有力量时，把注意交给它。节奏按上游选择展开；有意凝视蓄势不强插短镜，已选换挡则明确声画变化与落点。

### 生成路线分流

| 控制需求与实际素材 | 路线 | 分镜决定 |
|---|---|---|
| 需身份/空间/风格或声音等多参考 | 全能参考 | 标清每项职责；其中指定开场的参考图不等于接口首帧条件 |
| 只需从一张确定画面开始 | 纯 I2V | 真实起始帧负责开场，后续变化写清 |
| 需约束起点与终点 | 纯 FL2V | 首尾状态与中间可行动路径都成立，不把端点条件当作中间动作保证 |

路线按实际接口能力落实，模式互斥细节读命中模型方言；互斥的控制需求按[生成分组策略](../short-drama/references/model-aware-coverage-and-joins.md)拆段或重新选择。纯帧路线不能偷偷加参考音频；全能参考不能声称获得首尾帧硬约束。没有图片且明确选择文生时，另走文生并写全静态锚点。

若专属起始帧已承担当前构图、环境和光影，不重复绑定无新增职责的全景母版。素材准备状态（REF/PLAN/待补）与生成路线分开判断；绑定语法沿[参考输入](references/reference-inputs.md)。

## 3. 工作流与字段硬标准

### 第一步：先写本场「场景站位」（多镜场次必填）
在一场戏的首个镜头前，用精炼数行锚定全场物理骨架：
- 固定空间锚点、人物初始左右站位、轴线与 working side；
- 主光物理来向、明暗/冷暖光区边界、可用前景遮挡物与纵深留白方向。

### 第二步：逐镜落写（过场镜同样维持全片构图与光影秩序）
每个 `SHOT-...` 必须写齐以下字段（参考绑定语法见 [视觉依据与输入参考图](references/reference-inputs.md)）：

- `来源`：真实场景 ID + 本镜承担的剧本短引文；
- `时长`：按完整发声、动作路径、视觉消化与情绪余韵给足秒数（项目已有节奏配置沿其执行）；
- `目的`：写清本镜给观众的**新信息、情绪牵引或权力变化**（严禁写“中景展示某人说话”）；
- `景别/机位`：**必须同时含 4 个要素**——景别 + 机位高低/视角态度 + 构图几何/前景遮挡/留白方位 + 焦段/景深性格；
- `运镜`：**运镜围绕清晰观看路径组织（也可固定）**，写清触发动作、运动路径与停顿落点，复合运镜写清先后与动机，避免互相冲突；
- `起点 → 唯一动作 → 终点`：
  - **单镜一主事**：每镜围绕 **清晰的主导变化** 组织动作链（人物、双手、持物、道具状态及与光区的相对移动），绝不把五六个碎动作塞进同一短镜；
  - `终点` 写清出口时的构图与动作阶段、受光落点与观众带走的情绪余韵；
- `声音`：明确演员原声、物理接触音效、环境底声、音乐与静默由谁承担，标出 J/L-cut 或半拍停顿留白；
- `图片提示词项`、`输入参考图`、`视觉依据`：
  - 资产尚未建立时，`图片提示词项` 写「无」，`输入参考图` 仅列本镜需要的主体缺口；
  - `视觉依据` 逐项写明本镜依赖的人物、地点、道具，标清**必保的光色/材质特征**与**关键道具归属（归谁持有）**；`IMG` 为提示词条目，`REF` 为真实图，`PLAN` 为创作者自挂计划。**若本镜已分配自带环境光影的专属机位起始帧，不再冗余重复绑定全身全景母版图。**

### 字段写法对照（Bad → Good，跨题材通用示例）

* **不合格（机位说明书 + 丢掉视觉设计 + 动作过载）**：
  > `目的`：展示小夏把字条交给陈默并观察他反应。
  > `景别/机位`：中景，平视，两人站在吧台两边。
  > `起点 → 唯一动作 → 终点`：小夏低头擦杯子、叹气、放下抹布从口袋拿纸条递过去、抬头委屈地看陈默，陈默惊讶伸手接住。
* **合格（继承光影阻隔 + 单一主事 + 下游可直接翻译）**：
  > `目的`：藏住小夏正脸，单靠推杯越界动作与明黄花桶前景遮挡拉满试探张力。
  > `景别/机位`：贴吧台低高度近景，前景右侧以高饱和明黄鲜花桶虚化遮挡成边框，左侧大片奶油暖白墙面留白，画右高窗百叶窗条纹阳光斜切过台面，50mm 浅景深。
  > `起点 → 唯一动作 → 终点`：小夏（画左穿丹宁蓝工装，仅见肩与手）将折好字条（专属小夏持有）压在空咖啡杯底 → 她手腕轻推把空杯连同字条滑送进吧台中央阳光区，自己撤手退后拉出距离 → 末帧定格在条纹光带中央孤立的杯与字条，以及画右边缘刚探入光区的陈默半截迟疑指尖。

### 第三步：写「生成安排」与「接镜」（严格对齐视频模型预算）
在「场景站位」附近明确区分 `SHOT` 与实际生成调用（`clip`），按 [模型与接镜](../short-drama/references/model-aware-coverage-and-joins.md) 分组：

段长、分组与跨段接法只按[模型与接镜](../short-drama/references/model-aware-coverage-and-joins.md)和项目已接受规格决定，本入口不设置另一套默认秒数。

多镜容器明确镜界与切法；一镜到底明确连续调度，不把两者混写。关键帧按上述路线需求准备。文字与图形分类沿[通用成像配方](../short-drama-image-prompts/references/common-recipe.md#7-参考文字与定向修改)，后期承载沿[制作分工](references/editorial-coverage.md#字幕图形与效果的制作分工)。



### 第四步：单轮导演体验审读与原地返修
整集请求必须完成整集。整集分镜落稿后、进入资产与提示词前，按 [导演体验审读](../short-drama-review/SKILL.md#分镜后的导演体验审读) 仅执行 **1 轮高杠杆审读**：
- 先标出最炸、最该死保的 1–2 处镜头；
- 只挑最拉垮吸引力或发生“平庸降级”的 **Top 2–3 处**直接原位改透（不另建审查文档），随即接续最小主体资产、图片提示词与视频提示词；试生成后按实际问题回到对应镜头或参考修订。

## 4. 可选审阅预览

仅当创作者要求整集扫读、核对时长或明确要预览时，按 [分镜审阅预览](references/storyboard-preview.md) 生成派生四列表：`分镜号｜时间｜镜长｜完整声画调度`（保留完整摄影、光影构图、起止动作反应、逐字对白与必要声音，不压缩）。`分镜.md` 始终是唯一权威，连续制作不强制停靠预览。

## 5. 按失控点分级补控制（试片返修用）

生成不稳时按成本由低到高定向补控，不整集推倒：
1. 先补文本精度（构图几何、受光边界、减并发动作）；
2. 质感或身份漂移回修主体资产图 / 定调代表图；
3. 微小道具状态不稳补细节图；
4. 单切构图或切点失控补该切关键帧；复杂运动再上多关键帧、白模、动作参考或首尾帧。

## 6. 修订与三重连读校验（完成前必核）

修订时保留未受影响的 `SHOT ID`，并同步受影响的资产引用与视频提示词。交付前必须跑完三遍校验：

1. **物理与容量连读**：确认《剧本.md》中的每个场景均有镜头承载（或记录明确的未拍选择）；把「上镜终点 → 下镜起点 → 本镜唯一动作 → 本镜终点」连读，确认人物位置、双手、持物归属、道具状态与文字变化全部有镜内动作或明确剪接承接；核对同一 clip 内完整发声、动作与结尾反应装得下（拥挤就拆镜或减动作）。
2. **节奏与设计连读**：遮住对白，检查画面是否仍保有选定的审美主张和注意推进。相似镜头若无新的信息或体验就修订；有意重复按 `目的` 判断，不按角度或数量判错。
3. **体验曲线复核**：连看镜长、表演与声音密度，判断所选换挡或持续蓄势是否兑现；只修实际薄弱处，不强凑转折数量。
