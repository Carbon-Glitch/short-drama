# 短剧分镜与冻结关键帧

## 创作目标与默认阅读

先把画面设计得漂亮、独特、有想象力，再以角色行为、表演和剪辑兑现故事。先读[共同创作方式](../short-drama/references/viewer-first.md)和[影视工业核心](../short-drama/references/film-craft-core.md)，以及本阶段核心知识：

- [场面节拍](references/scene-beats.md)
- [镜头语言](references/shot-craft.md)
- [光的设计](references/lighting-craft.md)
- [为剪辑设计覆盖](references/editorial-coverage.md)
- [场景视觉组织](references/scene-visual-plan.md)
- [导演案例转译](references/premium-case-studies.md)

- [连续片观看机制](references/sequence-case-library.md)

动画与拟人化任务同时默认读[动画表演](references/animation-performance.md)。

- [成像风格与感官质感](../short-drama/references/image-look-and-finishing.md)
- [按模型排生成段与接镜](../short-drama/references/model-aware-coverage-and-joins.md)

手艺资料：[按问题查影视工业知识](../short-drama/references/craft-knowledge.md)。先用本地资料，遇到方法或接口缺口再定向联网。

本阶段核心资料按当前任务读取；同轮已读未变的内容复用，接口与故障资料用到再查。

把剧本和视觉事实转成有镜头职责、空间连续性和可冻结起点的 `剧集/<EP>/分镜.md`。
每镜使用二级标题 `## SHOT-...`，同镜下用 `### 冻结关键帧提示词` 写起始帧正文；
需要时另加 `### 收尾关键帧提示词` 写终点正文。

主动以观众情绪体验和高级影视感组织本阶段选择；读取[主动导演](../short-drama/references/film-craft-core.md)，将机位、构图、运镜、声画与剪辑技巧落实到具体画面和时间关系。

## Quick Start

```text
用 $short-drama-storyboard 完成 EP001 的正式分镜和每镜冻结关键帧
```

## 入口

当前剧本加视觉事实即可进入。资产图片提示词与分镜并行。关键场次主动构思不同的观看方式，比较情绪力量、空间、视点和声画节奏，选定方案后落实镜头组与转场两端。

把观众立场、情绪走向、表演、光色和声音先定成可观察选择，再大胆组合景别、机位、运镜与剪辑，形成场面的视觉记忆点。

创作者可读说明跟随项目语言；冻结关键帧的可复制正文跟随
`short-drama.json#/format/prompt_language`。没有 `short-drama.json` 时正文默认使用 `en`。
分配镜头时长前读取
`short-drama.json#/creator_authority/production_profile/choices/native_duration_seconds`。已声明目标模型但
没有原生时长时先补这一个选择；目标模型也未声明时照常按叙事节奏设计，不猜供应商限制。
同时读取 `short-drama.json#/creator_authority/rhythm_profile`：`status` 为 `accepted` 时，镜长按
[镜长从哪来](references/shot-craft.md#镜长从哪来-sht-28) 由声音事件与 `target_avg_shot_seconds` 推出，
全集近景类镜头占比不低于 `close_shot_share_min`；档案缺失或未接受时不核对这些数值。

冻结关键帧成稿后，再按画面中的可见内容填写视觉依据、图片提示词项和输入参考图，
避免只按镜头意图列资产而漏掉实际入画的人物或物件。

用户没有手工点名参考图，不等于选择文生视频。冻结关键帧后先根据本镜可见人物、地点、关键道具与
起始构图判断一致性需求，再检查项目中已有的真实图片。只有当前可读、内容与用途可核对的图片才能自动绑定；
文件名像某个角色但内容未核对时，仍视为未准备好。

项目里没有所需图片时，一次向创作者说明三条可选路径：把手上已有的图片放进项目再绑成 `REF-...`；在自己的工具里出图、本轮先用
`PLAN-...` 写出挂图计划；或者明确改走文生视频。用本套件的生产技能出图只是第一条路的一种做法，
需要项目外的 adapter 与凭据，不是唯一入口。

开始分镜前读 `剧集/<EP>/剧本.md` 的当前内容。创作者说「剧本已确认采用」指的是那个文件，
不是对话里更早的草稿；两者不一致时以文件为准，并把差异说出来。

## 工作流

承接现有简报或交接说明里的现实观众基线，区分已有证据与待验证预测；据此落实线索可见性、信息释放、人物反应和情绪兑现，不把“观众一定猜不到”当镜头事实。
本阶段复用受众基线，按影视工业知识查视觉与接镜方法；若必须改核心反转或入口承诺，回交写作/开发先更新对应判断。方法见[现实观众预期校准](../short-drama-develop/references/audience-expectation-calibration.md)。

1. 读取已接受的目标模型原生时长区间，再确认每个场景动作、对白、声音、画面文字和转折由哪些镜头承载。
2. 确定观众何时知道什么、对齐谁、空间如何揭示、转折落在哪个可见动作。
   关键段落先预想怎么接剪、怎样保住听者与结果，按需读[分镜先为剪辑设计](references/editorial-coverage.md)。
   必须保住的事件放在现有职责/起终/声音中；复杂剪口可加一行“剪辑意图”，不新增镜头表。
   情绪转折处把“触发→人物反应→观众兑现”写进这行，并点明声音先行/延续、音乐转折或有意义的停顿；后期据实际素材绑定时间，不把这些职责只留在前期说明里。
   剧本或 Brief 用“前半段 / 后半段 / 前三分之一 / 最后 N 秒”等相对时间限定首次出现、释放或禁止时，
   先用已接受集长换成明确时间边界再分镜；例如 60 秒作品的“后半段首次出现”不得早于 30 秒。
3. 每镜写清唯一职责、来源、时长、景别/机位、运镜、起点、唯一主要动作、终点和声音；用
   `起点 → 唯一动作 → 终点` 直接说明人物、双手与持物怎样完成本镜状态转换。三条依据留到第 6 步。
   “唯一”指主导戏剧变化；主动判断已建立的环境活动、听者行为、接触反馈及声音哪些持续、哪些改变，
   将相关的并行、反应延迟和余动写在现有动作/运镜/声音或场次说明中，不把主角以外默认冻结。
   场景默认按[场景视听调度](../short-drama/references/film-craft-core.md#场景生命注意转移与声画节奏)安排主次和声画关系，不靠增加运动数量。
   涉及字幕、图形或效果时，先按[制作分工](references/editorial-coverage.md#字幕图形与效果的制作分工)决定模型生成、后期或混合；
   在现有SHOT说明中交代触发、预留与验收，必要时加可选“制作分工”行，再写关键帧和视频提示词。
   数一下这一镜要观众看清的事，按镜长判断每件有没有足够的时间被看清；放不下时先删、合并或拆镜，见 [短镜头的动作量](references/shot-craft.md#短镜头的动作量-sht-03)：视频模型不会删掉多出来的动作，而是把它们压到看不清。
   「运镜」按本镜目的逐镜选，写行为和理由，固定也写理由，见 [运镜逐镜选](references/shot-craft.md#运镜逐镜选-sht-04)。
   有对白、VO 或 OS 时，先按原文和人物说话方式估算完整发声时间，再安排不能重叠的动作、停顿与
   末尾反应；把估时依据简写在本镜「声音」里。具体做法见 [对白估时](references/shot-craft.md#对白估时)。
   对白场先按 [对白覆盖默认](references/shot-craft.md#对白场怎么切-sht-29) 放切点；镜长不按剧本字数折算。
4. 一场戏拍成多镜时，在当前场第一个 `SHOT-...` 之前写这场的「场景站位」：固定锚点、各人相对锚点与彼此的位置、轴线与 working side、哪一镜改变站位。再逐镜锁定朝向、位置、视线、持物、出入口和必要状态，与「场景站位」一致；起点、终点里的位置写锚点和人物关系，视线写看向谁或什么；冻结关键帧再把它翻成本镜机位下的前后景、朝向、中间隔着什么和画面左右，见 [站位先写锚点和关系](references/blocking-playbooks.md#站位先写锚点和关系)。上游已有会限制动作空间的持续关系时，把关系投影进本镜起点与终点。
5. 冻结关键帧只投影镜头起点；删除终点才出现的文字、动作、姿态或道具状态。
   镜头的职责落在收尾那一下时，另写 `### 收尾关键帧提示词` 投影**终点**——同一格画面的
   另一端，规则完全对称：删除起点才有、终点已经不在的东西。它是可选的，写法与取舍见
   [首尾成对](references/shot-craft.md#首尾成对)。
6. 关键帧成稿后，先从成稿正文读出这一格里需要保持身份、造型或地理的人物、地点和道具，
   再用同一份清单一次填满三条依据：

   - **视觉依据**：清单里每一项写成《视觉设定.md》的条目引用，这是必写字段；
   - **图片提示词项**：清单里已有合适 `IMG-...` 条目的写上，没有的留「无」；
   - **输入参考图**：按清单在用户提供的输入、`剧集/<EP>/制作成果/` 和文档已指向的其他可见媒体中查找匹配图片；
     命中就写入 `REF-...`。一张都没命中时写「无（待补参考图：<本镜缺失的起始帧、人物、地点、道具>）」；
     只命中一部分时，在已有 `REF-...` 后追加「；待补参考图：<仍缺的图片>」，缺口之间只用 `、` 分隔。
     创作者说图片由他自己在别处准备时，把这份清单写成 `PLAN-...` 槽位，本镜即告就绪；
     只有创作者明确表示不用图时，才写「无（创作者已明确选择文生视频）」。

   三条依据读的是同一格画面，所以不能互相矛盾：关键帧里点名的人物或道具，一定出现在视觉依据里。
   目标模型的参考槽位有上限（Seedance 2.0 全模态参考最多 9 张图）时，输入参考图按失去它的代价从高到低保留：起始帧、正在说话或做主要动作的人物、必须认得出的道具、地点、其余入画人物、定调图；放弃的那些写明，必要事实进关键帧正文。
7. 整集请求完成整集，末端一次报告覆盖、节奏和真实未决选择。

## 接续场面设计

先按[设计阶段](../short-drama-design/SKILL.md)检查本次分镜与实际图像缺口。读原剧本与「场面设计 · 场次ID」，把选定的新事件、干扰、物品行为、沉默和声音落点一起分镜化；来源沿原场次，新增内容引用对应设计条目。先安排可见覆盖，再分配模型调用。

## 先保住设计与关键兑现

先确定资产最值得看的设计、关键刺激与人物/物品回应发生时，观众到底看哪里。落实到具体镜头和可读尺度/角度，必要时准备反应或细节覆盖，再排 clip 调用。漂亮细节不应在关键时刻转成侧面或被遮住；针对已知模型难点选择多镜覆盖、独立细节或后期承载，避免给一个连续运镜塞满相互竞争的任务。

## 生成安排与接镜

排镜时先读取实际模型/应用能力，区分 SHOT 与一次生成的 clip。同场连贯内容优先较长分组：H3 尽量13–15秒，Seedance 2.5 优先接近30秒；一次调用内可按分镜切镜。再按对白、动作、段落与可剪余量调整。在场景站位附近写简短「生成安排」（模型、预计调用次数、成员镜头、生成时长与成片目标窗口），跨段 SHOT 写「接镜」（接法、动作阶段、方向、声音与余量）。按已接通路径执行，后续提示词和生产沿用；方法见默认阅读的接镜指南。

## 镜头要求

- 每镜有唯一职责、明确来源、可见起止状态和合理时长。「来源」以《剧本.md》里真实存在的场景 ID 开头，
  ID 之后可以跟必要短引文，跨场次的镜头用 `、` 连写多条；`creator_markdown_check.py` 会核对每个 ID 都解析得到。
- 「来源」短引文应对应本镜承担的动作或声音。正文提到画外人物时，可在视觉依据写
  `；画外：<类别>「<名称>」`；这只声明其不在画面，不能代替必要动作的落实。
  需要看见的动作应另有镜头承载，或说明为何省略。

- 剧本里的每个场景都要有镜头承载。确实决定不拍某一场时，在《分镜.md》正文开头写一行
  `- 未拍场次：<场景 ID>（理由：……）`，多项用 `；` 连接。省略理由必须留在成稿文档中，供下游区分有意省略与遗漏（SHT-01）。
- 镜长按表演与叙事需要定，生成时长按实际模型和入口预算。短镜可从较长素材选窗，已支持多镜打包时可合并相邻镜头；超过单次上限时按动作与接法拆生成段，保留原镜头意图。多镜开关、关键帧和整数时长沿目标方言与项目配置；必要的路线选择随制作方案一次说明，普通分组由 Agent 在已授权范围内决定。
- 「唯一动作」写从本镜起点到终点的那条可见状态链；涉及交接、换手、放置或取回时，把接触者、
  接触方式和物件落点写在同一链里，不能让合法终点之间靠镜外瞬移衔接。
- 切镜必须带来信息、权力、情绪、空间或节奏变化；同义重复镜头删掉。
- 相对时间词约束的是事件首次可见或可听的时刻，不因前置动作已经完成就提前释放；分镜时间轴直接
  写出该边界，不把“稍后”“交接后”等叙事顺序当成数值时间的替代。
- 同一动作不跨镜重复发生，峰值处声明过的[冲击重复](references/shot-craft.md#动作落实表)除外；终点应能成为下一镜可信起点。
- 用富有表现力的运镜和竖屏构图引导观众读到主体、反应及空间层次。按观众此刻要看见、听见和推断的内容分配注意力；积极选择说话者、听者、物件或环境承接画面，用机位、光影和切换发展情绪。
- 复杂群戏先在「场景站位」里锁空间锚点、人物位置和轴线，再决定景别变化。
- 起终边界除了逐人姿态，还要写清本镜依赖的身体—物件—空间关系。关系在镜内不变时两端都保留；确需改变时，过程与终点必须有剧本依据。
- 冻结关键帧只写该瞬间能看见的内容；文字、手指、反射和遮挡要可生成。
- 近景类关键帧挂着地点板生成时，图片常被拉宽成中远景；正文写具体取景（画面切在哪、脸在画面哪里、机位距离），出图仍偏宽就这一镜不挂地点板，把背景写进正文。
- 一集的关键帧要像同一部片：每条正文用同一句画风（写实就写写实，不混用「漫剧」「插画」这类会把一部分图拉向插画脸的词），每个场景写同一句光与色温；生成时先出该场景一张中远景作定调图并接受，其余镜头把它作为最后一张参考、只取色调、光线与质感，不取构图。
- 《视觉设定.md》的连续性锁在生效镜头上原样写进冻结关键帧正文；锁面不因“参考图会交代”而省略。
- 检查发现遗漏就直接修正文档，不生成覆盖表来证明自己检查过。镜头块里的「视觉依据」是本镜的依据字段，不属于额外覆盖表。

## 视觉依据与图片

关键帧成稿后，用同一份实际画面清单填写「视觉依据」「图片提示词项」「输入参考图」。三者不得混用：
`IMG-...` 只是提示词条目，`REF-...` 是项目内当前可读的真实图片，`PLAN-...` 是创作者生成时自行挂载的计划。

- 「视觉依据」逐项引用《视觉设定.md》中本镜需要保持身份、造型或地理的可见对象，是必写字段；
  正文点名但未入画的条目标为「画外」，控制范围不超过这一格能承担的事实。
- 没有合适 `IMG-...` 时写「图片提示词项：无」，直接引用视觉设定，不编造 ID。
- 参考图只绑本镜真正需要的内容；待补、创作者自备和明确文生视频必须区分，部分绑定不得丢弃。
- 关键帧需要、但视觉设定尚缺条目的可见物件，用一致描述钉住并报告资产 owner，不伪造视觉依据。

逐字语法、封闭词表、REF/PLAN 示例与缺口写法见[视觉依据与输入参考图规范](references/reference-inputs.md)；
需要填写或修订这三项时读取，不在本主文件重复展开。

## 修订

保留未受影响的镜头 ID。拆镜、并镜或补充设计时，先回写所属来源，再刷新当前完整任务中受影响的资产引用、关键帧与视频提示词。单项修订则明确后续影响，留给接续任务处理。

## 完成

点名范围的原文都有镜头落实，每镜职责不重复、空间与状态连续、起止边界可制作、关键帧可冻结，
每镜「来源」解析到《剧本.md》的真实场景、剧本里每个场景都有镜头承载或已记入「未拍场次」，
且每镜关键帧里的可见人物、地点、道具都在本镜「视觉依据」里，即完成。画面需要的新设计由设计 owner 回填《视觉设定.md》后接续本镜；普通陈设纳入地点整体设计，关键互动道具独立登记。本次请求同时修改
《图片提示词.md》与《分镜.md》时，当轮刷新受影响镜头的引用；不另建覆盖表。
完整制作请求接续视频提示词、生产与成片，发现缺口就回填对应来源后继续。
写完本阶段文档后，可转 `$short-drama` 做局部机械核对（只核对已有文档）；五份齐备后再做完整核对。内容质量仍由创作者审查。
