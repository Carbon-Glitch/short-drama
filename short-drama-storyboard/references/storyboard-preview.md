# 分镜审阅预览

仅在创作者要整集扫读、核对镜头与时长，或明确要求分镜预览时读取。预览从当前 `分镜.md`
派生，不是第六份创作文档，不建立另一套镜头事实，也不要求连续制作停下来等待确认。

## 四列与“完整声画调度”

| 分镜号 | 时间 | 镜长 | 完整声画调度 |
|---|---|---|---|
| 稳定 SHOT ID 与中文名 | 按已声明镜长累计；缺时长则标待核 | 本镜计划时长 | 当前镜制作与观看所需的完整声画事实 |

“完整声画调度”取代容易诱导摘要的“画面重点”，也不采用会诱导无筛选堆字的“全部调度”。
完整指**不漏判断、拍摄和接续所需的信息**，不是穷举无关外貌、资产路径或内部分析。每格依次保留：

1. **目的**：观众实际获得的新信息、感受或观看关系；
2. **摄影**：景别/机位与运镜，包括固定或移动的观看理由；
3. **起点 → 动作与反应 → 终点**：人物位置、双手、持物、关键接触、说话者与承受者、可见反应及切出状态；
4. **声音**：实际声源、画内外关系、完整逐字对白、VO/OS、现场声、音乐与静默；
5. **按需信息**：画面文字、剪辑意图、制作分工与接镜，仅来源已写时加入。

工具直接投影现有 SHOT 字段，不重新概括、压缩或改写。缺字段显示“未写”并给出警告，不能靠预览
补造来源。参考图槽位、视觉依据和工艺检查仍回权威分镜查阅，不在预览中复制。

## 生成与使用

默认输出到终端，不产生项目文件：

```bash
python <套件目录>/short-drama/scripts/storyboard_preview.py <项目>/剧集/<EP>/分镜.md
```

确需交给他人审阅时，显式指定派生文件：

```bash
python <套件目录>/short-drama/scripts/storyboard_preview.py <项目>/剧集/<EP>/分镜.md --output <项目>/剧集/<EP>/分镜预览.md
```

`分镜预览.md` 可随时重建或删除；修订只改 `分镜.md`，随后重新生成。工具拒绝覆盖输入分镜。
直接完整分镜、局部返修或连续制作不必先经过预览；预览通过也不代表表演、声音或媒体效果已经验收。
