# 分镜先为剪辑设计

用于关键对白、证据揭示、动作接触、关系反转，以及“每张画面都漂亮，接起来却不成立”的场次。
普通镜头沿用现有字段，不增加镜数、景别比例或另一份镜头表。

## 先确定相邻镜头怎样交换意义

将同一小段戏看成叙事镜头组：准备/期待 → 触发 → 人物处理与选择 → 行动或确认 → 反应与后果。
只保留本段实际需要的环节；这些环节可以在同一个镜头内发生，不是每环节各拍一镜。
叙事镜头组不是 `GROUP-*` 生产容器：前者组织观看体验，后者只决定一次生成装几个镜头。

从预想剪法倒推最低覆盖：

| 当前剪辑问题 | 分镜需要提供的材料 | 替代与代价 |
|---|---|---|
| 重话落不到人身上 | 听者在准确触发词前后仍有可读反应 | 可在双人镜内调度，不必每句反打 |
| 动作接不上 | 接触前、接触、受力/物件落点与后果的可信状态 | 换角度可以省过程，不能省唯一因果证据 |
| 谜底泄露太早 | 证据何时进入可读范围、确认前谁知道多少 | 反应先行会改变观众对齐；先遮住关键字需保住后续确认 |
| 句中要切给别人 | 可连续的发声和同时发生的听者画面 | 原生混音未分离时，不能假设独立对白轨已经存在 |
| 想用声音桥过场 | 明确声源、人物是否听见、进入/退出的事件 | 提前进声可能提前泄露下一场地点或身份 |
| 素材不够剪 | 适合切出的真实反应、动作细节或空间后果 | 无关空镜、冻结或放大不能替代新表演 |

摄影机运动、人物运动和切镜不要同时争夺同一条线索。需要观众停下来读时可以保持；
需要不安、疏离或有意断裂时，也可以破坏连续性，但说明观众应失去什么、仍必须知道什么。

## 用事件交接，避免只交接秒数

常规状态写在现有“职责、起点、唯一动作、终点、声音”。关键剪口可另加一行可选的 `剪辑意图`：

```text
- 剪辑意图：保留门锁轻扣→她误以为他离开→他回头的确认；“我不走”可L-cut到她松手，不能提前给松手反应。
```

它说明必须保住的事件和可变剪法，不是强制切点或新的剧本权威。没有实际素材时用动作/词锚点；
生成后以真实发声、接触和反应时间决定源窗。未经实测不要把估时写成精确执行承诺。

## 字幕、图形与效果的制作分工

镜头涉及精确文字、图形或效果时，在冻结关键帧和视频提示词之前，选择模型内生成、后期添加或混合制作。
选择依据是叙事职责、修改需求、与人物/光照/遮挡的交互，以及当前执行路径；不要按“动效”二字一概归类。

| 内容 | 常用分工 | 生成前需要落实 |
|---|---|---|
| 对白字幕、片名、人物介绍、系统面板、倒计时 | 后期制作，服从用户选择 | 准确文字、样式来源、画面避让与出现事件 |
| 手机、合同、招牌等剧情文字 | 模型生成或预留后期替换 | 承载面、可读窗口、透视/遮挡，以及人物何时看见并反应 |
| 人物、衣物、环境的实际运动 | 模型生成 | 动作状态、物理关系、表演和现场光影 |
| 发光、烟雾、魔法、冲击等 | 模型、后期或混合 | 谁负责形态/运动、谁负责光照/遮挡，接触与结束状态如何吻合 |
| 强调线、图形转场、局部放大 | 通常后期，按本作表现选择 | 触发事件、作用范围、强度和退出方式 |

分工写进现有SHOT说明；确有跨阶段交接时可用一行可选“制作分工”，不要求每镜填表。例如：

```text
- 制作分工：模型负责拿手机、视线和看到到账后的反应；后期按剧本加入到账界面；手机转向人物时触发；预留可跟踪屏幕与手指遮挡；验收数字可读、透视贴合且反应不早于信息出现。
```

准确文字/样式沿用剧本与视觉设定；前期先锁触发、可读条件和层间关系，精确帧时码跟实际采用素材对齐。
后期负责的文字或效果不提前烘焙进参考图、关键帧或视频；模型仍生成所需承载面、表演及已分配的现场交互。
把文字或效果从产生到可读写清楚：哪镜尚未出现、哪镜发生书写/变化、哪镜供观众确认。后期负责产生过程时，范围同时包括实际书写/变化镜与后续可读镜，跟踪、遮挡和人物反应沿同一时间关系设计。
混合效果可以先用代理验证构图、透视、跟踪和遮挡；必要前提尚未实现时保留待完成，不能只写“后期解决”。
同一效果只在分配的层实现一次，最终核对有无重复文字、双重发光、遮挡错误和触发错位。
“制作分工”是创作说明，不是内置render的执行参数；后期仍须落实为支持的剪辑单字段或真实外部工程。

## 两条节奏线

分别看“事件推进了多少”和“人物真正消化了多少”。信息密度高的场景可能需要让一个反应多停留；
动作少的安静段可能因为答案被扣住而很紧张。不要用统一加速、平均镜长或鼓点决定每一个切点。

比较候选时问：这一次切换是换了一张画面，还是改变了观众正在等待的答案？

涉及预期差时，按已定剧本把“形成/强化预测、识别冲突、重读前文、情绪落地”分配到真实可见/可听的载体；
几项功能可在同镜完成，不按功能数加镜。线索只写在职责里不等于观众能看到；检查构图、焦点、停留、声音和
文字出现条件。后期负责的关键文字/效果，仍按制作分工预留，不能在信息可读前让人物或观众已经完成确认。
把必须保住的理解窗口和反应写进现有职责/剪辑意图，交给后期，避免把重构或兑现误删成冗余。

## 给可剪余量

有实际需要时，在主要动作/台词前后留足可剪余量（handles）：能看清动作启动、完整尾字、反应形成、
环境尾音或相邻接镜。余量随表演、原生时长、执行成本而定，不统一追加固定秒数。
预留余量不是在成片中全部保留，也不授权自动增加付费生成。

## 交给后期的证据

让剪辑者能从本镜现有字段找到：观众应何时确认什么、必须看/听到的事件、相邻镜要保持的状态和允许的替代剪法。
后期把真实采用源窗与取舍写入当前工程，新项目由film.html生成剪辑单，按[分镜落实与精剪](../../short-drama-edit/references/editorial-conform.md)
检查。只有ID齐全、台词齐全或镜头数相同，都不足以证明这段体验完整。
