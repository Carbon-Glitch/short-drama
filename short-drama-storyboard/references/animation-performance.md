# 动画与漫剧表演：姿态、重量、时间与动作可读性

本页只在二维动态漫、国漫、Q 版、水墨、风格化三维或动画表演需要精品精修时读取。
它补充各制作形态卡、冻结关键帧与视频运动规则，不把真人微表演或 AI 真人动力学直接套到动画。

## 先确定动画表演层级

按场次职责选择必要层级，不要求每镜全部运动：

1. **关键姿态**：观众第一眼读到谁、什么关系、哪种行动方向；
2. **重量与平衡**：重心、支撑、惯性和接触是否可信；
3. **时间与间距**：动作何时准备、发生、停止，速度变化是否服务注意；
4. **表演策略**：角色通过姿态、距离、视线和动作争取什么；
5. **次级运动**：衣物、毛发、道具、环境是否回应主行动，而非独立抢戏；
6. **效果与镜头**：线条、色块、粒子、景深和运镜是否帮助读取主动作。

静态漫剧可以由关键姿态、局部循环、声音和剪辑完成叙事，但不能用镜头移动假装人物已经完成动作。

## 姿态与剪影

先删掉细节检查轮廓：头、躯干、双手、道具和视线方向是否仍能说明行动？同阵营角色应在比例、
重心、姿态习惯和形状语言上可区分，不只靠发色或服装颜色。

关键姿态要能从起点到达终点：若人物将推、接、躲、护或停住，起止姿态必须留下动作发生的空间。
冻结关键帧只写当前瞬间，不把预备、接触和结果同时塞进一格。

## 重量、支撑与接触

重量不是把动作写得更大，而是让观众知道力从哪里来、经过哪里、落到哪里：

- 站立或移动时，重心由哪条腿/哪个支撑面承担；
- 推拉、提放、接取时，物件何时开始影响身体；
- 接触时，手、物件和目标的关系是否明确，松手后谁承托；
- 惯性停止时，身体、衣物或道具是否需要不同步的跟随。

风格化形态可以夸张或简化物理，但规则要一致。Q 版缩短肢体后，不照搬真人手指交接；
水墨与二维可用形状、笔触和节奏替代复杂接触，但不能省略剧情需要的归属变化。

## 时间与动作组织

从戏剧职责选择动作组织，不把 anticipation/follow-through 当每镜必填：

| 需要 | 可选组织 | 失效信号 |
|---|---|---|
| 动作必须一眼读懂 | 清楚起姿 → 主要动作 → 明确落点 | 过多预备和回弹淹没主动作 |
| 峰值需要强调 | 缩短关键瞬间、改变姿态对比或停顿 | 所有动作都夸张，峰值失去差异 |
| 日常表演需要真实 | 小动作、不同步反应、必要保持 | 每个部位同时启动，像机械拼接 |
| 喜剧需要时机 | 建立预期、延迟结果、让反应错位 | 用快切解释笑点或重复到失效 |
| 静态漫剧需要连续 | 关键姿态、声音桥、局部循环、剪辑承接 | 只有推拉拉近，人物状态不变 |

动作间距与速度由角色意图、重量、景别和模型能力决定，不套统一帧数或每秒动作数。

## 表演与口型

动画表演先写角色目标与行动，再选面部和肢体通道。避免把情绪拆成通用“高兴/生气/悲伤”素材包；
同一人物的压力应改变其惯常姿态、视线策略、动作完成度或与他人距离。

口型先保住台词、发声区间、说话人和表情策略。风格化形态不需要逐字真实口型，但开合、停顿和声音
不能互相否定。近景唇形不可靠时，可用反应、画外、背影或剪辑覆盖，不能改成别人说话或删除必要台词。

## 次级运动与效果层

衣物、毛发、粒子、笔触、光影和环境分别回应主行动、人物状态或空间变化。次级运动可以在主行动后
错开落点，但不为“画面丰富”让全部元素同频摆动。效果层不能遮住脸、手、接触点、证据和画面文字。

## 投影与验收

分镜写清关键姿态、支撑、主动作、接触和落点；视频提示词按目标形态写可执行变化，保留画风、
比例和识别锚点。生成后正常速度检查：

- 只看剪影能否辨认人物与行动？
- 重量和接触是否可信，松手后物件为何仍悬空？
- 动作是否同时启动、同时停止，导致机械或幻灯片感？
- 口型、声音和人物策略是否一致？
- 静态漫剧的镜头运动是否掩盖了人物没有表演？

## 方法来源与边界

动作时间与动画原理参考 Richard Williams《The Animator’s Survival Kit》；动画人物行动参考
Ed Hooks《Acting for Animators》；重量、平衡和动作分析参考 Chris Webster
《Action Analysis for Animators》。这些原理按形态、题材和执行端裁剪，不把十二原则当逐镜检查表，
也不要求 AI 视频通过堆砌术语自动获得重量与表演。
