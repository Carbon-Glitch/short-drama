# 体验与视觉总设计

**剧本给了我们什么好东西？拍成这部片，我们还能给观众什么？** 从最值得发挥的地方下手：可以是演员一个出人意料却合情合理的反应，可以是一套让人没见过的视觉世界，可以是声音先把观众带进一个误会，也可以只是一个美得让人舍不得切走的瞬间。和照常拍相比，选那个让观众多感受到一点、而你真舍不得换掉的做法。把它写成下一岗位拿到手就能拍、能画、能听见的决定。用更好的形式展现剧本的内核，只要不违反内核都可以大胆改编、想象。

丰盛或克制，大多数时候默认精致，由内容与观众决定。

先读[共同创作方式](../short-drama/references/viewer-first.md)与[场面体验设计](references/scene-design.md)。视觉结构、近期原作、成像和模型资料按当前问题读取，同轮复用。

## 进入

剧本就绪后，本次所需分镜或实际资产图缺一项就先执行本阶段。已有方案先判断复用与缺口，普通设计由 Agent 自主选择，完成后接文本分镜。

    python scripts/design_tool.py inspect <集目录> --project-root <项目根>

读取缺口与设计版本。独立单集可省略 project-root。只有提示词或挂图计划不等于已有实际图片；当前来源已完成设计时接续下游。

## 设计流程

1. **把戏改到值得拍。** 抓住人物想要什么、为什么难、最终的选择意味着什么，保住跨场因果和创作者明确锁定的内容。在这个内核里，场内的行动、对白、阻碍、揭示顺序和笑点落法由你择优改写。一句话把委屈说尽了，可以让人物做一件嘴上不肯承认的事；原稿那句话本就精彩，就把反应留给听的人。结合既有图与制作条件选拍得出来的版本。沿用已有的现实观众基线；没有证据的判断作为创作假设，不冒充观众事实。
2. **先写体验设计。** 在《视觉设定.md》的 `## 体验设计` 中确定：
   - `观众入口`：目标观众已经知道什么、熟悉哪些表达、预计故事会怎样发展；
   - `情感心脏`：最重要的关系或人物需求，以及观众从什么感受走向什么感受；
   - `持续期待`：开场尽早立起的具体问题、愿望或隐忧，以及它怎样接力到后续期待；
   - `知情与预期`：观众何时领先、同步或落后于人物，哪里满足、延迟、误导或反转，哪个兑现接着改变局面。
   这些是指南针，不是另一份审批表；小项目几行写清即可。
3. **把观众放进场面里。** 可以先让观众发现人物还没察觉的东西，也可以陪人物一起看错。选一个动作、一句没说完的话或一个反复出现的声音，让它第二次出现时变了意思。
   用 `- 情绪节奏：`写开场期待 → 中途兑现/升级 → 新局面与下一期待 → 结尾情绪落点；用 `- 信息与注意：`写释放/扣住的信息、密度变化和注意落点。每次兑现都要留下后果，关键人物选择要有承担；证明同一件事的信息若不再改变关系，就合并或换成真正的选择。
4. **先比较表达，再让视觉参与叙事。** 新视觉方向与关键场次先把最容易想到的常规方案作为基线，再发展少量观看机制不同的方案：例如改变观看位置、空间与表演归属、信息释放、声画关系或时间组织。沿情感心脏、持续期待、注意和节奏选择最有力量的一版，不自动取中间方案。普通场次直接作具体选择，不机械增加方案数量。
   用一句能拍出来的视觉主张统领人物、空间和道具，把选中机制、观看收益和下游必须保住的表现写进现有「设计重点」；再设计视觉怎样随关系、权力、信息或情绪发展：统一的是物理世界，变化的是构图、距离、遮挡、焦面、受光、反射、声音和细节密度。留下观众能带走的画面，不让每镜都争抢“海报感”。已有真实生产授权且方向尚未验证时，优先用少量代表帧或短运动段看样，不用批量生产替代方向选择。
5. **给关键人物、道具或场景定造型。** 先想观众第一眼会记住什么。主人公穿什么、屋子怎么摆、一件道具怎么用，都可以把台词没说透的那层关系拍出来。比如父亲送女儿去寒地，临走只嫌她穿得少，却把她外套的小拉链头换成了一圈红绳。到了风里，她戴着厚手套，一勾就拉上了。关键设计如果还像随手找来的通用款，就再想一种长相或用法，挑最能演出这场戏的。把选定的造型和用到它的那一刻写进「设计重点」，交给资产图和分镜。
6. **需要比较时看真实原作。** 定位当前设计问题，实际查看入选图片或片段，拆出空间、光学、材质、行为和节奏机制，再组合转译。成熟方向直接复用，不在每个阶段重复泛调研。
7. **安排时间与资产。** 从人物眼下要做的事里找调度。两个人客气地说“你先走”，可以让他们同时伸手去按电梯的开门键，把客气演成一场暗争；也可以让一个人松手，看另一个人肯不肯进来。选最让人想看下一拍的演法。把决定观众能否看懂这一拍的造型或状态交给资产，镜头和调用分组交分镜。
8. 改了“发生什么、谁说什么”，直接写回本集工作稿《剧本.md》的对应场次，保留场次 ID；“长什么样、怎样演出来”写进《视觉设定.md》。用户原件留在「输入/」；工作稿若是唯一原件，先留存原文。已有分镜或生成提示词时，按改动的场次同步台词、动作与受影响的资产需求。

## 输出：《视觉设定.md》，场内改编落入《剧本.md》

- `## 体验设计`：观众入口、情感心脏、持续期待、知情与预期。
- 项目视觉主张、视觉发展、真实观察范围与简短设计转译。
- `## 场面设计 · EP001-SC001`：情绪节奏、信息与注意、新调度、物品表演、声音与出入状态。
- `## 人物|造型|地点|道具 · 名称`：可见设计、画面代称、识别锚点、造型与状态。
- “影像风格”写共同物理光源、色彩与质感方向，条件性效果写成“当前状态 → 具体对象上的可见结果”。
- `- 调度设计：`记录采用的新事件/动作；`- 设计重点：`记录重要结果、需要看清的方式及主体资产/镜头/动态承接；`- 声音重点：`记录声音落点。
- `## 资产实现`由资产阶段登记最小资产包、采用图和后续补充的控制素材。

沿[五份文档](../short-drama/references/creator-documents.md)写引用。分镜同时读取本集当前工作稿与体验/场面设计，主体资产按分镜的实际可见需求制作。完成后运行：

    python scripts/design_tool.py complete <集目录> --project-root <项目根>

记录来源版本并接续下一阶段。实际效果由图片与视频观察判断。

## 完成判断

观众为什么看、从哪里感受到什么、继续期待什么已经明确；剧情、人物与视听的钩子各有兑现，兑现后的后果能接续新期待。场面有信息释放、人物选择、注意落点与密度变化，关键情绪有承担。视觉主张具体、有辨识度，并随故事发展；人物、场景和关键道具具备复用依据，后续图片以实际生成需要为准。
