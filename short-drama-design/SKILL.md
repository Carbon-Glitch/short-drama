# 体验与视觉总设计

本阶段是全片的**审美发动机**。下游分镜、生图和视频提示词只做忠实物理执行，不负责替你补救平庸——如果这里给的是安全常规解，整集就会彻底沦为无记忆点的流水线作品。
按当前问题读取 [场面体验设计](references/scene-design.md)；视觉结构、原型拆解与成像资料按需读取，同轮复用。

## 1. 进入与检查

剧本就绪后，分镜或本次所需实际资产图缺一项即先执行本阶段：

```bash
python scripts/design_tool.py inspect <集目录> --project-root <项目根>
```

独立单集可省略 --project-root。已有方案先判断复用与缺口；只有提示词或 PLAN 不算已有实际图片。用户锁定的核心设定、身份与对白原封保留；所有未锁定的视觉、空间、造型与调度维度，必须由你给出鲜明、有取舍的作者级决断，严禁自动退回“稳妥、对称、平视、均匀打光”的平均值。

2. 防死板四步法（强制跳出安全区）

第一步：立体验心脏与场内可拍化改写

在保住跨场因果和用户锁定事实的前提下，把“站着嘴炮解释”改写为“行动、视线、道具与声画反差”。在《视觉设定.md》的 ## 体验设计 用四行写透：

观众入口：目标观众对这类题材的惯性预判是什么？前 3 秒靠哪一个具体画面、反常动作或先入声音破局？
情感心脏：人物真正渴望/恐惧什么？观众从哪种心理体感走到哪种余韵？
持续期待：开场抛出的具体悬念/渴望如何一环扣一环接力？
知情与预期：观众在哪一拍领先、落后或被误导，哪次兑现立刻改写局势？

沿用已有的现实观众基线；缺少真实证据的判断标为创作假设，不冒充市场事实。

第二步：核心场次先“内部毙掉庸俗版”，再做单边取舍

对全片视觉定调及每个核心场次，禁止直接采用第一反应的常规拍法，在构思中先完成对比再落盘：

内部淘汰基线：先在草稿阶段识别该题材最容易想到的普通拍法（如“客厅对坐平视正反打 + 均匀暖白光”）并明确淘汰；为防负面词汇污染下游提示词，被淘汰的常规细节不写进最终正稿，只把淘汰方向记在策略理由中。
异质路线对比：构思 2 套在空间结构、视角站位、光影性格或声画机制上真正不同的拍法（日常过渡场次沿全片视觉语法直接定稿，不机械凑数）。
最终决断与主动牺牲：选出最抓人、最贴合题材且散场后最难忘的一版，严禁折中调和；并在该场写入一句硬承诺——主动牺牲：为了把 [核心爽感/笑点/张力] 推到极致，本场主动放弃 [某项常规稳妥需求]（如“放弃正打全脸与大环境交代，全程借桌面反光与紧贴手部的特写推进”）。

第三步：用“硬物理杠杆”锁死高辨识度视觉主张

用一句有态度的导演陈述统领全集（可参考具体影视/摄影/美术流派的视觉机制做转译，但必须落实为物理描写；风格服从题材，甜宠/喜剧/温情同样需要鲜明的构图秩序与光色美感）。

以下 5 项硬物理规格 必须填实写入视觉主张、「影像风格」及各场「设计重点」：

60 / 30 / 10 色彩纪律：写清 60% 环境底色、30% 主体色、10% 唯一高辨识度钩子色（具体到色名+材质），并点名本片主动收敛或排除的杂色。
单一物理主光与反差性格：写清光源实体、入射方位、局部照度衰减与明暗宽容度（哪怕明快轻喜剧，也要有通透的侧逆天光方向、清晰材质高光与干净色阶层次，绝不使用无方向均质平光）。
成像介质与光学脾气：明确唯一主导介质（如 35mm 胶片微粒与自然肤质 / 变形镜头柔和滚落 / 纯二维手绘墨线与矿物平涂）及本场主导镜头语言（如“广角贴脸喜剧张力 / 长焦压缩剥离 / 前景遮挡窥视 / 极致对称固定 / 固定框内纵深”中选定 1–2 项）。
至少 1 组“材质反差对”与造型记忆点：人物、空间与核心道具拒绝图库默认款，安排肉眼可辨的廓形、色彩呼应或材质碰撞（如“轻盈亮丝绸裙 vs 粗糙干枯红砖墙”“冷灰西装 vs 亮黄复古电话”）。
物理调度障碍物 / 正在进行的动作：每个核心场次给人物安排至少 1 个空间阻隔、高低落差、光区进退边界或正在做的具体动作，用身体和物品演戏，不空手站桩念词。

写法锚点（严禁写左栏，必须落到右栏跨题材颗粒度）

不合格（空洞套话，直接重写）    合格（下游生图/分镜无法磨平的物理规格）
“画面富有高级感与甜蜜浪漫氛围，人物造型精致，光影柔和唯美。”（甜宠/轻快）    “60% 奶油暖白粉刷墙 + 30% 低饱和丹宁蓝工装 + 10% 高饱和明黄鲜花桶；唯一主光为画右高窗斜射的清晨暖阳（带百叶窗条纹阴影）；两人隔着一张摆满水杯的窄吧台传纸条，全程借前景玻璃杯折射制造暧昧遮挡。”
“调度自然流畅，通过眼神交流展现人物内心纠结与暗涌的压迫感。”（戏剧/悬疑）    “主动牺牲双人同框正脸：林晚背对镜头站在窗边叠信，镜子只切出她发白的指节；丈夫停在门外阴影里半步不进，直到门缝冷光带切过他鞋尖才开口。”

第四步：严守双文档改写边界

改了“发生什么、谁说什么、声音事件是什么” → 直接写回本集工作稿《剧本.md》对应场次，保留场次 ID（用户原件留在 输入/；工作稿若为唯一原件先备份原文）。
“长什么样、光怎么打、机位态度、新调度与物品表演” → 写入《视觉设定.md》。
若已有真实生产授权且新风格尚未验证，先用 1～2 张代表帧或短样片验品味，不用批量盲产代替审美决策。已有下游分镜/提示词时，按改动场次同步受影响条目。

3. 输出结构（《视觉设定.md》）

沿五份文档写引用，包含：

## 体验设计：观众入口、情感心脏、持续期待、知情与预期。
项目视觉主张（含视觉坐标转译、60/30/10 色彩纪律、主光反差、成像介质、主动牺牲策略与避坑边界）。
## 场面设计 · EP001-SC001：
- 情绪节奏：（开场抓手 → 中途兑现/升级 → 新局面与下一期待 → 结尾余韵）；
- 信息与注意：（释/扣信息、密度变化与注意落点）；
- 调度设计：（物理阻隔、空间权力移动、光区进退与正在进行的动作）；
- 设计重点：（本场主动牺牲、核心视觉记忆点、材质反差对、硬光色要求及资产/镜头/动态承接）；
- 声音重点：（先声夺人、环境声退让、静默留白与声画错位落点）；
- 出入状态：（本场结束后人物、道具、空间与信息状态怎样交给后段）。
## 人物|造型|地点|道具 · 名称：可见设计（轮廓、色彩占比、材质与非默认记忆点）、画面代称、识别锚点、造型与状态。
「影像风格」：严格按硬物理规格填写；条件性光效写成“当前状态 → 具体对象上的可见结果”。
## 资产实现：留交资产阶段登记最小资产包、定调代表图与采用图。
分镜同时读取本集当前工作稿与体验/场面设计，主体资产按分镜实际可见需求制作。

4. 完成与接续

完成后运行：

```bash
python scripts/design_tool.py complete <集目录> --project-root <项目根>
```

记录来源版本并接续 $short-drama-storyboard。

自检红线（任一条不满足即原位返修）：
故事期望闭环是否成立（看点、情感心脏、持续期待、信息后果与出入状态各自清楚）？
抽掉全部形容词后，只看物理名词（色名、光源方位、材质、前景物、站位动作），这一场是不是依然画面鲜明、绝不平庸？
是否明确写出了本场主动牺牲的稳妥需求，且视觉主张贴合题材气质（不把轻喜剧硬凹成阴沉风，也不把强冲突拍成大平光），可被下游 100% 物理落地？
