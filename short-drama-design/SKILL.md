# 视觉创意与场面设计

**默认设计强度：除非需求明确指定极简、留白或其他克制风格，主动把画面发展得好看、精致、细节丰盛，视听语言丰富，以信息密度较高的优秀电影场面与爆款短视频为创作参照。** 在人物妆造、空间陈设、材质光色、前后景活动、物品行为、声音层次与调度变化中形成持续可发现的看点；以清楚的主次、注意转移和张弛组织这些信息，让丰富度转化为吸引力。写实或手机拍摄质感同样沿用这一默认。

把简单剧本发展成漂亮、独特、有想象力、细节与节奏具体的作品。先读[创作方式](../short-drama/references/viewer-first.md)、[近期原作与跨作品转译](references/recent-work-design.md)、[视觉结构](../short-drama/references/visual-structure-and-art-direction.md)与[场面设计](references/scene-design.md)，同轮复用。

## 进入

剧本就绪后，本次所需分镜或实际资产图缺一项就先执行本阶段。已有方案先判断复用与缺口，普通设计由 Agent 自主选择，完成后自动接资产安排、出图和分镜。

在技能目录运行：

    python scripts/design_tool.py inspect <集目录> --project-root <项目根>

读取缺口与设计版本。独立单集可省略 project-root。只有图片提示词、挂图计划或空分镜不等于已有实际产物。当前来源已经完成过本阶段时接续其下游；新剧本、新设计或制作方向变化时更新设计。

## 设计流程

1. 读故事内核、用户明确保留的人物/对白/视觉方向，以及既有图和制作能力。把真正保持的内容与可自由发展的空间分开，先提出具体视觉主张。
2. 搜近期优秀原作，拆出形态、色彩、材质、空间、物品行为和节奏方法，跨作品组合后做本作微创新。内部比较并选定有力方向；成熟方案复用。
3. 设计人的具体样貌、妆发、衣着、动作气质、声线与说话方式；设计场所的结构、陈设、光色与环境活动；设计道具的外形、机构、交互与性格。写实通过可信材质、光影、重量和接触呈现大胆构想。
4. **设计新调度**：围绕观众注意、预期和情绪增补事件、干扰、反应、沉默、物品动作、画内图形与声音。将“谁触发→谁怎样处理→发生什么→观众获得什么”写具体。资产的漂亮设计与角色行为互相加强。
5. 用整场节奏取舍：先按[模型与接镜](../short-drama/references/model-aware-coverage-and-joins.md)考虑较长连贯生成段的容量，H3优先13–15秒、Seedance 2.5优先接近30秒，具体镜头与调用分组交分镜落实。刺激、反应、升级、停顿与兑现怎样变化，哪些动作和对白并行，哪些细节值得单独看见。杯子落下、蚊子打断、沉默或嘲讽动图都可成为选择；选对本场最有收益的组合，而非把所有点子塞满。
6. 将选定设计写回同一《视觉设定.md》，给出代表画面意图与图像/动态实现重点。新状态沿场面交接传给后段。出图后根据真实效果返修这份设计，再扩展制作。

## 输出：仍是一份《视觉设定.md》

- 项目视觉主张与简短参考借鉴/设计转译。
- 二级标题“场面设计 · EP001-SC001”：对应原剧本场次，写情绪节奏、新调度、物品表演、声音与出入状态。
- 二级标题“人物|造型|地点|道具 · 名称”：沿现有语法记录可见设计、画面代称、识别锚点与状态。
- 用“- 调度设计：”记录采用的新事件/动作，“- 设计重点：”记录重要视觉结果，“- 声音重点：”记录声音落点。这些进入后期交接；“- 情绪节奏：”和参考说明帮助下游理解取舍。
- “## 资产实现”留给资产阶段登记出图安排与采用图，创意继续在上面的条目维护。

沿[五份文档](../short-drama/references/creator-documents.md)写引用。分镜同时读取剧本场次与这里的场面设计，图片提示词读取同一人物/场景/道具条目。新增调度成为导演依据；原剧本来源、锁定对白与内核仍可追溯。

完成后运行：

    python scripts/design_tool.py complete <集目录> --project-root <项目根>

记录已执行的来源版本，接续返回的下一阶段。记录只保存指纹，正文仍只在视觉设定。实际图像/表演是否成立由出样观察判断。

声音设计可按需查[声音方向](../short-drama-assets/references/voice-direction.md)，造型、空间与摄影方法沿共享影视知识；记录实际参考时区分声音身份与本场表演。

## 完成判断

选定方向在造型、空间、材质或行为上有具体而独特的设计，场面已从抽象对话发展为可看见的过程；原剧情与新增设计的关系清楚。Agent 在授权范围内选方案和迭代，已有参考和知识复用，按缺口补查。
