# 体验与视觉总设计

**剧本给了我们什么好东西？怎么拍，才能让观众第一眼被吸住、沉浸下去、看到最后还舍不得切走？**
先抓住最打动人、也最能立住差异化的地方下手：可以是一个出人意料却直击心坎的微表情反应，可以是一套让人眼前一亮的色彩与造型设计，可以是声音先一步制造出的错愕或心动，也可以是一个高级得让人屏住呼吸的瞬间。和“照常平庸地拍清楚”相比，选那个**更抓人、更有审美记忆点、在同类短剧或短视频里一眼出挑**的做法——并把它写成下一岗位拿到手就能拍、能画、能听见的明确决定。只要守住故事内核与观众情绪体验，形式、造型和视听语言都可以大胆想象与设计。

**质感与风格原则：风格必须服从内容与观众，可浓烈张扬、可明快轻盈、可细腻温润、也可冷峻克制；但无论哪种风格，都拒绝没有主见的“平庸均值感”与“廉价大平光网剧风”。** 高级影视感不等于生硬炫技，而是把每一分视觉和声音的控制力，精准花在让观众更入戏、更享受的地方。

先读[共同创作方式](../short-drama/references/viewer-first.md)与[场面体验设计](references/scene-design.md)。视觉结构、近期原作、成像和模型资料按当前问题读取，同轮复用。

## 进入

剧本就绪后，本次所需分镜或实际资产图缺一项就先执行本阶段。已有方案先判断复用与缺口；未锁定细节由 Agent 按全集视觉主张主动定调（过场同样维持一致的电影质感，不敷衍降级），完成后接文本分镜。

    python scripts/design_tool.py inspect <集目录> --project-root <项目根>

读取缺口与设计版本。独立单集可省略 project-root。只有提示词或挂图计划不等于已有实际图片；当前来源已完成设计时接续下游。

## 设计流程

1. **把戏改到更有看头、更好看。** 抓住人物想要什么、为什么难、最终选择意味着什么，保住跨场因果和创作者明确锁定的内容。在这个内核里，场内的行动、对白、阻碍、揭示顺序和笑点/爽点/痛点落法由你择优改写。**优先用行动、视线、道具和声画反差去演，少用台词硬解释；** 嘴硬心软时让人物去做一件暴露真心的事，原稿那句话本就精彩就把反应空间留给听的人。结合既有图与制作条件选最顺畅、最有感染力的版本。沿用已有的现实观众基线（知道观众熟悉什么、厌倦什么，从而精准给到新鲜感与满足感）；没有证据的判断作为创作假设，不冒充观众事实。

2. **先立体验骨架，锁定观众为什么愿意停留。** 在《视觉设定.md》的 `## 体验设计` 中精炼写清：
   - `观众入口`：目标观众已经知道什么、对这类内容预设怎样的走向，以及开场靠什么打破惯性或瞬间共情；
   - `情感心脏`：核心关系或人物欲望的真正支点，以及观众从什么情绪体感走向什么情绪余韵；
   - `持续期待`：开场尽早立起的具体问题、渴望、悬念或奇观吸引力，以及它怎样一环扣一环接力到后续期待；
   - `知情与预期`：观众何时领先、同步或落后于人物，哪里给到满足、延迟、误导或惊喜反转，哪个兑现接着改变局面。
   这些是指南针，不是审批表；几行写透本质即可。

3. **用期待、反差和声画配合把观众拉进场面里。** 可以让观众先看见人物还没察觉的破绽或温柔，也可以借声音、构图先把观众带进一种预期，再漂亮地拐出新意；选一个动作、一句没说完的话或一个反复出现的声音，让它第二次出现时味道完全变了。
   用 `- 情绪节奏：`写开场抓手 → 中途兑现/升级 → 新局面与下一期待 → 结尾情绪落点；用 `- 信息与注意：`写释放/扣住的信息、密度变化和注意落点。每次兑现都要留下后果，关键选择要有承担；冗余信息能删就删，把注意力留给真正改变关系和情绪的那一拍。

4. **多方案比出高下，确立高辨识度的视觉主张。** 关键视觉方向与核心场次，先摆出“最容易想到的常规安全拍法”作为参照，再发展少量观看机制和审美路数真正不同的方案（例如改变视角站位、空间结构、色彩与光影性格、声画节奏或信息揭示顺序）。沿情感心脏、停留吸引力与视觉新意选最有感染力的一版，**不自动折中取中间方案**；日常过渡场次直接沿同一视觉体系给出干脆的决定，不机械凑方案数。

   用一句能落地、有审美态度的话统领人物、空间与道具，并落实三项**决定影视高级感的硬规则**（写入视觉主张、「影像风格」及对应「设计重点」）：
   - **色彩与光影秩序（告别平庸出厂光）**：明确主色调、点睛色与需要避开的俗套配色；写清主光方向、冷暖层次与明暗反差性格——哪怕是明亮轻快的戏，也要有通透的光影方向和质感层次，而不是惨白均质的大平光；
   - **空间、景深与镜头性格**：视觉随关系、权力、亲密度或情绪推进而变化——统一的是物理世界与审美基调，变化的是构图松紧、前景遮挡、焦段与景深虚实、反光质感与信息密度。**拒绝“每一镜都硬拗海报感”破坏流动体验，但要求画面始终具备电影级的构图讲究、空气感与叙事意图**；
   - **视觉验证**：已有真实生产授权且方向尚未验证时，优先用少量代表帧或短运动段看样，不用批量盲产替代审美选择。

5. **做出跳出“图库默认款”的造型、空间与视觉记忆点。** 先想观众看这部片时，第一眼会记住什么、散场后脑子里会留下什么画面？服化道与空间不仅要真实可信，更要敢于为气质和情绪做**有辨识度的艺术强化**——可以是克制日常里的一处绝妙反差，也可以是高度风格化的色彩与空间奇观：
   - 写实情感戏，不必靠昂贵奇观硬凹，但可以在质感、色彩呼应和细节设计上做出精准记忆点（例如冷清素净的房间里一只格格不入的亮色旧物、雨天里被车灯和霓虹揉碎又重组的光斑倒影）；
   - 风格化、喜剧、奇幻或强冲突题材，更要放手在**色彩碰撞、空间尺度、服装廓形与反常道具行为**上迈出更大胆的一步，挑出最能一眼抓住注意力、演出人物性格与戏剧张力的那一版。
   把选定的造型特征和用到它的高光时刻写进「设计重点」，交给资产图和分镜。

6. **必要时拆解真实高水准原作（用真实品味拉高上限）。** 遇到容易流俗或需要建立强风格的题材，实际查看高水准电影、摄影或优质短片案例，拆出它的空间、光学、材质、造型与节奏机制，再做贴合本片的转译，不靠干瘪的形容词堆砌。成熟方向直接复用，不在每个阶段重复泛调研。

7. **从人物动机和空间关系里长出灵动的调度。** 好的调度既自然贴合人物当下的真实处境，又在画面上极有戏味和观看乐趣。不要满足于人物干站着轮流说台词；多利用**空间阻隔、距离拉扯、视线回避、光线明暗进退、或手中正在做的日常/特殊动作**，把客套、试探、暗恋、压迫或荒诞感直接演出来——选最顺畅自然、又最让人想看下一拍的演法。把决定这一拍成立的造型或状态交给资产，镜头与调用分组交分镜。

8. **严守双文档改写边界。** 改了“发生什么、谁说什么”，直接写回本集工作稿《剧本.md》的对应场次，保留场次 ID；“长什么样、怎样演出来”写进《视觉设定.md》。用户原件留在「输入/」；工作稿若是唯一原件，先留存原文。已有分镜或生成提示词时，按改动的场次同步台词、动作与受影响的资产需求。

## 输出：《视觉设定.md》，场内改编落入《剧本.md》

- `## 体验设计`：观众入口、情感心脏、持续期待、知情与预期。
- 项目视觉主张（含色彩光影基调与避坑边界）、视觉发展、真实观察范围与简短设计转译。
- `## 场面设计 · EP001-SC001`：情绪节奏、信息与注意、新调度、物品表演、声音与出入状态。
- `## 人物|造型|地点|道具 · 名称`：可见设计（轮廓、材质、色彩性格与记忆点）、画面代称、识别锚点、造型与状态。
- “影像风格”写清共同物理光源、明暗反差性格、色彩秩序、光学/景深质感（**禁止用“精致好看”这类空洞笼统词替代具体光影和色彩设计**），条件性效果写成“当前状态 → 具体对象上的可见结果”。
- `- 调度设计：`记录采用的新事件/动作/空间调度；`- 设计重点：`记录核心记忆点、视觉/造型硬要求、需要看清的方式及主体资产/镜头/动态承接；`- 声音重点：`记录声音落点与留白设计。
- `## 资产实现`由资产阶段登记最小资产包、采用图和后续补充的控制素材。

沿[五份文档](../short-drama/references/creator-documents.md)写引用。分镜同时读取本集当前工作稿与体验/场面设计，主体资产按分镜的实际可见需求制作。完成后运行：

    python scripts/design_tool.py complete <集目录> --project-root <项目根>

记录来源版本并接续下一阶段。实际效果由图片与视频观察判断。

## 完成判断

观众为什么会被吸住、从哪里产生真实情绪体感、又被什么钩着往下看已经明确；剧情、人物与视听设计各自成立且流畅推进，没有为了凑节奏而堆砌生硬套路。视觉主张既贴合当下题材的观众期待，又成功跳出了同类作品的平庸默认值——有明确的光影、色彩与造型辨识度，人物、场景与关键道具具备可复用且好看的视觉记忆点，后续图片以实际生成需要为准。
