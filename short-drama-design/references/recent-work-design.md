# 近期优秀参考 → 跨作品组合 → 原创设计

剧本后的设计阶段集中寻找近期优秀原作，拆方法、跨作品组合并发展本作的视觉与调度。后续沿用选定设计与来源；设计需要更新时在这里补充检索。

## 时效与取证

以运行时真实日期为基准，优先近30–90天；优质同类不足再扩到近一年及经典。窗口用于发现，不淘汰优秀旧作；相近质量与适用性时选更新的。原发布/首映、改版、展览与检索日期分开记录；抓取日、转发日和页脚年份不当作品新近证据。未知就写未知，经典明确标旧作。

沿“故事需求＋设计难点＋当前年月”搜索，再向相邻领域扩展。给物品设计人格，可从广告/动画延伸到机械装置、时装廓形、舞台与建筑，不只搜索同一种产品。优先创作者原账号、工作室/品牌案例、官方预告和幕后；聚合站用于发现，再追原作。

实际打开入选页面并看可访问的图片/片段，视觉设计比较以这些真实观察为依据。只有文字时，可采用作者明确讲过的方法，同时继续寻找可观察原作；仍只能取得文字就标注证据范围并交付草案。访问失败就换可访问原作，不凭标题或作者声誉想象画面。旧经验与小样本不能冒充当前普遍效果。

## 本轮检索范围

根据本场缺口找造型、美术、空间、物品表演、视觉包袱和情绪节奏参考；让不同来源承担不同维度。已有成熟方向复用，按新设计缺口补查。方法、来源与选法写回同一视觉设定，交给资产图、分镜和后期接续。

## 拆方法，再组合

为入选参考识别有用机制：轮廓怎样抓眼、材质怎样对照、功能怎样变成隐喻、物体怎样表达意图、空间怎样揭示、声音怎样带动作。数量随难点，不强制每阶段凑数。

跨作品组合，让不同来源承担不同维度：例如 A 的空间尺度 + B 的材质与服饰 + C 的物品动作逻辑；用本作统一的色彩、时代、材质与拍摄方式收拢。再改一个能产生新体验的变量：功能、运动机制、空间关系、使用方式或尺度，而不只是换名字/颜色。原作角色、标识与具体情节不是自动带入项。

在现有文档简记：

`- 参考借鉴：作品/作者｜原作链接｜发布日（未知则写未知）｜检索日｜实际看到了什么/只读到什么。`

`- 设计转译：借 A 的…与 B 的…，用本作的…统一；新增…；落实到 IMG/SHOT 或声音/图层…；为何比普通方案更值得看。`

这是可读说明，不是新必填 schema。最终只留下影响决定的来源；未用链接留工作区。技法借鉴与上传参考素材分开，继续沿既有媒体来源/工具路线生产。

## 用画面决定采用

比较主体资产、必要的代表图或试生成片段与选定视觉目标：第一眼焦点、形态比例、光色、材质层次、空间趣味与独特性是否在实际结果里成立。身份相同、画面清晰只是基础；普通但没错的图不是默认母版。指出缺的设计，回到参考机制重组后迭代，保留强项。

Agent 在已有授权与成本范围内比较并选择，不把每个参考/候选变成确认问题。跨题材复用“找→拆→组合→出样→取舍”，不复用统一的暖灯旧物、霓虹雨夜或规整构图。

## 方法来源与刷新入口

[BUCK 案例](https://buck.co/work)可发现角色、广告、图形与声音表达；[Design Museum / LAIKA](https://designmuseum.org/exhibitions/laika-presents-wildwood-the-exhibition)展示视觉研究到服装、木偶、布景的制作链。这些是入口和方法例子，不是固定推荐榜；每个项目仍按当日日期找适合的新作。

离线时用时代错位、材料尺度反差或正经外壳与荒诞内核发展原创；不虚构近期原作与观众证据。
