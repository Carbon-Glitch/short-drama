# 人物设定图与 Look Variant

## 身份测试

人物设定图保持一个已接受身份和一套相容 Look，不混用互斥的服装、发型、伤势、年龄或风化状态。
共享定义见[Character / Look 共享概念](../../short-drama/references/character-identity-and-look.md)。

## 输入与分层

输入包括已接受身份、一个准确 Look、用途、视觉风格、构图、背景/光线和来源指针。

- Character 可选年龄区间与体态、面部轮廓、固定发质/发际、永久特征和长期配饰；
- Look 写发型整理、服装穿法、鞋、妆面、临时配饰、污渍/水/血/新伤和服装损坏；
- delta 写相对 base 的变化、原因/生效位置和结束范围；
- 姿态、表情范围和视图数量依用途决定，不固定三视图或表情格。

先写剪裁、层次、领口/袖口、材质与主次色，再写“职业感”“落魄”等抽象效果。

服务多参考视频时，优先按用途拆出单人肖像与全身板；多视图拼板仅在明确需要且入口验证可用时采用，避免被误解为多个角色。板型选项见[参考板示例](ai-character-sheet.md)，质感规范只沿[通用配方](common-recipe.md)。

## 构图方法

1. **身份板**：中性全身或三分之二身，显示比例与一套 Look；可有少量正/侧细节，但均为同一时刻、同一 Look。
2. **面部识别板**：头肩为主，用立体柔塑识别光保留骨相阴影与自然肌理，避免平光磨皮；发际与轮廓完整；不承担服装全貌。
3. **服装 Look 板**：全身正面与必要背面/局部，突出层次、穿法和鞋；面部保持身份，除非明确只做服装，不换无脸 mannequin。
4. **状态板**：展示同一 Look 的因果差异，如雨后湿袖、包扎左腕；不默认塞入“前后对比”。

身体不要被道具、极端透视或强烈运动遮住关键特征。背景与光线服务识别，默认简洁中性，可由视觉方向覆盖。
表情依用途：身份板可平静或低强度角色态；表演测试可给有限范围，但不混入不同剧情时刻。

配饰写佩戴位置、尺度、材质和 Look 归属；交互需要的包袋、容器登记形制与携带位置。
角色板不承担剧情动作，手持剧情道具仍归道具状态。

提示词顺序：

```text
用途 + 身份锚点 → 当前单一 Look → 构图/视图/姿态/表情
→ 材质与主次色、识别友好光线 → 简洁背景 → 保持与排除
```

“23 岁”若来源只写“二十多岁”，不得假精确。身体描述以可见生产需要为限，避免无关物化细节。

## Look/state variant

Variant 不是完整身份重写，先复用 Character anchors，再突出 delta：

- **基准**：`CHAR-* + LOOK-base` 的精确引用；
- **变化**：位置、范围、材质/颜色，如“右袖肘以下被雨淋深一度，肩部仍干”；
- **保持**：脸、发际、体态、未变服装结构和未受影响区域；
- **连续性**：起因、有效场景/镜头范围及下游绑定。

瞬时表情或姿势由 storyboard/keyframe 拥有，不新建 Look；要改变身份事实先回 assets，不用 edit prompt 越权。

## 输出与审查

失败征兆：同时写制服和便装、受伤和无伤、干发和滴水发；不同视图变脸换衣；只有“年轻漂亮、电影感”；
强戏剧阴影遮住识别特征；把一次手持物、表情或站姿永久写入身份。

| 问题 | 分类 | 证据 |
|---|---|---|
| exact Character/Look 是否解析 | `structural_invariant` | `视觉设定.md` 的可见 ID 与当前变体 |
| 是否只有一个连贯 Look | `reviewed_invariant` | Look 字段与 prompt 对应句 |
| 是否保持区别性身份 | `reviewed_invariant` | Character anchors 与画面描述 |
| 泛化美词是否挤压锚点 | `craft_default` | 可删词与缺失事实 |
| 姿态/背景是否适合 | `craft_default` | 用途与构图 |
| 表情强度、板式数量 | `taste_option` | 创作者/视觉方向 |

最终在 `图片提示词.md` 产生一个 `IMG-...` 人物板条目和自足正文；不产生图片。

## 形态与模板

形态决定用什么词汇画，不决定画的是谁：

- 形状语言与比例影响身份锚点的表达颗粒度；
- 线条、表面和材质响应对应材质、主次色与识别友好光线；
- 身份层、服装可动层和效果层影响构图与保持/排除；
- 面部、剪影或线条识别通道影响锚点选择与视图数量；
- 形态不改写 Look 组成、有效范围、持有物、文字政策和故事状态。

模板默认值与身份冲突时身份优先。并排检查提示词，删除不能追溯到当前视觉设定的重复审美句。

| 检查 | 分类 | 证据 |
|---|---|---|
| 形态是否只落在词汇层 | `reviewed_invariant` | 形态卡字段与正文对应句 |
| 锚点在形态下是否可见 | `reviewed_invariant` | 识别通道与所选锚点 |
| 模板是否覆盖身份 | `reviewed_invariant` | 跨角色重复句与当前视觉设定 |
| 未决形态影响哪些描述 | 沿用所涉 `IMG` 规则等级 | 只挂起依赖该选择的通道、材质或分层；其他事实继续，真实分叉交创作者 |

伪装只改变本次Look：保留骨相、发际与体态，用服装穿法、局部遮挡和妆发形成新读法；不要把伪装身份当成另一个角色重新生成。
