# 图片提示词阶段契约

负责《图片提示词.md》的 IMG 条目，把当前美术设计变成可见画面。发现设计缺口时回填视觉设定再接续；通过明确参考用途让身份、造型、空间和风格共同成立。

| ID | 用法 |
|---|---|
| IMG-01 | 每张图明确所用资产、造型、状态与图像职责。 |
| IMG-02 | 用实际轮廓、空间、材质、光色和构图表达设计。 |
| IMG-03 | 人物图沿用既定身份，完整设计当前妆造。 |
| IMG-04 | 场景母版有清楚地理和完整陈设；用角色入景帧验证组合。 |
| IMG-05 | 道具图表现形制、尺度、材质、功能、使用痕迹与文字需求。 |
| IMG-06 | 定向修改说明目标、变化与保留项，更新关联使用。 |
| IMG-07 | 可读文字与项目文字处理方式相容。 |
| IMG-08 | 参考图判断来自实际看图或明确的来源说明，区分已见与待看。 |
| IMG-09 | 参考按真实用途分配身份、造型、地理、风格或构图职责。 |
| IMG-10 | 同一时空的光源和空间关系一致，变化随当前设计更新。 |
| IMG-11 | 主体资产优先复用；代表图、关键状态细节图与关键帧按实际控制需要制作并进入对应生成任务。 |
| IMG-12 | 真实参考沿 REF 槽位保存顺序、路径、名称与控制范围，换图更新绑定。 |
| IMG-13 | 已有连续性锁按适用范围传递，由机械检查核对。 |
| IMG-14 | 用途字段使用现有词表：身份/造型状态/地理/构图/尺度/效果/起始帧/结束帧/风格。 |

以真实图像中的人物、世界、注意力和观看乐趣评价创作；路径、引用、字面冲突由工具校验。细节可以来自本轮美术设计，记录在所属条目中。
