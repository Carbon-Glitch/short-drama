# 通用资产图片提示词配方

## 1. 目标与输入

资产图片首先服务后续生成，也体现本作的美术设计。提示词要同时做到：**身份准确、设计忠实、成像具体、消费位置明确。** 主体资产让人物、场景与关键道具可复用，代表图和关键帧按实际控制需要补充。

开始前读取《视觉设定.md》的准确条目、当前变体、设计重点、资产安排与已有 REF。先确定本图承担什么，再展开正文；普通成像选择由 Agent 主动完成。

- 绑定准确资产、造型、状态与图像职责。
- 把设计重点转成可见的轮廓、空间、材质、光色与构图，不用质量口号代替。
- 可读文字与项目文字政策相容。
- 参考图内容来自实际观察或明确来源说明。
- 每张参考只控制声明的用途。

## 2. 先定主体、状态与消费位置

从上游提取四类信息：

| 信息 | 要作出的选择 |
|---|---|
| 稳定设计 | 身份、地理、形制、持久材质与识别锚点 |
| 当前版本 | 妆造、开合、污湿、损坏、屏幕、持有关系及有效范围 |
| 复用需求 | 哪些人物、场景和道具会跨镜头出现，必要角度是什么 |
| 本图职责与消费位置 | 进入哪次生成，负责身份、造型状态、地理、风格、构图、效果或具体帧位 |

先完成人物/造型、场景、关键道具及必要状态的主体资产。人物条目中的鞋、袜、首饰、妆面和发型配件按实际景别分配承接；重要设计由本图正文、实际 REF 或对应镜头继续兑现。

代表图、关键状态细节图和逐切关键帧由真实控制需求触发。计划生成时写清它将进入哪次生成，而不是为了资产包完整多出一套图。

## 3. 从设计到可复制正文

按自然叙述组织以下内容，不机械显示栏目：

1. **用途与主体**：这是什么图，拍谁或什么，验证哪个设计重点。
2. **稳定身份与设计**：轮廓、比例、识别特征、地理或结构关系，以及本作独有的视觉构想。
3. **当前状态**：这一刻真实成立的妆造、位置、开合、接触与可见变化。
4. **构图与光学**：机位距离和方向、透视观感、主体占比、前中后景、焦平面、景深与虚实主次。
5. **光色与影调**：光源、方向、软硬、补光、阴影、黑位、高光、肤色及背景分离，写到具体对象。
6. **材质与感官**：不同表面的粗糙度、反射、透光、纤维、磨损、空气、接触阴影和尺度参照。
7. **背景与文字**：环境或空场政策，以及可读文字、符号、空白或后期承载区。
8. **参考与修改**：各 REF 的控制范围；局部修改写清变化与保留项。

通用骨架：

```text
[图像用途与代表状态]，[主体及稳定设计]，此刻[准确的造型/位置/开合/接触]。
[机位距离与方向、透视、主体占比、前后景和焦面]；[主光如何落到具体对象，暗部与高光保留什么]。
[各类材质如何受光，空气/接触/尺度怎样可见]；[背景与文字处理]。
```

删掉空项和重复形容，把句子写成当前画面独有的视觉说明。焦段、光圈等词可提示外观，同时写出想得到的透视、焦外和高光表现。

## 4. 按图种展开

- `character_sheet`：同一身份与一套 Look；完整呈现脸、廓形、妆发、服装层次、鞋和配饰。识别友好光线下仍写出面料、皮肤和工艺差异。
- `location_plate`：入口、路径、功能区、固定锚点与陈设形成可读地理；前中后景、生活痕迹、空气和光源共同建立空间。
- `prop_plate`：轮廓、比例、功能机构、材质工艺、使用痕迹与当前状态清楚；尺寸配合中性参照或已知结构。
- `look_state_variant`：从基准身份发展当前差异，写清生效状态、材质响应和未变部分。
- `scene_moment`：按需的风格/构图代表图。新视觉方向需要比较时，用完整入景画面检验人物、空间、光色和行为关系；选定后作为风格/构图参考或结束一次筛选。
- `key_state_detail`：按需的关键状态细节图。用合适尺度和焦面证明微小结构、修复、屏幕、接触或材质变化，并送入需要它的生成任务。
- `frame_anchor`：按需的逐切关键帧或首尾帧，投影指定 SHOT 的准确边界，绑定对应切点或接续关系。
- `edit_delta`：准确目标与区域、可见变化、保留项及连续性影响，优先保留已采用图像的强项。

## 5. 成像维度要写成关系

| 维度 | 具体写法 |
|---|---|
| 透视与构图 | 摄影机离主体多远、从哪里看；主体占多少；前景遮挡与后景信息怎样组织注意 |
| 焦面与景深 | 哪个物体、哪只眼睛或哪个细节清晰；背景还需读出什么；关键动作是否落在可读的焦面 |
| 光与影调 | 光从哪来、软硬如何；哪侧脸/哪块衣料/哪件道具接光；阴影保留什么纹理，高光在哪里溢散或收束 |
| 材质对比 | 湿缎面形成连续窄反射，粗呢保持哑光，拉丝金属出现方向性高光，透明塑料让内部层次透出 |
| 色彩与密度 | 主次色、明暗与饱和度怎样分配；重复形状和小面积亮点怎样形成节奏，细节在哪里密、在哪里歇 |
| 空气与接触 | 蒸汽由哪束光显出，脚底怎样接触湿地，杯底与桌面是否有接触阴影，物件重量靠什么变形或受压表现 |
| 尺度 | 用同图中的已知物体、功能尺寸或中性参照表达大小，微距同时交代它与整体的关系 |

这些维度按画面职责选择，重要设计必须落到具体可见关系，而非统一追加“真实、触感、柔和高光”。

## 6. 共同 Look 按状态投影

共同 Look 保持物理光源、色彩关系和质感方向一致。每张图再根据**当前机位、对象位置、遮挡与开关状态**写出实际受光，不复制全场通用句。

```text
闭门：琥珀灯只在玻璃内腔与窄反射中出现，手脸由冷白顶灯照亮。
开门递衣：同一盏琥珀灯随开口照到衣服和托衣的手，门角度改变反射位置；顶灯与冷窗光不变。
人物转身：缎面高光随衣料移动，背景光源位置不变。
```

状态变化同时检查材质反射、阴影方向、屏幕亮度、空气显形和相邻帧连续性。空景把光写在建筑、陈设与地面上；人物、手和脸的受光只在他们实际入画时描述。参考板的中性识别光只负责该板，场景与代表帧采用自己的剧情光态。

## 7. 参考、文字与定向修改

每个 REF 使用现有完整槽位语法，写清顺序、路径、名称、用途、控制与不得控制。身份、造型状态、地理、构图、尺度、效果和风格各尽其职；实际看图后登记 `visually_inspected`，只有可靠来源说明时登记 `creator_described`，其余保持 `unverified`。

基础资产进入视频生成或所选起始帧时，当前画面需要的身份、妆造、地理和形制由 REF 或正文明确继承。PLAN 只说明未来如何挂图，设计是否保住要在实际图像返回后判断。

文字沿两层选择：

| 资产来源政策 | 本图呈现 |
|---|---|
| `exact_readable` | `readable` 逐字呈现，或 `postproduction` 预留承载区 |
| `graphic_only` | `symbolic` 保留图形职责 |
| `no_readable_text` | `blank` 或不可读的 `symbolic` |
| `pending_creator_text` | `postproduction` 暂存承载区，内容到位后再读 |

输入图已有冲突文字时，通过裁切、清理、遮罩、替换或后期路线处理。可读内容与承载面始终同时成立。

局部修改用四件事组织：**Target / Change / Preserve / Continuity impact**。保留已采用的身份、构图、材质和未受影响区域，改后重新比较设计重点与几何状态。

## 8. 完成与真实图像检查

- `IMG-...` 条目包含用途、准确视觉依据、参考字段和 `### 可复制提示词`；正文不含内部 ID、路径或流程说明。
- 回读最终正文，确认重要设计有句子、实际 REF 或明确的镜头承接；状态与景别相容。
- 本次生成需要的主体资产已经齐备，每张图都有明确消费位置；代表图、细节图和关键帧与当前控制问题对应。
- 图像返回后先看漂亮与独特，再看身份、设计、构图、光色、材质、空间和状态。需要修改时保留强项，定向迭代并刷新采用版本与下游绑定。
