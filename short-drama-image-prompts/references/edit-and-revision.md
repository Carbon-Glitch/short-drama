# Scoped Edit 与自然语言修订

局部修改的目标是把已采用图像修得更好，同时保住它最有价值的身份、设计、构图与材质。普通视觉调整由 Agent 在现有授权内比较并选择；改变用户锁定的身份、故事或实质成本时再确认。

## 1. 两类修改

- **图像 edit**：基于真实 REF 修改指定对象和区域，输出新的采用候选。
- **提示词 revision**：修改当前 `IMG-...` 的生成表达，并同步受影响的参考与镜头。

身份、固定地理或故事状态需要改变时，先回《视觉设定.md》的对应条目更新，再刷新图片和分镜。光线、材质、局部造型与构图的 ordinary lookdev 可直接探索，选定结果回写来源。

## 2. Edit-delta 配方

```text
Target：哪个真实 REF、对象和区域？
Change：改成什么可见结果，位置、范围与程度如何？
Preserve：哪些身份、设计、构图、光色、材质与未影响区域保持？
Continuity impact：对应哪个状态，影响哪些 IMG/SHOT/MOTION？
```

变化要可观察。例如“右袖肘部以下被雨浸深，布料贴住手腕但无撕裂；脸、服装剪裁、右肩干区、背景和机位保持”。

一次修改聚焦一组相关变化。需要整体重建时新开代表帧或状态版，不用“全部保持”掩盖大范围改图。

## 3. 按目标模型组织输入

- 使用目标模型支持的自然语言、参考槽位与局部编辑方式；参考图分别声明身份、造型、地理、构图、风格等职责。
- 把已经采用且需要保住的图像作为编辑输入，正文说明允许改变与仍需保持的内容。摄影参数写成想得到的外观，不冒充精确物理控制。
- 其他模型的专有语法只在当前模型明确支持时使用。比较模型时保持同一设计、参考与评价标准。

## 4. 执行与比较

1. 读取当前《视觉设定.md》、IMG 条目和真实采用图，确认修改针对当前版本。
2. 保留原采用版，生成局部候选；比较修改区域和整体画面，而不只检查目标点。
3. 检查身份、几何、当前状态、设计重点、材质与相邻参考是否仍一致。局部变好但整体普通或连续性受损时继续调整。
4. 采用后更新同一 IMG 的正文、REF 版本和受影响 SHOT/MOTION 绑定；未被修改的 ID 与有效设计继续沿用。

自然语言请求“更有电影感”时，Agent 将其发展为本图具体的光比、透视、焦面、色彩或材质方案，交付选定正文与实际结果，不停在抽象选项上。

## 5. 完成检查

- 目标、变化、保留项与连续性影响清楚。
- 修改使用当前真实图片与目标模型支持的输入，原采用版可追溯。
- 新图经整体观察，设计与身份没有因局部修复而丢失。
- 采用版本、提示词和下游引用同步；实际媒体生产与任务记录交 `$short-drama-produce`。
