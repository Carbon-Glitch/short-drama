# 本地导演台

为个人创作者和小团队完成一集作品：创建或导入项目 → 编辑剧本 → 设计与资产 → 分镜/画布 → 生成与选片 → OpenFilm剪辑 → 成片及可编辑项目导出。

## 使用方式

- 左侧按剧本、视觉设计、分镜、资产、视频制作、剪辑交付切换；顶部选择项目/剧集。场景只在剧本与分镜内部组织。
- 中央随阶段展示对应产物；分镜默认文本镜头表、可切分镜墙；创作画布是独立跨阶段工具，同一对象共享身份与选择状态。
- 右侧显示选中对象及Agent操作；任务队列按需展开。
- 自动保存、撤销、重开恢复；冲突保留两方内容供选择。
- 生成前展示输入、范围和可取得的费用信息，实际执行沿任务有效授权。
- 新版本与当前采用版并排比较，采用和替换可撤销。

## 数据边界

前期结构化实体以项目内 `.short-drama/state/project.sqlite` 为权威；Markdown是可读投影。外部修改Markdown作为待导入变更，不静默覆盖实体。OpenFilm仍拥有film.html/VTT/镜头页的后期编辑事实，应用通过适配器读取与修改，不复制时间线权威。

项目、集、场、角色、造型、地点、道具、对白、镜头、提交单元、素材版本和剪辑绑定拥有独立不可变ID。依赖带来源版本和使用字段；改名不会触发无关重生成。历史快照固定实体与引用版本。

持久记录放state，派生缩略图、波形等放cache。本机端口、凭据与运行时放用户目录。旧项目导入副本，用户原件不变。

## 完成验收

- 普通用户可以创建、导入、关闭和继续一个项目，无需CLI。
- 剧本与镜头可以编辑、自动保存、撤销，重启后草稿仍在。
- 修改角色显示名不断引用；修改对白只标记受影响的依赖，未相关镜头不变。
- 多Agent并发写入不会静默覆盖，用户能比较冲突并恢复。
- 分镜以文本规划为主，视频制作以生成单元与可播放回片为主；独立创作画布连接素材、生成条目与结果，操作同一套对象。
- 实际生产任务能提交、显示真实状态、失败恢复和比较回片，不以模拟状态冒充执行。
- OpenFilm可进入、返回、继续编辑；原有剪辑事实保持。
- 导出成片、可编辑单集/系列、历史备份分别工作；项目搬目录后依赖可用。
- 清缓存不丢批注、采用、任务、历史或绑定。
- 在真实浏览器中验证主流程、空态、冲突、失败和恢复。

## 实施顺序

1. 项目实体、版本、事务、依赖、草稿、导入和可读投影。
2. 场景工作台、分块编辑、分镜墙与画布。
3. Agent命令、现有生产适配器与OpenFilm连接。
4. 导出恢复、启动入口和完整真实项目验收。

交互修订依据与阶段映射见 design/interaction-research.md；旧场景侧栏方案已撤回，保留底层实现。
