# 主动导演：情绪体验与高级影视表达

各阶段以漂亮、独特、有想象力的设计为基础，再用表演和剪辑兑现体验；设计方向沿[视觉与场面设计](../../short-drama-design/SKILL.md)，执行手艺按[知识入口](craft-knowledge.md)查用。表达决定写回所属创作文档；新项目后期写入 film.html/VTT/镜头页，剪辑单由工程生成。

## 导演目标：让观众经历鲜明的情绪与电影体验

积极运用摄影、场面调度、表演、光色、声音、转场与剪辑，追求鲜明、精确、有记忆点的观看体验。大胆选择表达的角度与强度，让技巧产生紧张、期待、惊奇、爽感、亲密、荒诞、震撼或余韵。感官吸引、美感、气氛与形式节奏本身也是成立的创作收益。

先确定观众从什么感受走向什么感受，随后选择最有力量的视听方案。导演主动完成授权范围内的表达取舍，将新决定落回现有分镜/设计；已确认的剧情、准确对白、人物身份和用户明确保留的形式是创作依据。

成像与声音的感官层同样主动设计：色彩/影调、光学观感、局部注意、表面纹理、时间稳定性和声音空间，按[成像风格与感官质感](image-look-and-finishing.md)落实到生成与后期各自的执行位置。

## 场次构思先于逐镜填写

把一场戏作为完整体验设计：吸引进入→建立期待→蓄压或反差→释放/转向→余韵。每个阶段决定观众与谁同在、看见多少、听见什么、等待什么。喜剧、动作、抒情和悬疑各自拥有速度、幅度与停顿。

对关键场面主动构思有差异的观看方案，比较空间调度、主观视点、信息揭示和声画节奏，再选择更有情绪力量的一版。可以让一个连续镜头经历多次重构图，也可以用强烈切换、时间省略和蒙太奇重新组织体验。将取舍简写在已有场次说明中，直接推进选定方案。

## 主动选择镜头语言

| 表达方向 | 可以大胆运用的技巧 | 落地决定 |
| --- | --- | --- |
| 压迫、疏离、权力变化 | 极端机位、偏置构图、负空间、框中框、长焦压缩、前景遮挡 | 观众站在哪里，人物占多少空间，距离/遮挡怎样变化 |
| 亲密、主观、不安 | 越肩贴近、主观镜头、跟身机位、手持迟滞、焦点呼吸、焦点交接 | 摄影机与谁同呼吸，关注如何偏移和重新抓住 |
| 规模、惊奇、沉浸 | 低机位广角、纵深调度、绕行揭示、升降、穿行、速度变化、复合运镜 | 从哪种尺度进入，经过什么前景，怎样揭开空间并落幅 |
| 突袭、爽感、荒诞 | 甩镜、急推急拉、变焦、倾斜机位、冲击重复、定格、跳切、速度重映射 | 击点、幅度、加减速、反应与声音瞬态 |
| 隐瞒与发现 | 遮挡揭示、反射构图、深焦双层行动、延迟反打、画外信息 | 先让观众看见什么，何时改变理解，揭示后留给谁 |
| 抒情、触感、视觉记忆 | 光色对照、逆光轮廓、材质特写、轮廓匹配、重复构图变奏、慢动作 | 哪种感官细节被放大，色光与节奏怎样发展 |

技法可以组合成完整句法：前景遮挡→侧移形成视差→主体回望→焦点交接→落到远景反应。写清机位、取景、路径、速度曲线、构图变化和停点；在目标画幅上检查重点是否可读。相机品牌、镜头/胶片风格词可以作为风格线索，同时给出要得到的透视、景深、运动模糊、高光与颗粒表现。

## 转场在分镜阶段成对设计

将出镜与入镜共同设计，而后分别写入各自镜头。记录两端的画面关系、动作阶段、声音和执行分工。

| 转场/剪辑技巧 | 前镜与后镜共同准备 |
| --- | --- |
| 动作匹配 | 动作阶段、方向、速度、接触点与两端可用余量 |
| 图形/构图匹配 | 轮廓、位置、尺度、色块、视线重心以及匹配带来的联想 |
| 遮挡/隐形切 | 遮挡物覆盖方向和时机、后镜揭开路径、运动延续 |
| 甩镜/运动衔接 | 两端运动方向、加减速、模糊区间和后镜重新抓住主体的落点 |
| J/L cut与声桥 | 实际声源、开始/延续位置、画面中的听者或反应、声音距离 |
| 硬切/跳切/蒙太奇 | 对比或省略的内容、情绪击点、观众凭什么理解新的时空关系 |
| 叠化/叠印/主观过渡 | 两层画面如何重叠、持续多久、光色/运动怎样形成记忆或时间感 |

将可生成的表演、构图和摄影写入H3，将剪接、重映射、图层、精确音效和调色写入既有剪辑工程。生成段长与最终剪辑镜长分别规划。需要额外覆盖、干净音轨或过渡余量时提前安排素材。

## 场景生命、注意转移与声画节奏

让主角、听者、环境、相机和声音共同表演。根据地点和已建立活动，主动设计持续背景、人物间的反应延迟、接触反馈、材料余动、光影/反射和画外世界。为层次写清对象、方向、强度、触发或持续条件、并行关系及收束。

以速度、景深、构图、光比和声音远近组织主次。场景可以繁忙、平静、突然停住或与主角情绪相反；在落点前后主动安排运动和声音的增减。先听后见、声画反差、环境撤出、瞬态强调、音乐进入/骤停与尾声延续都可成为表现手段。

固定镜头用画内调度、纵深和声音创造张力；运动镜头让空间、视点和注意连续变形。整场的远近、快慢、动静、密疏形成变化，选中的母题通过重复与变奏积累感受。

## 以观众体验选剪法

后期主动重组镜序、表演、反应、时长与声音。对关键段落比较不同剪法，可整体调整画面、音乐与节奏形成完整版本；定位单一故障时再隔离变量。以“哪一版更吸引、更有冲击、更有余味，观众如何接收到它”选择采用。

使用真实素材与实际字音/帧时钟落实操作，既有CUT/EDIT保存选择、效果参数、声画关系和采用区间。超出内置渲染能力的技巧使用真实外部剪辑/合成工程执行；把需要补拍的内容落实回素材计划。

## 实际回看

在正常速度、目标画幅和音量下看听完整段落，核对情绪起伏、注意转移、视觉记忆点、反应与余韵；观察到的失败按时间码定位并修到实际出口。分别记录设计意图、实际实现和用户反馈。未生成时交付的是导演方案与提示词，效果结论来自真实媒体。
