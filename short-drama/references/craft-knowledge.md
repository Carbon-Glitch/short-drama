# 按问题查影视工业知识

各阶段先用本机已有手艺资料解决当前问题，按需查网上作者/机构的一手方法、官方工具文档与制作拆解。知识重适用性与证据，不因年份旧就丢掉成熟技法；模型/API/软件接口按当前版本核实。

| 当前问题 | 本机入口 |
|---|---|
| 故事、人物策略与场面 | [剧作手艺](../../short-drama-write/references/script-craft.md)、[场次节拍](../../short-drama-storyboard/references/scene-beats.md) |
| 视觉结构与成像 | [美术结构](visual-structure-and-art-direction.md)、[成像与质感](image-look-and-finishing.md) |
| 资产身份、状态与可复用图 | [身份与变体](../../short-drama-assets/references/identity-vs-variant.md)、[代表帧](../../short-drama-image-prompts/references/lookdev-frame.md) |
| 调度、构图、覆盖与接镜 | [镜头手艺](../../short-drama-storyboard/references/shot-craft.md)、[剪辑覆盖](../../short-drama-storyboard/references/editorial-coverage.md)、[模型与接镜](model-aware-coverage-and-joins.md) |
| 模型执行 | 视频提示词技能的目标模型方言、生产技能的对应 adapter 文档 |
| 剪辑、声音、图形与交付 | [精剪](../../short-drama-edit/references/finishing-craft.md)、[声音叙事](../../short-drama-edit/references/sound-narrative-and-music.md)、[OpenFilm执行](../../short-drama-edit/references/openfilm-workflow.md) |
| 判断实际作品 | [质量证据](../../short-drama-review/references/quality-ladder.md)、[审查方法](../../short-drama-review/references/review-method.md) |

只读能改变当前决定的部分，同轮复用。线上检索用具体问题，例如“动作切中方向与动作阶段如何匹配”“屏幕替换怎样处理遮挡和玻璃反射”，而不是每个阶段重新找视觉风格。能实际观察的样例再写观察结论，文字教程只支持其明确说明的方法。

剧本后的视觉主张、近期原作检索、跨作品组合与新调度由[视觉创意与场面设计](../../short-drama-design/SKILL.md)集中组织。其他阶段把选定设计落实成自己的产物，遇到设计变化回到同一视觉设定更新。
