# 导演台 · 自动制作时看见真实产物

沿用 OpenFilm Studio，同一入口可看正式项目、仅有剧本的新集和只有图片、声音、成片的外部目录。它读取项目文件，不依赖对话历史，也不需要上传素材或另配模型。

## 打开与实时监测

Windows 可双击技能目录 scripts 下的「打开导演台.cmd」，选择一个项目目录。跨平台用：

    python scripts/dashboard_server.py --workspace "<项目根>" --open

浏览器登录态不一定互通。第一次在 Codex 内置浏览器打开时，同一命令将 --open 换成 --browser-link，在两分钟内用目标浏览器打开它返回的一次性本机地址。命令在接收导航或到期后退出。不要把普通 /api/.../desk 地址当作首次登录入口。

省略 --open：登记并在后台开始监测；已开页面可在项目下拉框或「监测另一个目录」切换。文件通知合并约 0.3 秒，另有约 2.5 秒的磁盘复查。打开「项目动态」查看当前集或全项目；总览可看其他已登记项目最近一次变化。订阅断开会自动重连。未在播放或编辑时自动更新产物，正在播放、阅读或编辑时保留位置和草稿，动态照常出现。关闭标签后，只要本机 Studio 进程仍在运行，已登记并启动的监测就继续。Studio 停止期间，重新打开只能对照前后落盘状态；多次覆盖同一文件无法从最终文件倒推出每次修改。

动态区分两种证据：文件新增、修改、删除；以及 Agent 自己署名的进展回执。正文类文件显示修改附近的行和摘要；大文件及图片、视频等二进制产物展示文件变化。历史保留最近 400 条/项目，界面可查看近 100 条；日志归本机 Studio 运行目录，不是剧情或审批文档。

## 从其他 Agent 接入

Codex、豆包、Kimi 或其他客户端只要有权读写同一个项目目录，导演台都能看到落盘结果。另一台设备可用同步目录，延迟包括同步耗时；不要求它们安装 OpenFilm。仅在网页对话里输出、没有共享目录或同步，不会被本机读到。界面不会读取私聊、隐藏思考或猜测执行者身份。

阶段开始、完成或重要改动时，在工作所在机器运行标准库脚本（路径为技能包中实际位置）：

    python scripts/director_signal.py "<集目录>" --actor Kimi --stage Design --change 调整 --message "把评分和自批午休设计成同一角色的两个状态" --artifact "视觉设定.md"

阶段：开发、剧本、Design、分镜、资产、投产、回片、剪辑、交付；变化：开始、调整、完成、等待、返修。只在真实执行时署名；已有产物才填 --artifact，可重复使用。没有 Python 但能保存文件的 Agent，可把同样的 JSON 作为 UTF-8 文件写到 <集目录>/.short-drama/progress/<32位小写十六进制唯一ID>.json，使用临时文件后改名，防止读到半条回执：

    {"id":"与文件名相同的32位ID","actor":"实际执行者","stage":"Design","change":"完成","message":"本次实际交付","paths":["视觉设定.md"],"at":"带时区的ISO时间"}

同步时包含这些进展文件。不同客户端不必写共享数据库。导演决定由同一台本机 Studio 管理；跨机器执行付费生产时须能读取最新导演决定，不能用各自独立的目录冒充已放行。

## 控制与交接

- 按阶段阅读和修改现有工作稿，查看有来源的原稿差异、原图、音色、镜头卡和实际提交内容。分镜墙可按时长播放；没有图片的镜头仍然有文字卡。没有生产证据的素材明确区分。
- 素材可以并排/滑动比图，同类音视频可同步对照。声音可看波形、定位并圈段回听。选定用途可记录采用版本；“替换绑定”预览涉及的正式文档，再把同一 REF 槽指向新文件。不会重写历史提交或触发重生成。
- 留意见时指定 owner、起点及可选终点。系统在本集 .short-drama/director-media 保留所注版本。同名文件覆盖后仍可回看旧意见，明确解决或重新打开。导演看过画面和听过声音分开登记。
- 锁定文档/原句及按阶段设置“到此等我”。确认与当前输入版本绑定，上游改变即需复核。Agent 进入下一阶段先运行 director_desk.py gate <集目录> <集号> <目标阶段>；退出码 3 表示等待。生产 run 在适配器调用前核对；带回片暂停时先试拍，再等导演决定是否扩拍。正式 OpenFilm 导出也核对前序暂停，预览不冒充交付。私自绕过 Skill 直接调用供应商的程序不受这个入口控制。
- 有导出回执的成片可按当前播放时间回查 CUT、原始素材时间、SHOT、场面、参考与实际提交。先校对导出文件和来源指纹；外部成片没有回执时只当外部片看。换片源通过原生 OpenFilm 修改接口保留源区间并执行长度与锁轨检查。
- 决策存本集 .short-drama/director.sqlite；只记录人工选择，不是第二份剧本或时间线。项目动态保存在本机专用 OpenFilm state/director-history，图片原件和成片仍由项目所有。
## 项目资料库与分栏审阅

左侧按项目、集与阶段切换。项目资料库可直接载入一个项目/外部素材包，也可添加短剧存放父目录；列表约每 5 秒发现其中的新项目（按 short-drama.json 或五文档中的剧本/视觉设定识别，扫描最多五层）。已有项目的同级目录自动纳入发现范围，不扫描整块磁盘。

剧本和设计按章节切换；资产可筛选图片和声音；回片/交付优先展示播放器，右侧分别处理来源、导演意见、采用与验收。原始文档仍可展开编辑。进入 OpenFilm 后顶部保留“返回导演台”，回到同一集的剪辑阶段。
