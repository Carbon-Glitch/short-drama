# Creator-first 工作流

## 当前主链

剧本 → 观看承诺与体验设计 → 表达机制比较/大胆选定 → 注意力与剪辑分镜 → 导演体验审读 → 最小主体资产 → 全能参考视频提示词与试生成 → 保住选定表达并按失控点补控制 → OpenFilm剪辑。

表达比较发生在现有设计阶段，不新增方案文档或审批；常规拍法可以参选，但只有最服务观看价值时才采用。

分镜后按[导演体验审读](../../short-drama-review/SKILL.md#分镜后的导演体验审读)检查期待、兑现、注意与视听吸引，最强处保留，重要问题原位修完再展开资产和提示词；不新增创作文档。
需要整集扫读时，从当前分镜派生[完整声画调度预览](../../short-drama-storyboard/references/storyboard-preview.md)；它只是可重建视图，不新增权威或确认闸门。

代表图、关键状态细节图和逐切关键帧按实际生成需要选择；普通多镜不预先生成整套首帧。

已有成熟产物可接续。进入制作时，分镜或本次所需实际资产图缺一项先执行设计；当前来源已经完成设计时复用结果，推进缺失的下游。阶段由design_tool inspect结合真实文件与设计来源版本判断。

## 五份创作文档

| 内容 | owner | 文件 |
|---|---|---|
| 故事、原句与场次 | short-drama-write | 剧集/<EP>/剧本.md |
| 观众体验、视觉主张、人物场景、新调度与信息密度 | short-drama-design | 剧集/<EP>/视觉设定.md |
| 期待与注意路径、镜头覆盖、文本画面、clip分组与按需关键帧 | short-drama-storyboard | 剧集/<EP>/分镜.md |
| 最小主体资产、参考安排与采用图 | short-drama-assets | 视觉设定末尾「资产实现」 |
| 主体资产与按需控制图片的生成表达 | short-drama-image-prompts | 剧集/<EP>/图片提示词.md |
| 目标模型执行提示词 | short-drama-video-prompts | 剧集/<EP>/视频提示词.md |

创作正文保持这五份。设计的场面章节对应原场次；资产实现只登记怎么出图与实际采用。新调度随视觉设定传给图片、分镜、提示词和后期，变化原位更新。

设计执行指纹保存在.short-drama/design-pass.json，生产与剪辑沿已有运行记录。它们记录来源版本和状态，创作内容仍由Markdown拥有；剧本、创意设定、已有设计参考或制作方向变化会使设计版本过期，登记资产实现不会让流程反复回到设计。

## 接续与输出

按用户点名范围持续推进，普通美术与调度选择由Agent完成；已有授权覆盖的生产接续。范围或成本实质扩大、改变锁定内核时再说明选择。

分镜同时读取原剧本与场面设计；来源使用原SC ID，视觉依据继续引用人物/造型/地点/道具。新事件和停顿进入SHOT，实际生成段与成片窗口分开规划。调度、视觉与声音重点进入OpenFilm交接，实际源窗在film.html。

说明跟随项目语言。图片正文按项目prompt_language；视频按已选模型语言/方言。对白语言与可读文字保持来源。模型、时长、参考方式和画幅沿short-drama.json已定配置，输入能力按执行路线核实。

各阶段按[影视工业知识](craft-knowledge.md)查手艺；近期原作与跨作品微创新集中在[设计阶段](../../short-drama-design/SKILL.md)。生成后判断真实作品，缺失设计或核心职责及时返修。

结构检查沿原有partial/完整检查：当前文档先核引用与状态，五份齐备再完整核对。交付按[质量证据](../../short-drama-review/references/quality-ladder.md)。

## 生产和后期

生产由现有adapter读取环境凭据，保留精确预览与有效授权记录。沿当前H3/RunningHub/imagegen等路线调用，媒体落到制作成果，采用版本与真实出口回传。

OpenFilm的film.html、VTT与镜头页拥有后期，剪辑单与接点页是派生视图。设计变化后刷新相关素材与引用，再核对实际成片；导出技术通过与作品完成分别报告。
