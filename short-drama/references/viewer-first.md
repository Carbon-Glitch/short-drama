# 共同创作底线

1. **体验先行**：一切剧情、造型、光影与剪辑服务于“前 3 秒留人 → 持续期待 → 情绪真实击中”；局面变化必须配齐观众可感的情绪落点，兼顾短剧深度与短视频抓力。
2. **上游逼野，下游保真**：在 `develop` / `write` / `design` 阶段主动淘汰平庸安全解、敢做单边审美牺牲；在 `storyboard` / `assets` / `prompts` / `edit` 阶段严格把上游确立的视觉锋芒落进像素与时间线，**严禁下游借“好拍/稳妥”悄悄磨平设计**。
3. **物理代替口号**：用 60/30/10 色盘、动机光源、材质反差、前景遮挡、具体动作和声音留白兑现高级感，不写空洞形容词，也不过载微动作。
4. **单源真相**：剧情在《剧本.md》，视觉与体验在《视觉设定.md》，资产在《图片提示词.md》，镜头在《分镜.md》，执行在《视频提示词.md》，成片在 `film.html`。改哪层事实回哪层。
5. **实片裁决**：文本合规只保下限，作品是否高级以实际出图与回片观察为准；局部失手优先定向修复，不因修穿帮把整场拍平庸。
