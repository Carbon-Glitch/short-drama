# 共同创作底线

1. **体验先行**：一切剧情、造型、光影与剪辑服务于“前 3 秒留人 → 持续期待 → 情绪真实击中”；局面变化必须配齐观众可感的情绪落点，兼顾短剧深度与短视频抓力。
2. **创作权限**：锁定剧情核、情感心脏与核心审美主张；鼓励下游分镜、生产和剪辑在实测中发现更强实现并大胆采用，不为省事磨平设计；重大视角或结构改动同步写回来源，改变用户锁定事实先取得授权。
3. **物理代替口号**：用本片选定的可见、可听事实兑现体验；视觉与节奏策略由[设计阶段](../../short-drama-design/SKILL.md)按题材选择，不写空洞形容词，也不过载微动作。
4. **单源真相**：剧情在《剧本.md》，视觉与体验在《视觉设定.md》，资产规划与采用在《视觉设定.md》的资产实现，图片生成说明在《图片提示词.md》，镜头在《分镜.md》，执行在《视频提示词.md》，成片在 `film.html`。改哪层事实回哪层。
5. **实片裁决**：文本合规只保下限，作品是否高级以实际出图与回片观察为准；局部失手优先定向修复，不因修穿帮把整场拍平庸。
