# Skill 版本对照评估

仅在修改 skill 后评估创作行为变化时阅读；不属于创作任务默认加载，也不是实际媒体通过率报告。
离线结构测试与真实媒体测试继续各走现有工具，本页补上“同一模型怎样比较两个 skill 版本”。

## 固定比较条件

1. 固定模型、运行宿主、采样设置、项目输入与已确认条件；基线版和候选版使用独立新对话。
2. 两版收到相同首轮输入和后续答复，不给候选版额外提示；记录 skill 版本、实际读取文件、读取字符量、输出和轮数。
3. 先跑此前失败的高区分度场景，再检查相邻能力是否回归。单次结果只说明本次观察，需要重复时报告次数。
4. 文本缺陷、阅读成本与媒体效果分开报告，不合成“精品总分”，不把字数更少自动视为更好。

## 最小区分场景

| 场景 | 主要观察 | 容易误通过的地方 |
|---|---|---|
| 长对白与有意长镜 | 信息承受、说话策略、同镜表演与覆盖是否由职责选择 | 为显得丰富而按秒强切，或全程单视点丢失反应 |
| 句末信息触发 | 反应是否从足够信息到达时开始 | 提前知道句末、机械统一话后停顿 |
| 画外承受后回切 | 压力、误判、动作与策略是否连续累积 | 画外复位成未听见的平静脸，或每句都强制反应 |
| 正反打受光 | 同一世界光源是否正确投影，暗部与光变是否有来源 | 两张脸同样亮、光源随反打移动、下一镜光态复原 |
| 关键交接与接触 | 起态、触点、释放/接住、归属与终点是否完整 | 用特写或切镜遮掉唯一交接，动作重复计时 |
| 多段生成边界 | 整组容量是否可行，剧情断点与真实接法是否成立 | 局部最近导致后段超限，或改表演凑平均段长 |
| 非人角色 | 是否用已有感知与可动结构完成表达 | 套人类眉嘴、增加器官、所有通道同时运动 |
| 分镜审阅预览 | 完整声画调度是否保留原话、反应、起止、声音与按需交接 | 只留画面亮点、摘要掉对白，或另写一份分镜权威 |
| 关键场次的表达选择 | 是否有常规基线与机制不同的候选，选定是否最大化观看价值 | 只交第一版安全答案，或只改变景别/运镜数量假装发散 |
| 选定机制的下游保真 | 设计重点、分镜、提示词、素材与剪法是否保住同一观看收益 | 为容易生成/剪辑退成通用构图、表演与平均切镜 |

不是每次修改都跑全部场景；先选直接受影响项和最容易被波及的相邻项，并说明选择理由。

## 记录与采用

- **文本一致性**：漏改原话、擅增事件、知情错误、空间/持物矛盾、不可见表演、动作重复、段界算术错误、无效切镜数。
- **阅读与交付成本**：实际读取文件及字符、首轮和全任务输出字符、到达同一交付范围的轮数；局部返修单独记录是否误读全库。
- **创作判断**：指出具体镜头和观众影响，保留有效强项；没有真人首看时标为作者自检或模拟首看，不冒称受众测试。
- **媒体验证**：另用相同入口、参数和参考素材试拍，记录真实缺陷、返工与未测项；文本改进不能推出媒体已提升。

采用候选版前，现有离线检查须通过，目标缺陷应有同条件证据改善，且没有把长镜、固定摄影、亮暗关系、
表演幅度或接镜选择硬化成统一配额。新观察只登记适用版本和场景，不因一次成功永久增加全局规则。
