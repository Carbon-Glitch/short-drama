# 中文短剧剧本核心

本页是写作默认入口，只保留最小创作契约和按需路由。新写、修订、规范化与审查分开加载，
不再默认阅读完整方法库。

## 最小创作契约

1. 先锁定本集观看承诺、人物当前目标、阻力、兑现和退出状态，再选择场景与载体。
2. 场景通过行动、信息、关系、权力、情绪或物理状态产生有效变化；氛围和过渡场不必硬造对手。
3. 核心转向由已建立的事实、筹码、代价或人物选择推动；偶然事件可以制造麻烦，不替人物完成核心解困。
4. 内在意义优先落到可表演行动、证据、空间、关系反应或有意声音；不为“可见”堆微表情。
5. 对白与画面各自承担必要工作。语言行动、精确信息和人物关系不必强行翻译成肢体动作。
6. 关键物件、空间和声音进入行动链；重复出现必须增加新作用，不重复解释已兑现的信息。
7. 时长按真实朗读、动作路径、反应和可读信息判断；不用统一字数、节拍或反转配方填满作品。
8. 保留用户已定内核、角色、原文与风格选择；普通美术和可拍实现主动发展，真实方向分叉再交创作者。

规则分级与冲突优先级见[契约与所有权](../../short-drama/references/contract-and-ownership.md#规则分级)。
长度、场景数量、对白比例和转折位置本身不证明质量；项目已接受的节奏档案才是数值核对依据。

## 改稿与交付复核

[剧本修订遍](script-revision.md)只在改稿或复核时读取。每遍只处理一类问题：
因果、选择、证据、场景、可表演、具体性、生产事实、声音与潜台词、扫读、经济性和所有权。
题面没有启用的机制不为检查而补造。
